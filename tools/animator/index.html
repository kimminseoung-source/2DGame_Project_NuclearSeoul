동작 만들기

캐릭터 그림을 조각으로 나누고, Blender 동작의 관절 각도대로 돌려 프레임을 만든다. 그림을 새로 그리지 않는다.
동작 좌우 반전 (왼쪽을 보는 방향)
오른팔·왼팔 바꾸기
앞에 그릴 팔 = 오른팔
양손으로 잡기 (왼손이 손잡이 아래)
깨진 곳 정리 (구멍·튄 점·외곽선)
서 있기에서 움직인 만큼만 (그림의 기본 자세 유지)
저장 위치: assets/characters/<캐릭터>/rig/<방향>.json
왼쪽 버튼으로 칠하기, 오른쪽 버튼으로 지우기(나누지 않음). 붓 크기
왜 나누나
조각마다 다른 관절을 축으로 돌린다. 몸통은 엉덩이, 머리는 목, 윗팔은 어깨, 아랫팔은 팔꿈치, 다리는 고관절·무릎을 축으로.
키 비율로 나눈 뒤, 팔·손이 몸통에 겹친 곳만 고치면 된다.
고른 관절을 그림 위에 클릭해서 옮긴다.
조각의 위·아래 끝으로 어깨·팔꿈치·손목 등을 추정한다. 틀린 점만 옮긴다.
초록 점 = 손(무기 손잡이), 노란 선 = 무기 방향(동작의 bat_dir)
뼈대 보기
원래 그림 겹쳐 보기
프레임을 클릭: 파란 테두리 = 준비, 빨간 테두리 = 치기 (④에서 저장)
프레임 그림: <캐릭터>/Tool_<동작>/<방향>/번호.png
keyframes.json의 이 방향을 덮어쓴다(원래 값은 같은 폴더 keyframes_backup.json).
