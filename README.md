# 부산까지 (가제)

핵 재난 이후 가상의 한국에서 서울부터 부산의 대피 거점까지 이동하는 다크풍 2D 도트 생존 탐색 게임.

- 개발 환경: Python + pico2d
- 화면: 탑뷰 / 싱글 플레이
- 핵심: 공기·방호복·물자 관리, 태도를 알 수 없는 생존자와의 조우 및 근접 전투
- 현재 상태: **기획 및 1차 발표 자료 준비 단계. 실행 가능한 게임 코드는 아직 없습니다.**

## 게임의 흐름

거점에서 준비 → 지상·건물 탐색 → 전투·생존자 조우 판단 → 다음 거점 도착 → 정비 → 부산 도착.

물자를 더 찾으면 이동에 도움이 되지만 공기와 장비를 소모합니다. 생존자 발밑에 관계를 원으로 표시합니다. 미확인은 회색 원과 `?`, 우호는 초록 원, 적대는 빨간 원입니다. 첫 조우는 미확인이며, 대화와 행동을 통해 태도가 드러나면 발밑 표시가 바뀝니다.

## 개발 원칙

리소스는 프로젝트 기준 상대경로로 로딩합니다. 실제 기능 구현과 검증 단위로 커밋하며, 완성된 작업을 사후에 나누거나 빈 커밋으로 개발 기록을 만들지 않습니다. 기획 1 ‘도장깨기’는 이 프로젝트에 포함하지 않습니다.

## 현실과 가상의 구분

실제 대응 원칙을 일부 참고하지만, 부산 이동·적 행동·공기와 체력 수치는 가상 설정입니다. 실제 비상대응 지침을 대신하지 않습니다. 참고 링크는 PRD와 기획서 발표자 노트에 기록했습니다.
