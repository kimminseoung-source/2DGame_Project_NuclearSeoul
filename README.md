# 부산까지 (가제)

핵 재난 이후 가상의 한국에서 서울부터 부산의 대피 거점까지 이동하는 다크풍 2D 도트 생존 탐색 게임.

- 개발 환경: Python + pico2d
- 화면: 횡스크롤 / 바닥 깊이 이동 / 싱글 플레이
- 핵심: 실시간 탐색과 발더스 게이트 3식 턴제 전투(미터 단위 자유 이동, d20 명중·피해 굴림), 물자 관리, 생존자 조우
- 현재 상태: **방공호·지상 탐색과 피폭체 1마리와의 턴제 전투 시제품.** 이동·공격·기회 공격, 명중 확률, 명중 돌림판과 피해 숫자 표시, BG3식 핫바·턴 순서·전투 기록까지 구현.

## 시제품 실행

Windows에서 Python 3.12로 검증했습니다. 저장소 루트에서 다음 명령을 실행합니다.

```powershell
python -m pip install -r requirements.txt
python src/main.py
```

`A/D`로 좌우 이동하고 `W/S`로 바닥 통로 안에서 위아래로 움직입니다. 위아래로만 이동하면 마지막으로 바라본 좌우 방향을 유지합니다. `Shift`를 누른 채 이동하면 속도를 낮춰 조용히 걷습니다. 방공호에서 노란 필터 근처의 `E`로 줍고, 오른쪽 출입문에서 `E`를 눌러 지상으로 이동합니다. 지상에서 필터를 주워 초록 출구로 이동하면 구간이 끝납니다. 도착 후 `R`로 다시 시작하고, `Esc`로 종료합니다.

게임에서 `F1`을 누르면 설정이 열리고 플레이가 일시 정지됩니다. `←`와 `→`로 이동 속도를 50~150% 사이에서 조절하고, `R`로 기본값 100%를 되돌립니다. `F1` 또는 `Esc`로 게임을 재개합니다. 이동 속도는 게임을 종료할 때까지 적용됩니다.

지상 카메라는 캐릭터를 가로로 따라갑니다. 도로에서 예비 필터를 챙겨 오른쪽 출구에 도착하는 것이 목표입니다.

마우스가 캐릭터의 왼쪽이나 오른쪽에 있으면 그쪽을 봅니다. `좌클릭`으로 방망이를 휘두르고, `Space`로 이동 입력 방향에 짧게 대시합니다. 이동 입력이 없으면 바라보는 방향으로 대시합니다.

### 전투

지상에서 피폭체에게 들키면 턴제 전투가 시작됩니다. 들키기 전에 가까이 다가가 `좌클릭`하면 기습이 되어 피폭체가 첫 라운드를 쉽니다.

- 내 턴이 되면 캐릭터가 자동으로 선택됩니다. 아래 핫바에서 `1 이동` 또는 `2 공격`을 고르거나 숫자키를 누릅니다.
- 이동: 파란 영역 안을 클릭하면 그 지점까지 걸어갑니다(최대 7.5m). 이동 거리는 걷는 만큼 줄어듭니다.
- 공격: 적을 클릭하면 사거리(1.5m) 안이면 바로, 밖이면 다가가서 방망이로 칩니다. 적에게 마우스를 올리면 명중 확률이 보입니다.
- 공격하면 머리 위 돌림판(d20 20칸)의 바늘이 휘리릭 돌다가 명중 굴림 결과에 멈춥니다. 초록 칸이 명중, 빨간 칸이 빗나감이라 초록 넓이가 곧 명중 확률이고, 노란 선부터 명중입니다(d20 + 4가 방어 이상). 선 근처 결과는 바늘이 선에 걸린 채 잠시 멈췄다가 넘어가거나 되돌아옵니다. 확률은 유닛의 방어·명중 보너스로 정해지므로 적마다 다르게 할 수 있습니다. 맞으면 대상 위에 피해 숫자가 뜹니다. 주사위 20은 치명타, 1은 대실패입니다.
- 공격 칸이나 무기 칸에 마우스를 올리면 피해 범위(3~8)가 보입니다.
- 붙어 있던 적에게서 멀어지면 기회 공격을 받습니다. `Space` 또는 오른쪽 아래 원형 버튼으로 턴을 끝냅니다. `L`로 오른쪽 위 전투 기록을 접고 펼칩니다. 우클릭은 고른 행동을 취소합니다.

Tab으로 배낭을 열고 닫습니다. 방향키로 슬롯을 선택하고 Esc로 닫을 수 있습니다. 창이 열려 있는 동안 이동, 공격, 줍기가 정지합니다. 예비 필터는 한 슬롯에 합쳐지고 HUD에도 같은 수량이 표시됩니다. 현재 시제품에서는 필터를 보관할 수 있으며, 장착 필터 잔량과 교체는 생존 시스템 단계에서 연결합니다.

## 게임의 흐름

핵전쟁 오프닝 → 대피 튜토리얼 → 방공호에서 준비 → 지상·건물 탐색 → 전투·생존자 조우 판단 → 다음 거점 도착 → 정비 → 부산 도착.

첫 방공호에서 공용 물자를 수집하고 생존자와 물물교환한 뒤 출발합니다. 대화나 개인 물자에 대한 행동에 따라 생존자의 관계가 바뀝니다. 지상에서 물자를 더 찾으려면 필터를 소모합니다. 생존자 발밑에 관계를 원으로 표시합니다. 미확인은 회색 원과 `?`, 우호는 초록 원, 적대는 빨간 원입니다. 첫 조우는 미확인이며, 대화와 행동을 통해 태도가 드러나면 발밑 표시가 바뀝니다. 대화와 물물교환은 미확인 또는 우호 상태에서만 가능합니다.

## 코드 구조

수업(LEC11~14)에서 배운 구조를 따릅니다. 화면에 나오는 것은 모두 `update()`와 `draw()`를 가진 클래스이고, `game_world`의 레이어에 담아 한꺼번에 갱신하고 그립니다.

| 파일 | 역할 |
| --- | --- |
| `main.py` | `reset_world → handle_events → update_world → render_world` 루프와 객체 사이의 규칙(줍기, 출구, 전투 시작·종료) |
| `game_world.py` | 레이어별 `add_object` / `remove_object` / `update` / `render` (배경 → 바닥 표시 → 캐릭터(깊이 정렬) → 효과 → 전투 표시 → 상단 띠 → 팝업 → 하단 핫바) |
| `player.py`, `zombie.py` | 주인공과 피폭체. `transitions.Machine` 상태 기계(주인공: IDLE·WALK·SNEAK·DASH·PICKUP·SWING·COMBAT) |
| `background.py`, `wreck.py`, `supply.py`, `exit_door.py`, `effects.py` | 배경, 폐차, 바닥의 필터, 출구, 타격 효과 |
| `hud.py` | 탐색 중 상단 띠, 하단 띠, 배낭·설정 창 |
| `combat.py` | 턴제 전투 규칙(선공, 턴 자원, 이동, 명중·피해 굴림, 기회 공격, 적 행동) |
| `combat_view.py` | 전투 화면 요소별 클래스(이동 영역, 명중 돌림판, 피해 숫자, 대상 정보, 턴 순서, 핫바, 전투 기록 등) |
| `nav.py` | 보이지 않는 0.25m 격자의 길찾기와 거리(미터) 계산 |
| `ui.py`, `camera.py`, `game_clock.py` | 공통 색·글꼴·도형, 카메라, 프레임 시간 |

## 개발 원칙

리소스는 프로젝트 기준 상대경로로 로딩합니다. 실제 기능 구현과 검증 단위로 커밋하며, 완성된 작업을 사후에 나누거나 빈 커밋으로 개발 기록을 만들지 않습니다. 기획 1 ‘도장깨기’는 이 프로젝트에 포함하지 않습니다.

## 현실과 가상의 구분

실제 대응 원칙을 일부 참고하지만, 부산 이동·적 행동·필터와 체력 수치는 가상 설정입니다. 실제 비상대응 지침을 대신하지 않습니다. 참고 링크는 PRD와 기획서 발표자 노트에 기록했습니다.
