# 부산까지 (가제)

핵 재난 이후 가상의 한국에서 서울부터 부산의 대피 거점까지 이동하는 다크풍 2D 도트 생존 탐색 게임.

- 개발 환경: Python + pico2d
- 화면: 탑뷰 / 싱글 플레이
- 핵심: 방독면 필터·물자 관리, 태도를 알 수 없는 생존자와의 조우 및 근접 전투
- 현재 상태: **1주차 탐색 시제품. 방공호, 방향별 걷기 스프라이트, 필터 수집과 구간 이동 구현.**

## 시제품 실행

Windows에서 Python 3.12로 검증했습니다. 저장소 루트에서 다음 명령을 실행합니다.

```powershell
python -m pip install -r requirements.txt
python src/main.py
```

`WASD`로 방독면 캐릭터를 이동합니다. `Shift`를 누른 채 이동하면 속도를 낮춰 조용히 걷습니다. 방공호에서 노란 필터 근처의 `E`로 줍고, 오른쪽 출입문에서 `E`를 눌러 지상으로 이동합니다. 지상에서 필터를 주워 초록 출구로 이동하면 구간이 끝납니다. 도착 후 `R`로 다시 시작하고, `Esc`로 종료합니다.

게임에서 `F1`을 누르면 설정이 열리고 플레이가 일시 정지됩니다. `←`와 `→`로 이동 속도를 50~150% 사이에서 조절하고, `R`로 기본값 100%를 되돌립니다. `F1` 또는 `Esc`로 게임을 재개합니다. 이동 속도는 게임을 종료할 때까지 적용됩니다.

지상 테스트 맵은 32×10칸이며 화면은 가로로 스크롤합니다. 예비 필터를 챙긴 뒤 아래쪽의 짧은 길이나 위쪽의 우회로로 오른쪽 출구에 갈 수 있습니다.

`Space`를 누르면 바라보는 방향으로 야구 방망이를 휘두릅니다. 지상 예비 필터 오른쪽의 나무 상자로 공격을 시험할 수 있습니다.

## 게임의 흐름

핵전쟁 오프닝 → 대피 튜토리얼 → 방공호에서 준비 → 지상·건물 탐색 → 전투·생존자 조우 판단 → 다음 거점 도착 → 정비 → 부산 도착.

첫 방공호에서 공용 물자를 수집하고 생존자와 물물교환한 뒤 출발합니다. 대화나 개인 물자에 대한 행동에 따라 생존자의 관계가 바뀝니다. 지상에서 물자를 더 찾으려면 필터를 소모합니다. 생존자 발밑에 관계를 원으로 표시합니다. 미확인은 회색 원과 `?`, 우호는 초록 원, 적대는 빨간 원입니다. 첫 조우는 미확인이며, 대화와 행동을 통해 태도가 드러나면 발밑 표시가 바뀝니다. 대화와 물물교환은 미확인 또는 우호 상태에서만 가능합니다.

리소스는 프로젝트 기준 상대경로로 로딩합니다. 실제 기능 구현과 검증 단위로 커밋하며, 완성된 작업을 사후에 나누거나 빈 커밋으로 개발 기록을 만들지 않습니다. 기획 1 ‘도장깨기’는 이 프로젝트에 포함하지 않습니다.

## 현실과 가상의 구분

실제 대응 원칙을 일부 참고하지만, 부산 이동·적 행동·필터와 체력 수치는 가상 설정입니다. 실제 비상대응 지침을 대신하지 않습니다. 참고 링크는 PRD와 기획서 발표자 노트에 기록했습니다.
