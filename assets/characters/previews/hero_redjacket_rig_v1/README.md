# 기존 동작 + 새 외형 · 3D 재사용 비교

2026-11-23. 사용자: 이전 주인공 동작이 자연스러우니 그 위에 지금 외형을 넣을 수 있는지 확인.

## 확인한 구조

- 기존 게임 주인공 `hero_3d`는 MPFB 리깅 모델에 Mixamo 동작을 붙여 렌더한 그림이다. `tools/sprites/build_hero3d.py`, `tools/blender/mpfb_pose.py`가 제작 근거다.
- Walking은 원본 동작 시간 구간을 6등분한 표본이다. 조준 이동은 같은 걷기 하체와 Baseball_Hit 준비 상체를 혼합한다. 현재 기본 samurai 공격은 baseball 준비와 greatsword 타격/회복을 조합한다.
- 따라서 동작을 프레임마다 AI로 다시 만들 필요 없이, 같은 뼈대에 새 외형을 붙이고 기존 동작을 다시 렌더할 수 있다.
- 정지 그림 한 장을 통째로 덮는 방법은 관절 회전·몸 뒤로 가려진 면·검/손 위치를 제공하지 않는다. 한 방향 2D 부위 분리는 가능하지만 8방향과 몸 회전에서는 안 보이는 면을 추가 제작해야 한다.

## 이번 실제 시험

- 원본 `C:/Users/doboh/busan_ai/mpfb/busan_hero.blend`를 별도 복사본으로 열어 기존 뼈대를 유지했다. 원본에는 저장하지 않았다.
- 복사본에서 붉은 짧은 재킷, 어두운 안옷, 맨손, 팔 두께, 넓은 바지, 배낭 없음으로 조정했다. 검은 별도 3D 오브젝트다. 머리카락/얼굴과 의상은 원화 복제가 아닌 기존 메시를 조정한 실험이므로 외형이 많이 단순하다.
- 모델: `assets/source3d/scenes/hero_redjacket_rig_v1/hero_redjacket_v1.blend`.
- 기존 Walking.fbx와 기존 생성기의 `round(f0+(f1-f0)*i/6)`를 그대로 사용해 남동 한 방향 6프레임을 렌더했다. 프레임별 정지 그림 변형이나 AI 재생성은 하지 않았다.
- 고정 카메라와 같은 픽셀 밀도로 ID/light 패스 24장(몸/검 포함 각 6×2)을 렌더하고 팔레트로 변환했다. 최종 PNG 12장 모두 비어 있지 않고 캔버스 경계에 닿지 않는다.
- `walk_comparison.gif`, `comparison.png`: 기존 / 새 AI / 기존 뼈대의 붉은 재킷 모델 비교. 3D 두 경우는 같은 시간 표본이다. 비교 패널 바닥은 각각 첫 프레임 발끝을 기준으로 한 번 맞춘 것이며 프레임마다 발끝을 이동시킨 것이 아니다. 모델 지면 원점 투영은 별도로 `renders/anchors.json`에 보존했다.
- 새 모델은 이전 결과보다 목표 몸 높이를 작게 맞춘 36px 기준이며 기존 모델의 현재 실제 출력 높이와 차이가 있다. 프레임이 시간상 같다는 것이 이미지 좌표나 외형까지 같다는 뜻은 아니다.

## 판단과 다음 작업

기존 동작 재사용은 가능하며 관절/몸 비율이 프레임마다 새로 생성되지 않는 장점이 있다. 어려운 부분은 리깅 재사용보다 승인된 AI 외형을 3D 모델로 맞추는 일이다. 현재 모델은 원화의 넓은 어깨·머리 모양·얼굴·바지 형태가 부족하므로 정식 외형으로 승인받은 결과가 아니다. 사용자가 좋아한 새 그림의 모습이 최우선이다.

이번은 걷기 한 방향의 방식 검증이다. 공격/조준/회피/피격/쓰러짐을 새 모델로 렌더하거나 게임에 교체하지 않았다. 현재 플레이 가능한 AI 버전도 그대로 보존했다. 외형을 맞춘 뒤 기존 조준/검 공격을 같은 뼈대에서 재사용하는 것이 다음 순서다. 3D 외형으로 그림의 매력을 유지하기 어렵다면 부위 분리 2D 방식도 한 방향에서 비교할 수 있지만 지금 구현한 결과는 아니다.
