# 총 중심 첫 시험 · 권총 양손 자세

2026-11-23. 사용자는 총 조준을 먼저 정하고 몸과 총을 분리하는 방향에 동의했으며 첫 무기로 **권총 양손 조준**을 선택했다.

- 계획: `docs/plans/2026-11-23_총중심_주인공_제작계획.md`(프로젝트 루트 기준). 이번은 단계1의 외형 확인 초안이다.
- 내장 image_gen으로 남동 한 방향 낮춰 들기/양손 조준 2자세를 만들었다. 원본 `generated_poses.png`, 문안/도구 기록 `prompt.txt`.
- `pistol_pose_guide.png`는 이번에 설계한 2D 팔/손 안내다. 기존 3D 하체 관절을 추출한 결과나 실제 권총 IK를 푼 결과로 보지 않는다.
- 외형: 검은 머리·붉은 재킷·검은 안옷·넓은 카고 바지, 배낭/두루마리 없음. 기존 권총 PNG는 9×4이며 이번 새 원화의 권총과 동일 자산이 아니다.
- `low_ready_36px.png`, `aim_36px.png`: 64×64 RGBA, 낮춰 든 몸 높이 36px 기준의 공통 배율. 발바닥 행 58, 경계 접촉 없음. `comparison.png`는 정수 5배 확대다. 측정은 `validation.json`.
- 조준 자세는 양손 지지/앞을 향하는 총이 구분된다. 낮춰 든 자세는 손 겹침과 작은 총의 윤곽이 실제 크기에서 덜 명확하여 검토가 필요하다. 두 자세의 골반/어깨 전환도 아직 애니메이션으로 검수하지 않았다.
- **현재 그림에는 총이 포함돼 있다.** 몸/총 분리, 손잡이·보조손·총구 좌표 측정, 손가락 가림 처리, 발사/반동, 게임 연결은 아직 하지 않았다. production.json의 좌표 이름은 요구사항이며 측정값이 아니다.
- 최초 이미지 요청은 도구 필터에 차단됐고 게임 미술 시안임을 명확히 한 재시도로 결과를 받았다. 외부 API/새 설치는 사용하지 않았다.
- 원본/기존 게임/검 시안 보존. 다음은 자세 확인 후 단계2 분리와 기준점 정리다. 공격/움직임/여러 방향으로 아직 확장하지 않는다.

정리 도구: `tools/sprites/pistol_pose_study.py`. 커밋/푸시 없음.
