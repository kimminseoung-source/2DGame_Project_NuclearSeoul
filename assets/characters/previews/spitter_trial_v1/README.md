# 원거리 피폭체 1차 시험 · 2026-11-23

기존 주인공과 일반 피폭체를 유지하고 원거리 피폭체를 별도 시험장에 추가했다. 정식 스테이지 출현과 주인공 재설계는 적용하지 않았다.

## 실행

프로젝트 루트에서:

```powershell
.venv\Scripts\python.exe tools\run_spitter_trial.py
```

또는 `tools/원거리_피폭체_시험.cmd` 실행. WASD 이동, 마우스 시선, 좌클릭 공격, Space 구르기, R 재시작, Esc 종료. F4 개발 패널의 정지 기능으로 자세를 볼 수 있다.

## 제작 방식과 결과

- 내장 image_gen으로 참고 시안의 핵심 자세 8장 생성. 원본 `generated_keyposes.png`, 요청 문안 `prompt.txt`. 별도 유료 API/플러그인 설치 없이 수행했다.
- `tools/sprites/build_spitter_trial.py`: 원본을 같은 배율로 축소하고 64×64 칸의 발 기준점 (32,58)에 정렬. 대기 키는 높이 36px, 다른 자세는 같은 배율이라 자세에 따라 높이가 다르다. 몸을 늘이거나 프레임별로 다른 배율을 쓰지 않았다.
- 본체와 발광 PNG를 분리. 대기/걷기/회복은 초록빛 없음. 준비 0.8초 동안 발광 불투명도 증가 → 발사 0.16초 → 회복 1.2초 소등.
- 한 방향 + 좌우 반전. 걷기 2장, 공격 3장, 대기·피격·누운 시체 각 1장이다. 시체는 넘어지는 중간 동작이 없으며 위아래 공격용 그림도 아직 없다.
- `src/spitter.py`: 일반 피폭체 감각/추적/경직을 재사용. 발견 표시는 잠깐 `!`뿐. 원거리 피폭체에 근접 공격 범위 부채꼴은 표시하지 않는다.
- 준비 시작 위치를 조준하고 고정하므로 옆으로 움직이면 피할 수 있다. 몸통 피격 또는 카운터로 준비를 끊는다. 시험 버전의 다리 피격은 기어가기 대신 경직한다.
- 시험 수치: 공격 거리 230, 이동 속도 46, 탄 속도 180, 최대 비행 거리 440, 피해 12. 추가 중독·출혈·붙잡기는 없다. 구르기 무적과 개발 무적을 존중하고 벽에서 소멸한다. 죽은 발사자의 탄도 이미 발사됐다면 남는다.
- 기본 스테이지는 새 종류를 생성하지 않는다. `tools/run_spitter_trial.py`에서만 원거리 1마리와 일반 1마리를 배치한다.

## 확인

- `tools/checks/check_spitter.py`: 7개 역학 검사 통과. 얇은 벽을 관통하지 않는 연속 충돌, 벽 안 시작/스치는 탄, 구르기, 옆 회피, 조준 고정, 피격 중단.
- 기존 Game을 사용한 숨김 창 시뮬레이션: 준비·발사·회복 확인, 주인공 체력 100→88, 재시작 시 탄 초기화, 가방/개발 정지 중 탄 멈춤, 발사자 사망 후 탄 유지 확인.
- 실제 렌더: `game_trial.png`, `game_trial.gif`. 그림 비교: `attack_board.png`. 수치 기록: `validation.json`, `runtime_check.json`.
- 판단: 한 방향의 실루엣과 발광 예고를 빠르게 검토하기에는 유용하다. AI가 자세마다 어깨 폭과 팔다리 크기를 조금 다르게 그려서 8방향 장기 제작 방식으로 확정할 근거는 부족하다. 걷기는 두 장이라 거칠고, 피격 하얀 번쩍임·넘어지는 애니메이션도 미완성이다. 다음 비교는 같은 디자인을 3D→도트로 만들 때의 방향/관절 일관성과 비용이다.
- 사람의 실제 플레이 감각은 아직 사용자 검토 전이다. 자동 검사 통과를 재미나 최종 품질 승인으로 해석하지 않는다.

## 관련 파일

- `src/spitter.py`: 새 피폭체/발광 그리기/탄.
- `src/play.py`: 탄 초기화·업데이트·시야 내 그리기·피격 연결.
- `src/attack_tells.py`: 원거리 종류를 근접 부채꼴에서 제외.
- `docs/plans/2026-11-23_원거리_피폭체_시험.md`: 범위와 결정 기록.
