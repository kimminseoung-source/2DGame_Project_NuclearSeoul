# 좁힌 기본 자세 + 공통 걷기 하체 + 팔만 조준

## 최신 A/B 플레이

`tools/권총_AB_비교_플레이.cmd`를 실행하면 처음 권총 자세(A)와 이 수정본(B)을 F8로 전환하며 같은 조건에서 비교한다. A는 대기/조준 두 그림만 있어 걷기는 정지 그림으로 이동한다. B는 공통 걷기 다리8을 사용한다. F9 적 정지/재개, R 재시작, 기존 조작 동일. 전환해도 위치/체력/탄약/조준을 초기화하지 않는다. 처음은 적 정지다. 비교 도구는 자세 선호와 걷기 품질을 구분하기 위한 것이며 기존 품질 문제를 해결한 새 애니메이션 제작은 아니다.

> 후속 품질 판단: 사용자 지적 후 8프레임을 재대조했다. 상체 고정/다른 하체 합성 때문에 무게 이동과 골반 연결이 어색하다. **이 결과는 구조 시험이며 최종 동작으로 채택하지 않는다.** `diagnostic_contact_sheet.png`와 현재 총 중심 계획서의 최신 품질 판단을 참고한다. 다음은 같은 전신에서 설계한 조준 보행 한 방향을 검토한다. 기존 실행은 기록/비교용으로 보존했다.

## 후속 · 사용자 직접 플레이 연결

- 사용자 요청에 따라 `tools/권총_수정자세_플레이.cmd` 또는 `.venv\Scripts\python.exe tools\run_shared_pistol_trial.py`로 직접 조작할 수 있게 연결했다. 아래 ‘게임 미연결’은 이전 합성 단계 기록이다.
- 일반/원거리 피폭체가 있는 시험장. WASD 이동, 좌클릭 누르기 조준/놓기 발사, Space 회피, R 재시작, Esc 종료. 시험용 탄약60발이며 재장전 기능을 추가한 것이 아니다.
- 상체2/공통 하체9/권총1을 실행 중 실제로 분리 그리며, 이동량에 따라 같은 다리8장을 대기/조준 이동에서 공유한다. 총을 낮춰 들거나 올려도 정지 하체는 동일하다.
- 숨김 실제 게임에서 대기/걷기8프레임/정지조준/조준이동/탄1발 차감/회피/피격/재시작 유지 확인.
- 현재는 좌우 반전 자세만 있다. 탄도/명중/반동 수치는 기존 권총 코드를 사용하며 실제 새 총구 좌표와의 정합은 미완성이다. 피격/쓰러짐은 정지 그림, 회피는 다리 그림과 잔상으로 임시 대체한다. 기존 검 실행/기본게임은 보존했다.

## 이번 방식

- 내장 image_gen으로 무기 없는 대기/조준 원본 2장을 생성했다. 좁은 같은 정지 하체와 머리/몸통을 유지하고 팔 자세를 바꾸도록 요청했다. `generated_emptyhands.png`, `prompt.txt`.
- 원본을 같은 배율로 64×64에 정리했다. 허리 분할선 Y=42, 머리 상단 구간 [0,31)은 대기 그림을 조준에도 그대로 공유했다.
- 정지 하체는 **하나의 동일 이미지** `lower_idle.png`만 사용한다. 양쪽의 부츠 영역 바이트가 같은지 확인했다. 부츠 마지막 4행의 가로 범위는 기존 조준 26px → 새 대기/조준 모두 14px다. 해부학적 어깨 폭의 실측이 아닌 표시된 부츠 픽셀 범위다.
- 걷기는 기존 `hero_poseguided_ai_v2_twohanded/walk_0..7.png`의 Y=42 아래 **하체 8장만 재사용**했다. 낮춰 들기와 조준 걷기에 같은 하체를 사용하고 상체만 고른다. 새로운 전신 걷기를 두 벌 생성하지 않았다.
- 상체는 `upper_low.png`, `upper_aim.png` 2개다. 팔/다리를 회전하거나 몸을 늘이지 않고 그려진 상하 조각을 동일 기준에서 합쳤다. 원화 고해상도 팔을 잘라 돌린 방식이 아니다.
- 총은 기존 `assets/weapons/pistol.png` 9×4 한 장을 분리해서 재사용한다. 낮춘 총은 무기만 회전하고 조준 총은 수평이다. 합성 순서는 하체→총→상체/손. 손잡이 좌표는 이 시험을 눈으로 맞춘 근삿값이며 아직 게임의 총구 기준/발사 위치로 검증하지 않았다.
- 원본/고유 그림 수는 **상체2 + 정지 하체1 + 걷기 하체8 + 권총1**. `low_walk_*`, `aim_walk_*`는 검토용으로 같은 원본을 합쳐 저장한 결과이지 새로 그린 16장이 아니다.

## 미리보기

- `stance_comparison.png`: 같은 하체로 낮춰 들기/팔을 들어 조준.
- `shared_walk.gif`: 낮춰 들고 걷기/조준 걷기 모두 같은 다리 8장이 움직임. 한 주기 600ms.
- `low_idle.png`, `aim_idle.png`, `low_walk_0..7.png`, `aim_walk_0..7.png`: 합성 결과.
- `layers.json`: 허리 분할선, 손잡이 근삿값, 원본 수, 검사와 제한. 조준/대기 상체/하체는 64×64 RGBA 좌표를 공유한다.

## 확인과 남은 부분

- 8개 하체가 모두 다른 이미지인지 해시로 확인했고, 16개 걷기 합성 결과가 캔버스 경계에 닿지 않음을 확인했다. GIF 저장 주기 600ms와 정지 하체의 동일함을 검사했다.
- 실제 게임 연결/총 발사/총구 보정/무적·피격 전환 검수는 하지 않았다. 최신 실제 플레이는 이전 검 버전 그대로다.
- 다른 시안에서 하체를 가져왔으므로 허리의 폭/색·주머니 위치와 작은 손/총 가림은 더 검토해야 한다. 원래 걷기의 다리 가림/발 접지 문제가 모두 해결된 것도 아니다. 같은 하체를 쓴다는 사실이 자연스러운 접지를 보장하지 않는다.
- 정지↔조준은 현재 팔 두 자세의 전환이다. 부드럽게 들어올리는 중간 팔 그림까지 만든 것은 아니다. 머리와 다리를 공유해 불필요한 전신 변화가 생기지 않도록 한 작은 구조 시험이다.
