# 3D는 자세 안내, 최종은 AI 그림 · 작은 걷기 시험

2026-11-23. 사용자는 AI 외형을 유지하고 3D 자세만 안내로 사용하는 작은 시험을 요청했다. 걷기 한 방향 6프레임만 만들었으며 게임에는 적용하지 않았다.

## 수행한 것

1. 원본 MPFB 모델을 읽고 Walking.fbx의 실제 시간 표본 `[1,7,13,20,26,32]`를 적용했다. 원본 모델 파일에는 저장하지 않았다.
2. 고정 정사영 카메라(방향 45도, 고도 30도)로 머리/어깨/팔꿈치/손목/골반/무릎/발목/발끝의 실제 위치를 투영했다. `pose_joints.json`은 원자료, `pose_guide.png`는 그 위치로 만든 자세 안내다.
3. 자세 안내와 승인된 외형 그림을 내장 image_gen에 함께 제공했다. 역할과 전체 요청은 `prompt.txt`, 생성 결과는 `generated_walk.png`.
4. 원본의 흐린 주변부는 알파 128 기준으로 정리하고 같은 배율로 축소했다. 첫 자세 높이 36px 기준, 64×64 RGBA, 공통 가로 중심과 발바닥 행 58. 프레임별 다른 배율이나 캐릭터를 코드로 변형하는 작업은 하지 않았다.

## 결과

- `walk_comparison.gif`: 왼쪽 기존 주인공, 가운데 앞선 AI 걷기, 오른쪽 이번 자세 안내 AI 그림. 6프레임, 100ms 간격. `comparison.png`는 첫 프레임이다.
- `walk_0.png`부터 `walk_5.png`: 게임 크기의 결과. 6장 모두 캔버스 경계 접촉 없음. 측정 `validation.json`.
- 앞선 넓게 선 걷기보다 무릎 통과/발 디딤/뒤꿈치 들기가 눈으로 구분된다. 걷기 때는 기존 팔 흔들기에 맞춰 검을 한 손으로 들었다. 공격의 양손 검 자세를 포기한 결정은 아니다.
- 최종은 3D 모델 그림이 아니라 붉은 재킷/검은 머리/넓은 바지의 AI 그림이다. 다만 직립 보행이라 낮은 전투 준비 자세보다 상체가 좁게 보인다.

## 남은 문제

- AI가 관절 위치를 정확히 복사하지 않았다. 머리/어깨/검 길이, 뒤쪽 발과 팔다리의 가림 관계에 프레임별 차이가 남았다. 결과 관절 오차를 자동 측정하지 않았으며 원화 외형이 완전히 유지됐다고 보지 않는다.
- 실제 뼈대가 결과 그림에 붙은 것은 아니다. 이미지로 자세를 안내한 생성이다. 강제 포즈 제어 모델이나 자동 리깅은 설치/사용하지 않았다.
- 게임 이동/발 접지 검증, 다른 방향/공격 제작은 이번에 하지 않았다. 기존 AI 플레이 버전은 그대로 보존했다.
- 방법은 더 비교할 가치가 있지만 생성 한 번으로 자연스러움이 보장되지 않는다. 다음 반복은 머리·어깨와 검의 차이를 줄이는 작은 수정이 적절하다.

도구: `tools/blender/export_walk_poseguide.py`, `tools/sprites/poseguided_walk_study.py`. 후자의 `--guide`는 안내 이미지 생성, 기본 실행은 생성 원본 정리와 비교 제작이다. 커밋/푸시 없음.
