# FACE-R1 · 같은 방향 얼굴을 한 장으로 공유 (2026-11-24)

## 사용자 지적과 실제 원인

사용자에게 가장 중요한 기준은 일관성이다. 정지/이동 얼굴 크기가 다르게 보였고 수정 동작을 보고 있는지도 불분명했다. 실제 D 로더가 이전 C의 상태 원화와 새 D 보행 원화를 혼합했다. 몸 높이36px/동작 연결/일부 상체 보존 검사는 얼굴 크기·형태 일치 검사가 아니었다. `../identity_audit/before_head_comparison.png`와 `head_region_grid.png`는 수정 전 비교다.

## 적용

- 새 얼굴을 생성하지 않았다. 기존에 사용하던 D `walk_0.png`에서10×9px 머리/얼굴 RGBA 레이어를 잘라 `head.png`로 저장했다. 크기/색/눈·코·머리 실루엣을 재샘플링하거나 회전하지 않았다.
- 같은 방향의 상태6키(low/raise/aim/recoil/settle/hurt), 보행16키, 무릎 보완4키가 이 **한 장의 머리 픽셀**을 공유한다. 각 원화의 목 위치만 지정하여 이동 배치했다. 머리 제거 마스크는 목 옆 팔을 지우지 않도록 명시했다. 모든 키에서32행 이하의 몸/다리를 보존했고 조준 팔 옆31행도 확인했다.
- `tools/sprites/build_pistol_identity.py`로 자산을 구성하고 `tools/pistol_gait_look.py`의 실제 D 로더에 연결했다. F10 수정 전/후도 머리는 공유하므로 얼굴이 이전 원화로 되돌아가지 않는다. A/B/C는 역사적 비교로 원본 유지한다.
- 넘어짐/누움은 머리 각도가 달라 기존 별도 원화다. 이번 정방향 머리 공유가 전체 방향·표정·죽음 원화나 몸 전체의 완전한 동일성을 보장하지는 않는다. 현재 요청한 정지/걷기/조준의 얼굴 크기·픽셀을 고정한 범위다.

## 버전과 플레이 안정성

- 모든 새 비교 실행 화면 우상단에 `BUILD FACE-R1`을 고정 표시한다. 최신 얼굴 공유가 적용되는 모드는 **D**이며 `D 얼굴 공유`라고 함께 표시한다. F10은 무릎·접지 반응만 비교한다. 이 표식이 없는 창은 FACE-R1 확인용 창이 아니다.
- 이전 무릎 수정판의 로그에서 UI 텍스트가601개가 되면 캐시 전체를 지워 현재 키까지 사라지는 KeyError가 발견됐다. `src/pixel_ui.py`는 가장 오래된 항목만 제거해 새 항목을 유지하도록 수정했다. 실행 직후 창 응답 확인과 사용자의 현재 창/장시간 실행 안정성은 구분한다.
