# 낮은 통과 자세와 작은 접지 반응 (2026-11-24)

최신 얼굴 보완은 [FACE-R1](../identity/README.md). 아래 네 무릎 보완 원본을 보존하고 실제 로더에서는 같은 머리를 적용한 identity/refinement 사본을 쓴다. F10 두 경로 모두 얼굴은 공유하며 무릎·접지 피드백만 비교한다.

- 사용자 평가: D 동작은 많이 좋아졌으나 3번째 자세의 무릎이 너무 높다. 약한 쥬시 요청. 이번 수정에 대한 최종 사용자 평가는 아직 없다.
- 기존 GAME_JUICE/MOTION_RULES/ART_FEEDBACK를 참고하여 원화의 무릎 높이를 먼저 고치고 접지 순간의 작은 피드백을 붙였다. [작업 계획](../../../../../docs/plans/2026-11-24_보행_무릎높이와_접지리듬.md).
- built-in image_gen으로 일반/조준 3·7번째의 들린 다리만 낮췄다. 생성 원본과 정확한 요청은 `passing_edit_input.png`, `passing_edit_output.png`, `prompt.txt`. `tools/sprites/refine_pistol_passing.py`가 공통 배율/하나의 바닥 기준으로 샘플링하고 원본 상체0~39행과 지지 부츠 영역(22,51)-(33,59)을 마스크 복원했다. 나머지12키/지지 발/보폭/위상·속도는 유지한다. 원본 시트 보존, 팔다리 회전/전신 늘이기 없음.
- D에서 수정 후가 기본. **F10**으로 이전 높은 무릎+기존 거리 발소리 / 낮춘 무릎+접지 발소리·작은 입자를 비교한다. 위치/체력/탄약/보행 위상 유지. F8 A/B/C/D, F9 적 정지/재개는 그대로.
- 기존32world 거리 소리는 수정 D에서만 끄고, 보행의0/.5 경계에서 접지 소리를 한 번 재생한다. 음량 .20(은신 .08), 기존 소음/감지 규칙은 건드리지 않는다. 카메라 발걸음 흔들림/추가 히트스톱/이동속도 변경 없음.
- 시각 쥬시는 기존 `dodge_fx.Dust`를 재사용한 `step` 종류: 수명 .10초, 저명도1px 입자2개, 도달거리1~3world. 구르기 효과는 기존 크기/색 유지한다. 새 먼지 그림을 만들거나 큰 연출로 다리를 가리지 않는다. 은신은 입자를 생략한다.
- `runtime_check.json`: 네 원화의 지지/상체 픽셀 보존·들린 다리 낮아짐, 실제 접지당 소리1회, 정지/차단/정지 시계 중 중복 금지, 한 주기2접촉, F10 상태 유지, 입자 규모 검사 통과. 기존 D 실사격·탄약·보행 검사와 C 회귀 검사도 통과.
- 시각 검수: `passing_comparison.png`, 실제 게임 `game_comparison.gif`. 발 미끄러짐 완전 제거, 기존 다른 방향/구르기/줍기/총 분리의 완료를 뜻하지 않는다. 실제 소리의 선호와 입자의 강도는 사용자 플레이 평가로 조정한다.
