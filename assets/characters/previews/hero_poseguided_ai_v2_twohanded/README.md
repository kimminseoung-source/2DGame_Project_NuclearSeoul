# 양손 검 대각선 준비 자세 · 걷기 보완

2026-11-23. 사용자 요청: 걷기를 더 자연스럽게 만들고 첨부 빨간 선처럼 양손으로 검을 오른쪽 위로 들기.

## 반영

- 검을 허리/배 앞에서 양손으로 같은 손잡이에 위아래로 붙여 잡는다. 칼날은 약 45도 오른쪽 위이며 머리 위로 치켜든 자세가 아니다. 사용자 첨부는 `user_sword_direction.png`에 보존했다.
- 3D는 하체 자세 안내에만 사용했다. 원본 MPFB/Walking에서 8시점의 실제 관절을 뽑은 `pose_joints.json`은 수정하지 않았다.
- `designed_pose_joints.json`, `twohand_guide.png`: 기존 걷기 하체에 새 양손/검 위치와 안정된 머리/어깨 안내를 결합했다. **상체 팔 위치는 이 시험에서 설계한 2D 관절 안내**이며 원본 3D 관절 그대로 또는 IK를 푼 실제 리깅 결과라고 보지 않는다.
- 내장 image_gen에 승인된 외형, 새 안내, 사용자 첨부를 함께 제공했다. 원본 `generated_walk.png`, 전체 문안 `prompt.txt`. 최종 모습은 AI 그림이다.
- 8시점은 통과/디딤 연결을 추가로 안내하려는 것이며 장수만 늘린 것이 아니다. 상체/손잡이/검 방향과 크기를 유지하도록 함께 요청했다.

## 결과 파일

- `comparison.gif`: 왼쪽 이전 한손 6프레임, 오른쪽 새 양손 8프레임. 두 버전 모두 한 주기 600ms로 같은 속도에서 비교한다. GIF의 10ms 시간 단위를 고려해 실제 저장된 주기를 검사했다.
- `comparison.png`: 첫 프레임 비교.
- `walk.gif`: 새 양손 버전만 확대 재생. `walk_slow.gif`: 1200ms 느린 검토.
- `walk_0.png` … `walk_7.png`: 64×64 RGBA, 첫 자세 높이 36px 기준의 공통 축소 배율, 가로 셀 중심과 발바닥 행 58. 8장 모두 캔버스 가장자리에 닿지 않는다. 수치는 `validation.json`.
- 생성된 그림을 코드로 늘리거나 팔다리를 회전시키지 않았다. 알파 128로 가장자리를 정리하고 동일 배율 축소/발 기준 정렬을 수행했다.

## 관찰과 남은 문제

- 두 손과 검의 대각선 준비 자세가 작은 화면에서도 구분된다. 이전 팔 흔들기 대신 양손으로 지지하는 상체를 사용했다. 원본 생성 결과에서도 8장 모두 두 손이 같은 손잡이 근처에 모이고 칼날이 위를 향한다.
- 머리/어깨/검 방향은 앞선 한손 버전보다 일정하게 보이지만 AI가 동일한 픽셀이나 관절을 강제 유지하는 방식은 아니다. 다리가 겹치는 구간의 발 모양과 가림 관계, 미세한 머리/검 크기 차이가 남는다. 완성된 걷기 또는 발 접지가 검증된 결과라고 보지 않는다.
- 위아래 전용 방향/공격/피격/쓰러짐과 게임 적용은 이번에 하지 않았다. 기존 게임 및 AI 자산은 보존했다. 사용자의 새 자세 확인 후 같은 방향에서 어색한 발 연결을 먼저 다듬는 것이 다음 순서다.
