# 붉은 재킷 · 걷기와 검 베기 1차

2026-11-23. 사용자: 새 외형이 괜찮으며 걷기와 공격 모션을 추가하자.

## 플레이

이전과 같은 `tools/새_주인공_플레이.cmd` 실행. 또는 프로젝트 루트에서:

```powershell
.venv\Scripts\python.exe tools\run_redjacket_trial.py
```

`--spitter`를 덧붙이면 원거리 피폭체 시험장이다. WASD 이동, 좌클릭 누르기/놓기 준비/공격, Space 회피, R 재시작, Esc 종료. 다른 무기는 검이 포함된 그림과 맞지 않아 이 실행에서만 줍기를 제외한다. 기본 실행과 기존 주인공 자산은 보존했다.

## 이번 변경

- 내장 image_gen으로 새 자세 9장 생성: 걷기 6장, 준비/베기/회복 각 1장. 원본 `generated_motion.png`, 요청 `prompt.txt`.
- 같은 축소 배율을 새 9자세에 적용하고 64×64 RGBA 칸에 정렬했다. 걷기 첫 자세 높이 36px 기준이다. 세로는 발바닥을 기준점 (32,58)에 맞추고, 가로는 원본 셀의 공통 몸 중심을 쓴다. 검이 큰 프레임의 bbox 중심으로 인물을 다시 정렬하지 않는다.
- 준비 자세의 칼 위쪽 여백을 보존하기 위해 원본 그리드 윗부분 32px를 포함해 잘랐다. 작은 떨어진 생성 찌꺼기를 제거했다. 본체를 코드로 그리거나 늘여 동작을 만들지 않았다.
- 기존 대기/준비 원본도 이전 폴더에 보존하고 새 패키지에 기준점을 맞춰 정리했다. 프레임별 자동 크기 맞춤은 하지 않았다. 측정은 `validation.json`.
- `tools/run_redjacket_trial.py`: 실제 좌표 변화량으로 걷기 주기를 진행한다. 기본 보행은 한 주기 64 world units, 6자세. 멈춤/벽에 막힘에서는 프레임이 진행되지 않는다. 조준 이동은 검을 낮춘 걷기 그림을 공유하며 멈춰 준비하면 들어 올린 자세를 사용한다.
- 공격은 기존 `hit_at` 전에 준비 자세, 접촉 순간 베기 자세, 남은 회복 구간의 앞 38% 동안 베기 자세 유지, 이후 회복 자세를 쓴다. 기존 피해·충전·공격 취소·효과 수치는 유지한다.

## 확인과 제한

- `tools/checks/check_redjacket_motion.py` 통과: 실제 이동 중 6프레임, 정지·벽 막힘, 일반/충전 베기의 실제 적 체력 감소와 접촉 프레임, 회피, 피격, 재시작.
- `game_motion.gif`: 실제 게임 렌더로 이동→정지→준비→베기→회복→반대쪽 이동 300프레임을 기록했다. `walk.gif`, `attack.gif`는 확대된 키 이미지 검토용이며 게임에서의 공격 시간은 실제 무기 시간에 따른다. 공격 캡처 `game_impact.png`, 전체 자세 `motion_board.png`.
- 아직 한 방향+좌우 반전이다. 위아래 전용 그림, 실제 구르기·피격·쓰러짐 중간 그림, 무기 레이어 분리는 미완성이다. 회피는 기존 잔상 방식, 피격·사망은 대기 그림을 임시 사용한다.
- AI 자세마다 머리/어깨·다리 모양에 작은 차이가 있어 걷기에서 약간 흔들린다. 이동 거리 동기화는 발 고정 역학이나 모션 캡처를 의미하지 않으며 미끄러짐이 완전히 사라졌다고 보지 않는다. 8방향 확장 전 이 일관성을 더 다듬어야 한다.
- 검 그림은 비스듬히 앞으로 내려베기 한 방향이며 실제 판정/궤적 효과는 마우스 방향을 따른다. 위아래 조준에서 그림의 방향까지 맞는 상태는 아니다.
- 커밋·푸시는 하지 않았다. 기존 미커밋 작업과 원거리 피폭체는 보존했다.
