# 권총 C · 전신 보행과 동작 흐름 보완

2026-11-23. 사용자: A의 정지 조준은 힘 있고 좋다. 이동은 자연스러워야 하며 전체 동작의 어색함을 제작자가 판단해서 다듬는다.

## 직접 플레이

`tools/권총_동작흐름_플레이.cmd`, 또는 프로젝트 루트에서 `.venv\Scripts\python.exe tools\run_pistol_comparison.py` 실행. 기존 A/B 비교 실행도 같은 파일이므로 **현재는 C로 시작**한다.

- F8: A(처음 넓은 두 자세) → B(상하체 합성) → C(이번 전신 동작) 순서로 전환. 위치/체력/탄약은 유지한다.
- F9: 적 정지/재개. 처음은 적이 멈춰 있으며 일반/원거리 피폭체가 있다.
- WASD 이동, 좌클릭 누르기 조준/놓기 발사, Space 회피, R 재시작, Esc 종료. 시험용 탄60, 재장전 기능은 아니다.

## 바꾼 것

- 다른 원화 하체를 허리에서 잘라 붙이지 않고, **전신 그림으로** 일반 걷기4/짧은 조준 걷기4를 사용한다. 실제 이동량으로 같은 걸음 위상을 진행하고 조준 전환 때 위상을 초기화하지 않는다. 뒤로 걸으면 위상을 역방향으로 진행한다.
- 대기/중간 올리기/힘 있는 정지 조준/반동/멈춰 자리 잡기/피격/넘어짐/누운 자세 각1장, 총 전신 키16장을 정리했다.
- 정지에서 팔 올리기/내리기는 약0.12초, 조준 이동을 멈추면 약0.09초 자리 잡기를 거쳐 넓게 버티는 조준으로 간다. 현재는 중간1장을 이용한 전환이며 영상처럼 연속 보간한 팔 동작은 아니다.
- 발사 판정이 발생한 뒤에 반동 키를 보여주고 약0.11초 유지한다. 기존 카메라 반응/소리와 총구의 트레이서/작은 효과를 연결했다. 피격은 hurt, 사망은 fall→down으로 바꿨다.
- 조준 이동 때 몸이 이동 방향으로 뒤집히던 것을 C에서 조준 방향을 유지하도록 수정했다. 좌우 자세만 있으므로 위아래 전용 방향이 완성됐다는 뜻은 아니다.
- 회색 총몸 끝 픽셀 후보로 자세별 총구점을 얻어 게임 렌더와 대조했다(`muzzles.json`). C의 조준선은 해당 자세 총구, 발사선/명중은 반동 키 총구에서 커서 쪽으로 시작한다. A/B는 원래 비교 동작을 보존한다. 피해/사거리/탄약/소리 수치는 같지만 C의 출발점은 보정된 것이므로 외형만 다르고 모든 기하가 완전히 동일하다는 주장은 하지 않는다.

## 제작/선택

- 내장 image_gen, 요청 전체 `prompts.txt`. 원본 `generated_keys.png`, `generated_walk_8.png`.
- 첫 12보행 출력은 발 교대가 모호해서 채택하지 않았다(`rejected_walk_12.png`). 두 번째는 접지/통과/반대 접지/반대 통과의 4핵심 자세씩으로 좁혀 제작했다. 장수만 채우기 위해 실패 출력을 쓰지 않았다.
- `motion_guide.json/png`: 기존 MPFB 걷기 관절 투영을 바탕으로 팔과 짧은 보폭을 설계한 안내. `four_key_guide.png`는 재시도용으로 직접 설계한 접지/통과 안내이며, 새로운 3D IK/모션 캡처를 푼 결과가 아니다. 최종 캐릭터 그림은 AI가 생성했다.
- 공통 가상셀512, 하나의 배율/지면 기준으로 64×64에 배치했다. 프레임마다 몸 높이나 bbox 바닥을 맞춰 움직임을 숨기지 않았다. 쓰러짐 원본은 셀 경계 밖으로 넘어간 부분까지 포함해 여백을 확장한 뒤 같은 픽셀 밀도로 처리했고 떨어진 이웃 셀 찌꺼기만 제거했다.
- **이번 C는 동작 품질 검토용으로 총이 전신 그림에 포함돼 있다.** 기존 B의 무기 분리 구조와 원본은 보존했다. 최종 몸/총 분리 목표가 완료된 것은 아니며 C를 여러 총/파츠 공용 자산으로 세지 않는다.

## 검증과 실제 한계

- `tools/checks/check_pistol_flow.py`: 실제 게임에서 일반/조준 보행4키, 정지 올리기, 멈춤 자리 잡기, 실제 명중/탄1발 차감과 반동, 피격/넘어짐/사망, 재시작과 A/B/C 상태 보존 확인. 결과 `runtime_check.json`.
- 게임300프레임 시퀀스 `game_flow.gif`, 화면 `game_flow.png`. 전신4키 비교 `motion_preview.gif`, `motion_board.png`. PNG16장 비어 있지 않음/최종 캔버스 경계 접촉 없음.
- **접지 완성은 아님:** 손으로 추정한 오른발 중심을 실제 이동과 함께 1/60초마다 기록했다(`foot_audit.json`). 접지 후보 자세를 붙잡는 동안 최대 약6.52 canvas px의 이동이 남는다. 네 장을 표시하는 동안 발 픽셀이 완전히 고정되는 연속 리깅이 아니므로 발 미끄러짐이 남는다. 이 수치는 해부학적 접지 구간 전체나 원근을 정확히 복원한 자동 검증이 아니다.
- AI 머리/팔/무기/몸 폭에 작은 프레임 차이가 있다. 조준 걷기는 짧고 낮은 자세라 정지 조준보다 몸 높이가 작다. 다른 프레임을 자동 확대해 이를 숨기지 않았다.
- 전용 구르기/줍기 그림은 아직 없다. 회피는 자리잡기 그림+기존 잔상, 줍기는 현재 자세의 임시 표현이다. 사망은 새 그림을 쓰지만 중간 넘어짐은1장이라 추가 연결 여지가 있다. 8방향/재장전/총 파츠도 이번 범위 밖이다.
- 따라서 전체 동작이 완성됐거나 어색함이 없다고 보고하지 않는다. C는 합성 이음새/상태 전환/반동·피격 누락을 보완한 비교판이며 발 접지와 방향 확장은 남았다.
