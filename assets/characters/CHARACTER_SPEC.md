# 기본형 캐릭터 제작 규격

작성 2026-11-10. 사용자 지시: "캐릭터를 제일 기본형을 만들고, 거기서 변형해서 다양하게 만들 수 있도록" ([개발 계획](../../PLAN.md) 사용자 지시 기록). 기본 몸 하나를 처음부터 새로 그리고, 옷·머리·등 소품·무기를 **갈아 끼우는 레이어**와 **색 바꾸기**로 주인공·동료·생존자·적대 생존자를 만든다. 1차 발표의 노란 방호복 주인공도 이 방식의 첫 변형으로 다시 만든다.

## 1. 칸과 기준점

| 항목 | 값 |
| --- | --- |
| 한 칸 크기 | **96 × 64 px** (방망이 휘두르기까지 들어가는 너비) |
| 바라보는 방향 | **오른쪽만** 그린다. 왼쪽은 게임에서 좌우 반전 |
| 발 기준점 | 칸 왼쪽에서 **x = 48**, 위에서 **y = 60** (두 발이 닿는 바닥선) |
| 캐릭터 키 | 바닥선에서 머리 끝까지 **약 54 px** (머리 끝 y = 6). 지금 주인공(58px 칸)과 비슷한 크기 |
| 몸 중심선 | x = 48. 서 있는 자세에서 몸통 중심을 이 선에 맞춘다 |
| 배경 | 투명. 그림자·글자·격자 없음 |
| 시트 | 동작마다 한 줄 가로 시트, 칸은 왼쪽부터 재생 순서 |

## 2. 동작 목록

| 동작 | 파일 이름 | 칸 수 | 쓰임 |
| --- | --- | --- | --- |
| 대기 | `idle` | 4 | 숨 쉬듯 살짝 오르내림 |
| 걷기 | `walk` | 8 | 탐색·전투 이동, 대시는 걷기를 빠르게 재생 |
| 조용히 걷기 | `sneak` | 6 | 몸을 낮추고 기울인 걷기 |
| 휘두르기 | `swing` | 6 | 준비 2 · 타격 2 · 마무리 2. 무기 레이어가 바뀌어도 같은 동작 |
| 피격 | `hurt` | 3 | 뒤로 움찔 |
| 쓰러짐 | `down` | 5 | 무너져 바닥에 누움, 마지막 칸 유지 |
| 줍기 | `pickup` | 4 | 무릎 꿇고 손을 바닥에 |

## 3. 레이어 (아래에서 위 순서)

| 순서 | 레이어 | 폴더 | 예시 |
| --- | --- | --- | --- |
| 1 | 등 소품 | `parts/back/<이름>/` | 공기통, 배낭, 구급가방 |
| 2 | **기본 몸** | `base/` | 피부, 얼굴, 기본 속옷, 체형 |
| 3 | 하의·신발 | `parts/legs/<이름>/` | 방호복 하의, 작업 바지, 부츠 |
| 4 | 상의 | `parts/torso/<이름>/` | 방호복 상의, 점퍼, 의사 가운 |
| 5 | 머리 | `parts/head/<이름>/` | 후드+방독면, 헬멧, 머리카락, 모자 |
| 6 | 손 무기 | `parts/weapon/<이름>/` | 방망이, 쇠파이프, 렌치 (쥔 손가락 포함) |

- 각 레이어는 **기본 몸과 같은 칸·같은 동작 파일 이름**으로 그린다. 예: `parts/torso/hazmat/walk.png`는 `base/walk.png`와 칸마다 정확히 겹친다.
- 레이어가 없는 동작은 비워 둔다(예: 쓰러짐에서 등 소품이 바닥에 깔리면 그 칸만 다르게).
- 무기가 몸 뒤로 가는 칸은 무기 레이어에서 가려지는 부분을 지워서 표현한다.

## 4. 색과 색 바꾸기

- 외곽선은 짙은 남색 계열 한 색, 명암은 색마다 3~4단계로 맞춘다.
- 색 바꾸기를 쉽게 하려고, 옷 레이어의 **주색·보조색 명암 단계**를 정해진 기준색으로 칠한다. 게임은 이 기준색을 다른 색표로 바꿔 같은 옷을 다른 색으로 만든다(예: 노란 방호복 → 주황·회색 방호복).
- 기준색 표는 기본 몸을 그린 뒤 실제 사용 색에서 뽑아 이 문서에 추가한다.

## 5. 폴더

```
assets/characters/
  CHARACTER_SPEC.md        이 문서
  templates/<동작>.png     칸·바닥선·중심선·머리 높이를 표시한 안내 시트 (그릴 때 아래 레이어로 깔기)
  templates/preview.png    모든 템플릿을 4배로 확대한 미리보기
  base/<동작>.png          기본 몸
  parts/<레이어>/<이름>/<동작>.png
```

## 6. 그리는 순서 (제안)

1. Pixelorama에서 `templates/<동작>.png`를 열고 그 위에 새 레이어를 만들어 기본 몸을 그린다. 대기 → 걷기 → 휘두르기 → 피격 → 쓰러짐 → 조용히 걷기 → 줍기 순서(전투에 필요한 것 먼저).
2. 기본 몸 시트를 게임에 넣어 크기·발 위치·재생 속도를 확인한다.
3. 1차 발표의 주인공 모습(노란 방호복, 후드와 방독면, 공기통, 쇠파이프/방망이)을 레이어로 만든다.
4. 동료·생존자는 레이어 조합과 색 바꾸기로 만든다.

이미지 생성 도구로 초안을 만들 때도 이 칸 크기와 기준점에 맞춰 정리한 뒤 사용한다.
