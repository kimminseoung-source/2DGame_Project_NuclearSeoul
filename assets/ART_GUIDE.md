# 「부산까지」 도트 리소스 제작 가이드

새 리소스를 만들거나 기존 리소스를 교체하기 전에 아래 제작 양식을 채운다. 먼저 게임에 들어간 기준 이미지를 고르고, 새 결과를 같은 화면과 같은 크기에서 비교한다.

## 리소스별 기준

| 종류 | 기준 | 확인할 점 |
| --- | --- | --- |
| 주인공 | [기존 캐릭터](survivor_walk.png)와 [6프레임 걷기 시트](survivor_walk_6frames.png) | 황토색 후드, 청록색 렌즈, 올리브색 배낭, 짙은 회색 장비와 어두운 외곽선. 동작과 방향이 바뀌어도 장비의 모양과 색을 맞춘다. |
| NPC | 주인공과 같은 탑뷰 각도, 도트 밀도, 명암 단계 | 체격, 옷, 소지품으로 역할을 구분한다. 관계 표시는 게임 UI에서 따로 그린다. |
| 바닥 아이템과 HUD 아이콘 | 현재 [필터 표시](../src/item_ui.py)와 같은 화면에서 비교 | 바닥용과 HUD용 표시 크기를 따로 정한다. 두 곳에서 같은 아이템으로 알아볼 수 있도록 핵심 실루엣을 공유한다. |
| 배경과 소품 | [시작 방공호](shelter.png)의 탑뷰 각도와 낮은 채도 | 바닥, 벽, 통과할 수 있는 문이 구분돼야 한다. 장식이 캐릭터와 상호작용 표식을 가리지 않는지 확인한다. |

## 새 리소스 제작 양식

다음 항목을 제작 요청이나 리소스 기록에 복사해서 채운다.

```text
이름과 종류
게임에서 쓰이는 장소와 상황
기준 이미지 파일과 맞출 요소
새 리소스에서 바꿀 요소
카메라 각도, 팔레트, 외곽선, 도트 밀도
투명 배경 여부, 파일명, 원본 크기, 게임 표시 크기
애니메이션이면 방향 순서, 프레임 수, 동작 순서, 반복 시간, 기준점
제작 도구와 최종 프롬프트 또는 원본 출처와 이용 조건
게임에서 확인한 항목과 수정할 점
```

기존 이미지와 같은 캐릭터를 만들 때는 기준 PNG를 제작 요청에 함께 넣는다. 색상과 장비 같은 고정 요소와 새 자세처럼 바꿀 요소를 각각 적는다. 캐릭터의 방향 순서, 칸 크기와 발 기준점은 [애니메이션 가이드](ANIMATION_GUIDE.md)를 따른다.

## 적용 전 확인

- [ ] 기준 이미지와 나란히 놓고 색상, 각도, 비율, 도트 크기를 비교했다.
- [ ] 실제 게임 크기에서 캐릭터, 아이템, 출입구를 알아볼 수 있다.
- [ ] 투명 PNG의 테두리에 배경색이 남거나 일부가 잘리지 않는다.
- [ ] 애니메이션은 동작과 방향을 바꿔도 발 기준점이 튀지 않는다. 반복 재생으로 프레임 순서와 연결을 확인했다.
- [ ] 배경과 소품의 그림이 실제 충돌 범위와 맞는다.
- [ ] 적용한 파일과 제작 기록을 저장소에 두고, 게임에서는 프로젝트 기준 경로로 불러온다.
