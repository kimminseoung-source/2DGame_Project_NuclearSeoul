# 할 일 (차례대로, 2026-11-17)

사용자 지시: "해야 할 것에 추가하고 차례대로 진행하세요". 위에서부터 하나씩, 작게 해 보고 보여 준다.

1. **배낭 다시 만들기** (사용자 "배낭, 인벤토리 다 많이 손봐야 함, 커서로 정리할 수 있게, 잘했다는 말이 나오게")
   - 무게 계산 없애고 칸 수만 (이미 승인)
   - 물건마다 자리를 기억: 마우스로 끌어서 원하는 칸에 놓기, 놓을 수 있으면 초록·없으면 빨강 미리보기
   - R(또는 끄는 중 우클릭)로 90도 돌리기
   - 같은 물건 겹치기(붕대 x3을 한 칸에), 올리면 이름·설명 표시
   - 손 칸으로 끌어서 무기 들기, 바닥으로 끌어서 버리기, 두 번 클릭으로 쓰기
   - "정리" 버튼: 자동으로 빈틈없이 정렬
   - 지금 코드: `src/bag_grid.py`(무게로 칸 수를 정하고 매번 자동 배치), `src/bag_screen.py`(키·마우스), `src/hud.py`(그리기)
2. **정리(승인됨):** 근접 무기 5종 → 2종(빠른 칼, 느린 둔기), 상처 3종 → 출혈 하나, 통조림은 체력 회복
3. **낮과 밤, 손전등**
4. **피폭체가 어둠 속에서 희미하게 빛남**
5. **피폭체 종류:** 방호복 작업자, 군인, 시민
6. **총 다듬기** (사용자 "총 요소로 전투가 훨씬 재미있어짐, 추후에 더 수정") — 총 쏘는 동작, 녹음된 총소리

답을 기다리는 제안: 부위 조준 줄이기, 스테이지 5개와 부산 디펜스, 방사능 측정기, 새 기둥 3개.
