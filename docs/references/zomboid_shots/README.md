# 좀보이드 참고 자료 넣는 곳

여기에 넣은 이미지는 저장소에 올라가지 않는다(.gitignore). 상용 게임 화면이라 공부용으로만 쓰고, 우리 게임에는 직접 쓰지 않는다.

## 넣는 방법
- **스크린샷**: 파일 이름에 무엇을 보라는지 짧게 적는다. 예: `ui_인벤토리.png`, `전투_좀비떼.png`, `조명_밤거리.png`
- **한 줄 메모**: 같은 이름의 .txt 또는 아래 표에 "무엇이 좋은지" 한 줄. 예: "가방 칸이 무게로 나뉘는 게 좋음"
- **영상**: 유튜브 링크 + 시각(예: 3:20)을 아래 표에 적는다. Claude가 그 장면을 브라우저에서 멈춰 캡처해 본다(소리는 들을 수 없음).
