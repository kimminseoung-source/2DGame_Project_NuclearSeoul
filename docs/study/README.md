**웹 개발 일지:** https://claude.ai/artifact/5NjFEUrpcB5qCqmPnXnxg5 (비공개, 원본은 `docs/devlog/index.html`)

개발하면서 만난 기법을 개발 일지(devlog)처럼 한 편씩 남긴다. 사용자 요청(2026-11-18): "왜 그렇게 했는지 이해하면서 진행하고 싶다", "유튜브 개발 과정 영상처럼, 1~7번 나열은 눈에 잘 안 들어온다".
