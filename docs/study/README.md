# 공부 노트

사용자 요청(2026-11-18): "개발을 할 때 왜 그렇게 하였는지 이해하면서 진행하고 싶습니다. 어떠한 선택지들이 있고, 어떤 기법들이 있고, 최적화를 어떻게 하였고, 어떤 것들을 고려하면서 했는지 공유".

큰 기능을 만들 때마다 한 장씩 쓴다. 모든 노트는 같은 순서를 따른다.

1. **문제:** 무엇이 왜 안 됐나
2. **선택지:** 가능한 방법들과 장단점
3. **고른 것과 이유**
4. **기법 이름:** 다른 게임·자료에서 찾아볼 때 쓰는 이름
5. **고려한 것**
6. **최적화:** 얼마나 무거운지, 어떻게 가볍게 했나
7. **코드 위치:** 파일과 함수
8. **한계와 다음**
