# 00. 공부 지도: 「부산까지」 안에 들어 있는 것들

게임 하나에는 생각보다 많은 "기법"이 숨어 있다. 우리 게임에 이미 들어 있는 것과, 앞으로 만나게 될 것을 한 장에 모았다. 굵은 것부터 보면 된다.

## ★ 꼭 알아야 할 다섯 가지

### 1. 게임 루프와 dt
게임은 1초에 60번 "입력 받기 → 세상 움직이기 → 그리기"를 반복한다. 컴퓨터마다 속도가 달라서, 움직임은 **지난 프레임에서 흐른 시간(dt)** 을 곱해 계산한다. 그래야 빠른 컴퓨터에서 피폭체가 빨라지지 않는다.
- 우리 게임: `src/main.py`의 반복문, `play.update(dt)`
- 응용: 개발 설정창의 "게임 속도"는 dt에 배수를 곱하는 것뿐이다

### 2. 상태 기계 (FSM)
피폭체는 "대기 → 경계 → 찾기 → 추격 → 공격 준비 → 공격 → 회복" 중 한 상태에 있고, 조건이 맞으면 다음 상태로 넘어간다. 게임 AI의 가장 기본 뼈대다.
- 우리 게임: `src/infected.py` `Zombie.update`의 `self.state`. 할퀴기 부채꼴이 진해지는 순간(F1)이 "공격 준비" 상태다
- 다음에 만날 것: 행동 트리(Behavior Tree). 군인처럼 할 일이 많아지면 비교해 본다

### 3. 감각: 보고 듣기
AI가 "무엇을 아는가"를 정하는 부분이다. 시야 부채꼴 안에 들어오고 벽에 가리지 않으면 본다. 소리 원 안에 있으면 듣는다. 놓치면 마지막 위치를 8초 기억한다.
- 우리 게임: `infected.sees`, `infected.hear`, `play.make_noise`. F5(시야)·F6(소리)로 눈에 보인다
- 2026-11-18 결정: 시야는 늘 140으로 같고, 살금 걷기는 **발소리만** 줄인다. 규칙이 하나 줄어서 이해하기 쉽다

### 4. 충돌과 공간 나누기
피폭체 9마리가 벽 수백 개와 매 프레임 부딪히는지 다 비교하면 느리다. 맵을 128칸 격자로 나눠서 **근처 칸의 벽만** 본다.
- 우리 게임: `src/area.py` `near_blocks`(버킷), `move_body`(한 축씩 미끄러지기), `kept_out`(역 울타리)
- 이름: 공간 분할(Spatial partitioning), 그중 균일 격자(Uniform grid)

### 5. 길 찾기
벽을 돌아서 목표까지 가는 길이다. 맵을 32 단위 격자로 보고, 목표에서부터 퍼져 나가며 칸마다 "목표까지 몇 걸음"을 적는다(BFS). 피폭체는 걸음 수가 줄어드는 칸으로 간다.
- 우리 게임: `src/area.py` `waypoint`
- 다음에 만날 것: A\*(목표 하나를 빨리 찾음), 흐름장(Flow field: 많은 적이 같은 곳으로 갈 때 강함). 디펜스처럼 다 같이 역으로 오는 상황은 흐름장이 어울린다

## 그 밖에 들어 있는 것

| 기법 | 한 줄 | 우리 게임 |
|---|---|---|
| 타격감 (Game feel) | 맞는 순간 화면을 아주 잠깐 멈추고(히트스톱) 흔든다(셰이크) | `play.update`의 `hitstop`, `shake` |
| 예고 (Telegraph) | 공격 전에 "!"와 자세로 미리 알려 피할 기회를 준다 | 피폭체 `windup` 상태 |
| 데이터로 정하기 (Data-driven) | 무기·사람 종류를 코드가 아니라 표 한 줄로 늘린다 | `weapons.WEAPONS`, `survivors.KINDS`, `dev_tools.ROWS` |
| 적 생성 관리 (AI 디렉터) | 언제, 어디서, 몇 마리를 내보낼지 조절한다 | `play.spawn`, 소리가 부르는 입구, 디펜스 중 몰려오기 |
| 표적 고르기 | 누구를 노릴지 정한다 | `play.prey_for` (가장 가까운 사람) |
| 출입 금지 구역 | 특정 무리만 못 들어가는 영역 | 역 울타리 → [01](01_역_울타리.md) |
| 픽셀 캔버스 | 작은 캔버스에 그린 뒤 정수 배로 키워 도트가 고르게 보인다 | `play.draw_canvas` (선이 픽셀 사이로 사라지는 문제도 여기서 생김) |
| 디버그 도구 | 안 보이는 규칙을 화면에 그린다 | F1 히트박스, F5 시야, F6 소리, F4 설정창 |

## 앞으로 만날 것

- 군인·시민 행동: 상태 기계 vs 행동 트리 vs 유틸리티 AI(점수로 행동 고르기)
- 무리 움직임(Steering, Boids): 피폭체가 한 줄로 겹치지 않고 퍼져서 오게
- 낮과 밤, 손전등: 빛과 그림자(지금 시야 원뿔의 확장)
- 저장과 구역 넘어가기: 배낭·체력을 다음 구역으로 넘기는 방법
