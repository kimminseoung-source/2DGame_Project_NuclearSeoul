# 참고 자료로 할 수 있는 작업 목록

작성 2026-11-13. [제작 도구와 참고 자료](PRODUCTION_REFERENCES.md)를 보고 Claude가 직접 할 수 있는 작업을 모았다.
사용자 요청: "저기 사이트를 이용해서 다른 것들을 보고 배워서 너가 작업할 수 있나요?" → "리스트로 만들어 볼까요? 뭘 할 수 있는지?"

- **크기**: 소(한 번에 끝남) · 중(반나절) · 대(여러 번 나눠서)
- **필요한 것**: 사용자 허락(내려받기), 사용자 확인(소리 듣기·그림 보기) 등 Claude 혼자 끝낼 수 없는 부분
- 모든 작업은 공통 규칙으로 만든다(다른 무기·적에도 그대로 적용). 남의 그림·코드는 베끼지 않고 원리만 가져온다.

## 추천 순서

1. **A1 → A2** 효과음 합성과 타격별 소리: 내려받기 없이 바로 시작, 손맛 차이가 가장 큼
2. **B1** 흰색 번쩍: 작고 효과 큼
3. **D1** 한글 도트 글꼴: 허락만 받으면 금방
4. **C1** 들키는 거리 원: 은신 플레이가 쉬워짐
5. 그다음은 방향 결정(어둠 + 손전등 여부)에 따라 C3 또는 D4
