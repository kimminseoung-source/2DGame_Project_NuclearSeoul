## 추천 순서

1. **A1 → A2** 효과음 합성과 타격별 소리: 내려받기 없이 바로 시작, 손맛 차이가 가장 큼
2. **B1** 흰색 번쩍: 작고 효과 큼
3. **D1** 한글 도트 글꼴: 허락만 받으면 금방
4. **C1** 들키는 거리 원: 은신 플레이가 쉬워짐
5. 그다음은 방향 결정(어둠 + 손전등 여부)에 따라 C3 또는 D4
