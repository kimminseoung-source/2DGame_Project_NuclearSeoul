# 우리 게임에 무엇을 어떻게 적용하면 재미있나 (2026-11-16)

사용자: "그래서 내 게임에 무엇을 어떻게 적용하는 게 게임적 재미가 있을까까지 조사해서 나한테 보고하세요. 지금 여러 작업들을 주고 있는데 차례대로 잘 정리해서 순서대로 진행하세요."
재료: 좀보이드 커뮤니티 조사(재미·단점), 좀보이드 규칙 분석(REA), 동작 조사, 추가 조사(욕심 vs 위험 구조, Darkwood의 공포, 근접 전투 반응). 기준은 DESIGN_LOCK 기둥 1(빈틈을 노리면 한 방에 끝나는 긴장감 있는 칼싸움)과 "흔한 건 싫어".

## 1. 결론 한 줄

**우리 게임의 재미는 한 구역 안에서 세 가지 선택을 계속하게 만드는 데서 나온다.**
① 더 챙길까, 지금 나갈까(욕심 vs 탈출) ② 몰래 갈까, 맞붙을까(은신 vs 싸움) ③ 둘러싸이기 전에 어디에 설까(자리 잡기).
지금 게임에는 세 가지의 재료(물자·출구·사방 스폰, 시야·소리·조용한 처치, 밀치기·붙잡힘·구르기)가 이미 다 있다. **새 시스템을 늘리기보다, 이 세 선택이 눈에 보이고 대가가 분명하게 다듬는 것**이 가장 재미를 키운다.

## 2. 세 가지 선택과 적용 방법

### ① 욕심 vs 탈출 (가장 중요)
- **왜 재미있나:** "조금만 더"와 "지금 나가자" 사이의 줄다리기는 보드게임의 '운 시험하기'와 같은 구조다. 위험이 커질수록 보상도 커야 하고, 실패할 수 있지만 성공도 할 수 있어야 계속 도전한다. 좀보이드 공략의 "첫 집은 오래 뒤지지 말고 떠나라"도 같은 긴장이다.
- **지금:** 물자를 챙겨 지하철 입구로 가면 끝. 피폭체는 시간이 지나면 계속 온다. 그런데 **챙기는 게 필수 목표처럼 보여서 선택이 아니다.**
- **적용:**
  1. 출구는 처음부터 열려 있고, 물자는 **선택**("더 챙기면 다음 구역이 쉬워진다")으로 보이게 목표 문구를 바꾼다.
  2. 시간이 갈수록 스폰 간격이 줄고(지금 6~9초 → 끝에는 3~4초), 시끄러울수록 더 당겨진다(이미 있음).
  3. 좋은 물자일수록 **위험한 자리**(폐차 사이 좁은 길, 출구 반대편)에 둔다.
  4. 구역 요약에 "챙긴 것 · 걸린 시간 · 조용히 처리한 수"를 보여 줘 욕심낸 결과가 남게 한다.
  5. (다음 구역이 생기면) 챙긴 붕대·통조림이 **다음 구역으로 이어짐**(DESIGN_LOCK 정할 것 3·7과 연결).

### ② 은신 vs 싸움
- **왜 재미있나:** 맷집 변경(v6.0)으로 "못 본 피폭체는 한 방, 보고 덤비면 2~3번"이 되었다. 계획(몰래 접근)이 성공하면 깔끔하고, 실패하면 시끄러운 난전이 된다. 이 차이가 클수록 계획하는 재미가 생긴다.
- **적용:**
  1. **한 방이 가능한 순간을 알려 준다.** 마우스 커서(조준점)가 바뀌는 정도로만 알려 주고, 화면 글자는 늘리지 않는다(UI 개편 원칙).
  2. 조용한 처치는 소리가 작아 **다음 스폰을 당기지 않고**, 시끄러운 난전은 당긴다(이미 있음). 구역 요약에 조용히 처리한 수를 보여 준다.
  3. 정면 난전에서는 **밀치기 → 넘어뜨림 → 한 방**을 쓰는 게 이득이 되게 한다(이미 있음, 해 보고 숫자 조정).

### ③ 자리 잡기 (사방에서 오는 긴장)
- **왜 재미있나:** 사용자가 탑뷰를 고른 이유가 "사방에서 오는 긴장감"이다. 둘러싸이면 붙잡히고, 좁은 길에서는 한 방향만 상대한다. 어디에 서느냐가 실력이 된다.
- **적용:**
  1. **벽 밀치기:** 폐차·벽 쪽으로 밀친 피폭체는 반드시 넘어진다. 자리를 잘 잡으면 확실한 한 방이 된다.
  2. **좁은 길:** 폐차 사이 길목을 몇 군데 두어 "여기서 버티기" 선택을 만든다(구역 배치).
  3. 뒤·옆에서 오는 공격은 예고가 짧다(이미 있음). 등을 벽에 대는 판단이 생긴다.

## 3. 보이지 않는 공포 (세 선택을 강하게 하는 양념)
- Darkwood는 시야 원뿔 밖의 적을 숨기고, 소리로만 무언가 있음을 알린다. 무서움은 깜짝 놀라게 하기보다 "빈 공간을 머리가 채우는 것"에서 온다. 우리는 시야 원뿔과 폐차 가림이 이미 있다.
- **적용:** 시야 밖 피폭체의 신음·발소리를 **방향이 들리게**(왼쪽·오른쪽 음량) 낸다. 지금 소리는 "별로"이므로, 실제 녹음 기반 무료 소리(CC0)로 바꿀 때 함께.

## 4. 맞을 때 손맛 (동작 조사와 연결)
- 같은 반응만 반복하지 말고 **세기·방향에 따라 다르게**: 가벼운 베기 = 움찔, 센 베기·밀치기 = 비틀거림·넘어짐, 맞은 쪽 반대로 밀려남. 멈춤(히트스톱)·흔들림·피·소리를 함께.
- **적용:** 지금 움찔·비틀·넘어짐 세 단계가 생겼다. 다음은 그림: 앞에서 맞음 / 뒤에서 맞음 두 가지, 베기 A·B·C 번갈아(동작 조사 4절 우선순위 그대로).

## 5. 넣지 않는 것 (재미를 해치거나 기둥과 안 맞음)
| 좀보이드 요소 | 빼는 이유 |
|---|---|
| 배고픔·목마름·피로 | 짧은 구역 게임에서 관리만 늘고 선택은 안 늘어남 |
| 무기 내구도·제작·거점 짓기 | 좀보이드 단점 "중반 이후 반복"과 진입 장벽 |
| 긴 감염 타이머(며칠 뒤 죽음) | 구역 단위 즉시 재시작과 안 맞음. 피폭을 다시 켤 때 물림과 연결만 검토 |
| 부위별 부상 효과 | 몸 그림 표시로 충분(보류) |
| 상태 숫자·아이콘 늘리기 | 사용자 "긴장 공황 표시 별로", UI 개편 원칙 "느끼게" |
