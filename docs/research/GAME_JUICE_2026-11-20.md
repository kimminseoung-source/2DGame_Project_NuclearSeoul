# 전투 손맛(게임 쥬스) 조사 — 지금 있는 것과 더할 것 (2026-11-20)

사용자: "전투, 게임이 게임 쥬스가 있어야 해요. 이런 요소가 많이 있으면 좋겠습니다."

게임 쥬스(game juice): 입력 하나에 화면·소리·몸이 과하다 싶을 만큼 반응해서 "때리는 맛"이 나게 하는 작은 연출들. 규칙(판정·피해)은 그대로 두고 **느낌만** 키운다.

참고: Martin Jonasson·Petri Purho "Juice it or lose it"(GDC Europe 2012), Jan Willem Nijman(Vlambeer) "The art of screenshake"(2013), Steve Swink 《Game Feel》, 우리 조사 [MOTION_FEW_SPRITES](../planning/MOTION_FEW_SPRITES_2026-11-19.md).

## 지금 게임에 있는 것

| 요소 | 무엇 | 코드 |
|---|---|---|
| 히트스톱 | 맞는 순간 약하게 0.035초, 강하게 0.09초 멈춤 | `play.JOLTS`, `Game.jolt` |
| 화면 흔들림 | 약 1px·0.1초, 강 4px·0.25초 (매번 흔들면 무뎌져서 중요한 타격만 세게) | `JOLTS` |
| 맞은 적 하얗게 번쩍 | 2프레임 | `z.flash` |
| 베기 궤적 그림 | 휘두르는 쪽으로 초승달 | `slash_fx.SpriteFx("slash")` |
| 타격 효과 그림 | 맞은 자리 번쩍, 쓰러지면 큰 효과 | `SpriteFx("hit")`, `hit_big` |
| 피·불똥 | 바닥 핏자국, 불똥 | `stains`, `Spark` |
| 소리 | 휘두르기·맞기·구르기·줍기·헛손질 | `sound.Sounds` |
| 맞을 때 화면 가장자리 빨강, 기력 막대 깜빡 | | `hurt_flash`, `tired_flash` |
| 핵심 자세 3장 + 친 자세 붙잡기 | 준비 → 치기(붙잡기) → 회복 | `DirLook.key_pose` |
| 내딛기(런지) | 칠 때 겨눈 쪽으로 몇 px 나감(무기마다 `lunge`) | `hero.lunge` |
| 피폭체 공격 예고 (11-20 추가) | 할퀴기 준비 중 실제 범위를 은은한 빨간 점선으로, 받아치기 때 조금 밝게 | `attack_tells.py` |

## 더할 수 있는 것 (후보)

| # | 요소 | 무엇 | 왜 손맛이 나나 | 크기 |
|---|---|---|---|---|
| 1 | **넉백** | 맞은 피폭체가 맞은 방향으로 몇 px 밀려남, 강타는 더 멀리 | 힘이 전해진 게 보임 | 작음 |
| 2 | **방향 있는 흔들림(카메라 킥)** | 아무 방향이 아니라 친 방향으로 화면이 툭 밀렸다 돌아옴 | 타격 방향이 몸으로 느껴짐 | 작음 |
| 3 | **주인공 내딛기(런지) 키우기** | 이미 몇 px 나감. 치기 그림(앞으로 내디딤)과 거리·때를 맞춰 더 또렷하게 | 무게가 실림 | 작음 |
| 4 | **피 튀김 파티클** | 맞은 방향 반대쪽으로 피 방울 몇 개가 튀고 바닥에 남음 | 결과가 남음 | 중간 |
| 5 | **결정타 연출** | 쓰러뜨리는 마지막 한 방에 더 긴 멈춤(0.12초) + 짧은 슬로 + 큰 흔들림 | 보상감 | 작음 |
| 6 | **맞은 적 휘청 그림/찌그러짐** | 맞은 피폭체가 뒤로 젖는 그림(3D 피폭체가 생기면) 또는 잠깐 납작해졌다 펴짐 | 맞았다는 반응 | 중간 |
| 7 | **조준 다 찼을 때 신호** | 꾹 눌러 노리기가 다 차면 무기 끝 반짝 + 짧은 소리 | 타이밍 손맛 | 작음 |
| 8 | **소리 변주** | 같은 소리도 높낮이·크기를 조금씩 바꿔 매번 다르게, 무기마다 다른 타격음 | 반복이 덜 지루함 | 작음 |
| 9 | **무기마다 다른 궤적·효과** | 도끼는 두껍고 느리게, 칼은 가늘고 빠르게 (MOTION_RULES 6번, pixelfx) | 무기 차이가 느껴짐 | 중간 |
| 10 | **발밑 먼지** | 구르기·내딛기·쓰러질 때 먼지 | 땅을 디딘 느낌 | 작음 |
| 11 | **헛손질 반응** | 허공을 치면 몸이 살짝 끌려가고(관성) 바람 소리 | 빗나감도 느껴짐 | 작음 |
| 12 | **피격 시 주인공 반응** | 맞으면 화면 빨강 + 짧은 멈춤 + 주인공 밀림 | 위험이 느껴짐 | 작음 |

주의: 매번 다 세게 하면 오히려 무뎌진다(이미 `JOLTS`에서 지킨 원칙). 약한 타격은 작게, 중요한 순간만 크게. F4에서 하나씩 켜고 끌 수 있게 해서 비교한다.
