# 조사: Claude Code와 GPT(Codex)가 한 프로젝트를 함께 쓰는 방법 (2026-11-25)

요청: "GPT와 작업을 공유하면서, GPT가 주로 3D·이미지 생성 쪽을 맡고… 관련 스킬이나 방법이 있는지 조사하고 적용". 적용 계획: [2026-11-25_GPT_공동작업_방식](../plans/2026-11-25_GPT_공동작업_방식.md).

## 1. 지시 파일을 하나로: AGENTS.md + CLAUDE.md 불러오기

- Codex는 저장소의 `AGENTS.md`를 그대로 읽는다. Claude Code는 `CLAUDE.md`를 읽고, 그 안의 `@AGENTS.md` 한 줄로 같은 내용을 불러올 수 있다 → 공동 규칙은 AGENTS.md 한 곳, Claude만의 메모는 CLAUDE.md 아래에.
- Windows는 심볼릭 링크에 권한 문제가 있어 불러오기 한 줄이 가장 안전하다는 안내.
- 주의: 개인 `CLAUDE.local.md`를 두면 공동 AGENTS.md를 안 읽게 되는 경우가 있다는 글. 최근 버전에선 CLAUDE.md가 없으면 AGENTS.md를 바로 읽는다는 보도도 있으나 버전마다 달라 불러오기를 쓴다.
- 출처(대부분 비공식 안내라 세부는 미확인): [InfoWorld](https://infoworld.com/article/4224410/claude-code-now-also-accepts-instructions-in-openais-agents-md-format.html), [DevOps.com](https://devops.com/claude-code-adds-agents-md-fallback-cutting-instruction-file-sprawl/), [eesel.ai](https://www.eesel.ai/blog/claude-code-agents-md), [SSW Rules](https://www.ssw.com.au/rules/symlink-agents-to-claude), [makandra](https://makandracards.com/makandra/626671-claude-code-read-agents-md?page=23)

## 2. 공식 Codex 플러그인 (Claude Code 안에서 Codex 부르기)

- `openai/codex-plugin-cc` (OpenAI, 2026-03-30 공개). 설치: `/plugin marketplace add openai/codex-plugin-cc` → `/plugin install codex@openai-codex` → `/reload-plugins` → `/codex:setup`. Codex CLI는 `npm install -g @openai/codex`, 로그인은 `codex login`.
- 필요: Node.js 18.18 이상(이 컴퓨터 v24 있음), ChatGPT 구독(무료 포함) 또는 OpenAI API 키. 사용량은 Codex 한도에서 깎임.
- 명령: `/codex:review`(읽기만 하는 코드 검토), `/codex:adversarial-review`(설계 가정 따지는 검토, 읽기만), `/codex:rescue`(조사·수정 시도 맡기기, `--background`), `/codex:transfer`(이 대화를 Codex로 넘기기), `/codex:status`·`result`·`cancel`, `/codex:setup`(리뷰 게이트 켜면 사용량을 빨리 씀).
- Windows 안내는 README에 없음(미확인). 이 컴퓨터: Codex 앱 로그인 흔적(`~/.codex`)은 있으나 Codex CLI는 없음.
- 출처: [공식 README](https://raw.githubusercontent.com/openai/codex-plugin-cc/HEAD/README.md), [GIGAZINE](https://www.gigazine.net/gsc_news/en/20260331-claude-code-codex-plugin), [DEV Community](https://dev.to/siddhesh_surve/openai-just-dropped-a-codex-plugin-for-claude-code-and-it-changes-the-ai-coding-meta-1ilg). 이름이 비슷한 제3자 저장소(andyli953/codex-plugin-cc 등)는 공식 아님.

## 3. 여러 AI가 한 저장소에서 부딪히지 않게

- **마크다운 작업판**: 칸반을 파일 하나(또는 폴더)로 — 사람·Claude·Codex 누구든 읽고 고칠 수 있음. ([TimeToBuildBob](https://timetobuildbob.github.io/blog/multi-agent-task-coordination), [Batty](https://dev.to/battyterm/how-i-run-a-team-of-ai-coding-agents-in-parallel-p7c))
- **충돌의 대부분은 같은 파일**: 작업을 나눠도 둘이 같은 파일을 건드림 → 파일·폴더 담당을 먼저 정함. ([HackerNoon](https://hackernoon.com/four-ai-coding-agents-one-codebase-and-a-coordination-problem), [파일 잠금 글](https://dev.to/authora/stop-your-ai-coding-agents-from-fighting-file-level-locking-for-shared-codebases-3pej))
- **git worktree**: 동시에 코드를 고칠 때 작업 폴더를 나눔(같은 기록 공유). 같은 파일 충돌은 못 막음. ([David Wells](https://davidwells.io/blog/multi-agent-coding-without-worktree-chaos))
- **인수인계 파일**: 잘못된 가정의 비용이 클 때 짧은 인수인계 파일이 값을 함. ([cross-repo handoff](https://dev.to/gerodriguez/cross-repo-handoff-protocol-coordinating-ai-coding-agents-across-separate-repositories-43a3))
- 잠금 도구(agent-coord 등)는 제3자 도구라 두 명 규모엔 과함.
