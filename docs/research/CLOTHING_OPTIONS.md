# 기본 몸에 옷 입히기 조사

작성 2026-11-11. 사용자 지시: "나는 이 캐릭터도 나름 맘에 들어, 동작도 자연스럽고 이 방식도 괜찮은데, 다만 옷 입는 것만 해결되면 될 것 같아. 조사해 봐." — 지금 게임 속 기본 몸(Quaternius Universal Base Characters)과 동작(Universal Animation Library 1·2)은 그대로 두고, 옷만 제대로 입히는 방법을 찾는다. 조건: 무료, 같은 뼈대면 가장 좋음.

| 방법 | 같은 뼈대 | 비용·라이선스 | 장점 | 단점 |
| --- | --- | --- | --- | --- |
| **Quaternius Modular Character Outfits – Fantasy (Standard)** | **예** (Universal Base Characters용으로 제작) | 무료, CC0 | 기본 몸·동작 그대로. 무료판에 **Peasant(셔츠·바지·부츠)** 와 **Ranger(후드·가죽 조끼·띠·팔 보호대·긴 부츠)** 남녀 포함. 부품을 섞어 입힐 수 있음 | 판타지 풍(가죽 끈·버클). 색을 시안 색으로 다시 칠하고 부품을 골라야 생존자 느낌이 남 |
| MPFB2 (MakeHuman for Blender) | 아니요 (MakeHuman 몸) | 무료, 기본 자산 CC0 | 캐주얼 옷(셔츠·청바지·신발 등) | 몸이 바뀜 → 동작을 다시 옮기거나 Mixamo로 다시 리깅해야 함. 후드·카고 바지 같은 옷은 기본 팩에서 찾지 못함 |
| Mixamo 캐릭터 (Alex 등) | 아니요 | 무료(Adobe 계정) | 옷이 모델링돼 있음 | 2026-11-11 시험: 사용자 "맘에 안 든다" |
| 유료 의상 팩 (Davlet 등) | 아니요 (MetaHuman) | 유료 | 현대 전술복 | 무료 원칙에 어긋남 |
| Claude가 직접 모델링 | 예 | 무료 | 자유로움 | 스크립트 모델링이라 단순, 어색할 위험 |

결론(제안): **Quaternius Fantasy 의상 무료판**을 받아, Ranger의 후드·조끼와 Peasant의 셔츠·바지·부츠를 섞고 시안 색(겨자색 상의, 짙은 회색 바지, 어두운 부츠)으로 다시 칠해 본다. 같은 뼈대라 지금 동작·렌더 도구가 그대로 동작한다. 미리보기: `assets/characters/previews/research_quaternius_outfits_standard.jpg`.
