## 문제: 3D 그림이 없는 동작은 예전 옆모습 그림이 나옴

`DirLook`은 그림이 없는 동작을 예전 옆모습 시트로 넘긴다. 그래서 그대로 기본만 바꾸면 맞거나 쓰러질 때 다른 사람(예전 그림)이 나온다. 또 이 동작들은 방향(angle)을 넘기지 않아서 8방향 그림을 고를 수 없다.

|---|---|---|---|---|
| 서 있기·숨쉬기·걷기 | | 있음 | | |
| 조준·공격(휘두르는 무기) | | 있음 | | |

## 방법

- 그림: `tools/sprites/build_hero3d.py` ACTIONS에 동작마다 한 줄(원본, 장수, 폴더). 장수는 MOTION_RULES 2-1(적게).
- 게임: `DirLook`이 동작 이름과 같은 폴더가 있으면 그 그림을 씀(한 번 하는 동작은 진행 0~1로 장 고르기, 반복 동작은 시간으로). 공용 규칙이라 다른 캐릭터도 폴더만 있으면 됨.
- `hero.py`: 맞기·쓰러짐·줍기·밀치기·구르기에도 바라보는 방향을 넘김(구르기는 구르는 방향).
- 기본 주인공: `play.py` `HERO_PX` 기본값을 `hero_3d`로(`BUSAN_HERO=hero_px40`으로 예전 것 비교 가능).
