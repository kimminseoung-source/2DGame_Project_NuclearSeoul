# 계획서: 그래픽·UI·UX 통일 기준(아트 바이블)을 먼저 정하기

- 작성 2026-11-25 · 상태: **진행 중 (사용자 선택 대기)**
- 요청(Scavland 화면 4장 첨부): "전체적으로 UI, UX, 그래픽들이 통일된 느낌이 나고 특색이 있잖아요. 저는 그런 부분을 미리 어떻게 할지 정하고 싶어요. 계획을 하고 진행해야 나중에 계속 수정해야 할 부분이 줄어들 것 같아요."
- 이해한 것: 그림·UI를 하나씩 만들기 전에 **게임 전체의 보이는 규칙(아트 바이블 / 스타일 가이드)**을 문서로 먼저 정한다. 이후 GPT(그림)와 Claude(게임·UI)가 모두 이 문서를 따른다.

## Scavland에서 본 통일의 비밀 (첨부 화면 분석)

| 요소 | 본 것 |
|---|---|
| 색 | 세상 전체가 **녹·흙·바랜 갈색** 한 묶음. 진한 색은 불·피·주황 강조뿐 |
| UI 색 | UI 판이 **세상과 같은 색**(짙은 올리브 판 + 녹슨 청록 금속 테두리), 강조는 **주황 한 가지**, 체력은 빨강 |
| UI 모양 | 칸 나눈 막대(눈금), 도트 아이콘, 도트 한글 글꼴, 모서리에 금속 장식 — 판·막대·아이콘이 모두 같은 규칙 |
| 그래픽 | 비스듬한 탑뷰(3/4), 촘촘한 소품(차·통·판자·쓰레기), 장소가 이야기를 함 |
| 빛 | 어두운 바탕 + 불·횃불만 따뜻하게 빛남, 비 입자 |
| 정보 | 단축키 안내는 화면 왼쪽에 작게, 물건 설명은 같은 판 양식 |

## 정할 것 (아트 바이블 목차)

1. 한 줄 콘셉트(무슨 느낌의 게임인가)
2. 색: 세상 팔레트, 강조색, 위험색(피폭 초록), 시간대 색
3. 그래픽: 시점 각도, 도트 크기(캐릭터 키 px), 외곽선, 명암 단계, 소품 밀도
4. 캐릭터: 주인공·피폭체·사람 그림체 하나로
5. 빛·효과: 광원, 그림자, 입자, 화면 효과
6. UI: 판·테두리·막대·아이콘·글꼴 규칙, 강조색 쓰는 곳
7. UX: 정보 위치(HUD·커서 근처·화면 가장자리), 안내 방식
8. 금지 목록(AI 티, 섞이는 그림체 등) + 점검표
