# 계획서: 낮을 살짝 더 밝게

- 작성 2026-11-25 · 상태: **완료**
- 요청: (분위기·UI 조사 후보를 보고) "1. 낮이 살짝 더 밝으면 괜찮을 듯"
- 원인: 낮에도 시야 원뿔 밖을 `daylight.FOG_DAY = 60`만큼 어둡게 그림(밤 150). 그래서 낮 화면이 전체로 탁함(`docs/planning/mood_now_12.png`).

## 바꿀 것

| | 지금 | 바꾼 뒤 |
|---|---|---|
| 낮 시야 밖 어둡기 `FOG_DAY` | 60 | **40** (살짝) |
| 사실 모드(F3) 차가운 덮개 | 낮·밤 모두 70 | **낮 45 → 밤 70**으로 빛에 따라(`MUTE_DAY`, `MUTE_NIGHT`) |
| 밤 `FOG_NIGHT` | 150 | 그대로(밤은 후보 A에서 따로) |

- 저녁·새벽은 낮↔밤 사이를 이어서 같이 조금 밝아짐. F4 "낮 화면 어둡기"로 바로 조절 가능.

## 확인

- 숨긴 창 낮 12시 화면 밝기(전체·시야 밖) 전후 숫자, 나란히 그림. 밤 22시는 그대로인지.

## 손맛(게임 쥬스)

- 해당 없음(밝기 조정). 낮·밤 차이가 커져서 밤의 긴장감(후보 A)이 더 살아나는 쪽.

## 결과

- 처음 `FOG_DAY`만 60 → 40으로 낮췄더니 화면 밝기 64.4 → 66.3(거의 안 보임). 재 보니 시야 밖 어둡기를 0으로 해도 70 — **낮을 어둡게 하던 주된 것은 사실 모드의 차가운 덮개(알파 70, 낮밤 같음)**. 그래서 덮개를 낮에만 45로.
- 숨긴 창 화면 평균 밝기: **낮 64.4 → 70.5(약 +10%)**, 저녁 59.0 → 63.0, **밤 42.8 → 42.8(그대로)**. 전후 그림 `docs/planning/day_brighter_compare.png`. check_daylight·shadow_match·dev 통과.
