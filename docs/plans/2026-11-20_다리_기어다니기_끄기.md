# 계획서: 다리 부위·기어다니는 피폭체·밟기 끄기 (머리와 몸통만)

- 작성 2026-11-20 · 상태: **완료**
- 요청: "기어다니는 거는 없애도 될 것 같음, 밟는 요소를 빼도 될 것 같아요" → "다리는 비활성화하죠? 머리랑 몸통 정도만 하는 게 좋아 보여요. 저희가 2D이다 보니까 이게 적절해 보임"
- 방식: 지우지 않고 **설정 하나로 끔**(`settings.LEGS_AND_CRAWLERS = False`). 나중에 다시 켤 수 있고 바꾸는 곳이 적다.

## 바뀌는 것

| 무엇 | 지금 | 끈 뒤 |
|---|---|---|
| 노릴 수 있는 부위 | 머리(피해 3배)·몸통(공격 끊기)·다리(기어다니게) | **머리·몸통**. 다리 높이를 노리면 몸통 |
| 피폭체 몸 판정 | 다리 0~20, 몸통 20~35, 머리 35~48 | 몸통 0~35, 머리 35~48 |
| 기어다니는 피폭체 | 다리를 맞거나 일부가 기어서 나옴 | 안 나옴 |
| 발목 물기·밟기 | 기는 피폭체에게 | 없음 |
| F4 "기어가는 피폭체 소환" | 있음 | 숨김 |
| 3D 주인공 "밟기" 그림 | 기본 주인공 교체 계획에 있음 | 뺌 |

## 하지 않는 것

- 기는 피폭체·밟기 코드 지우기(설정으로 꺼 둠)
- 머리·몸통 효과·피해 바꾸기

## 결과

- `settings.LEGS_AND_CRAWLERS = False`. `weapons.PARTS`(몸통 0~35, 머리 35~48)·`PATH_PARTS`(33 아래 몸통)가 설정을 따름, `Zombie`는 기어 다니는 놈으로 만들어지지 않음(구역 배치·새로 들어옴·소환 모두), F4 "기어가는 피폭체 소환" 숨김.
- 점검: 구역 30번 시작 + 새로 들어옴 40번씩 = 피폭체 1,440마리 중 기는 놈 0, 높이 2~25 = 몸통·34 이상 = 머리, check_aim(다리 겨냥 → 몸통, 기지 않음), check_combat·defense·dev 그대로.
- 기록: README(조작 설명), DESIGN_LOCK "노릴 부위" 줄, 기본 주인공 교체 계획서에서 밟기 뺌.
