# D 보행의 무릎 높이와 작은 접지 반응

사용자 플레이 평가: 동작은 많이 좋아졌지만 3번째 동작에서 다리를 너무 높이 든다. 약한 쥬시를 더하고 싶다. 제작 판단: 현재 통과 자세는 무릎을 높게 드는 행진처럼 읽힌다. 같은 문제를 가진 반 주기 뒤 7번째 자세도 함께 고친다.

## 근거와 적용

- 기존 ANIMATION_GUIDES/MOTION_RULES/MOTION_FEW_SPRITES/ART_FEEDBACK와 `GAME_JUICE_2026-11-20.md`를 먼저 확인했다. 기본 보행과 체중 이동을 유지하고 동작 순간에 작은 피드백을 붙인다. 전신 코드 변형/카메라 발걸음 흔들림/접지 오류를 가리는 먼지는 사용하지 않는다.
- 발 교대 순서/지지 발 궤적/보폭은 유지한다. 일반·조준의 3번째/7번째 네 그림에서 **들린 다리의 무릎과 발을 낮춘 원화**만 image_gen으로 수정한다. 다른 12장과 원본 시트를 보존한다.
- 기존 `play.py` 발소리는 32world 단위마다 재생되어 D의 반 주기24.46875와 시점이 다르다. 수정 D에서만 실제 보행의 반 주기 접촉 이벤트로 발소리를 동기화한다. 음량은 작게 유지하고 이벤트 중복/정지 중 재생/히트스톱 중 재생이 없어야 한다.
- 작은 접지 반응은 기존 먼지 효과를 재사용한다. 코드 확인 결과 기존 Dust는 그림이 아니라 픽셀 입자이므로, 같은 효과에 수명 .10초/저명도1px 입자2개인 step 종류를 추가한다. 큰 구르기 먼지나 새 연출로 바꾸지 않는다. 적에게 들리는 소음 규칙/피해/속도/카메라는 바꾸지 않는다.
- D 안에서 F10 수정 전/후 비교를 제공한다. C 및 A/B도 유지한다. 실행 중인 사용자 게임을 임의 종료하지 않는다.

- 실제 게임에서 좌우 이동/조준/이동 사격/멈춤/재출발/벽 막힘/히트스톱 중 접촉 이벤트 확인. 접촉 한 번당 발소리 한 번, 기존 거리 소리와 중복 금지. 수정 전후 전환 시 위치/탄약/위상 보존.

## 적용 결과

- 네 프레임의 들린 다리 원화를 낮춰 저장했다. 일반/조준 상체0~39행과 지지 부츠 영역은 원본 픽셀 복원으로 유지하고 다른12키/보폭은 보존했다. 실제 다리 그림을 AI가 수정했으며 코드로 다리를 회전하거나 전신을 이동시키지 않았다.
- D 수정 후 기본, F10으로 이번 수정 전/후를 같은 위상에서 비교한다. `distance_step_audio` 기본True, 수정 D에서만False로 기존32world 소리를 끄고 보행 접촉 이벤트로 소리를 재생한다. 화면 흔들림 없이 기존 Dust에 작은 step 종류만 추가했다.
- `check_pistol_refinement.py`의 픽셀/접지 이벤트·소리 중복/정지·차단/한 주기2접촉/F10 상태/입자 크기 검사 통과. `check_pistol_gait.py` 실사격·탄차감·보행 흐름 검사와 `check_pistol_flow.py` C 회귀 검사 통과. 원화 비교와 실제 게임 GIF를 확인했다.
- 결과와 생성 요청: [refinement README](../../assets/characters/previews/hero_pistol_gait_v4/refinement/README.md). 사용자가 좋아한 D의 교대 흐름은 유지하며, 이번 수정의 소리/입자 강도에 대한 사용자 평가는 아직 받지 않았다. 기존 접지 오차/방향·구르기·총 분리 제한은 유지한다.
