## 바꿀 것

| | 바꾼 뒤 |
|---|---|
| 흔들림 | 모드와 상관없이 맞을 때마다. **방향 있는 흔들림**: 때린 쪽에서 밀리는 방향으로 한 번 크게(6px) 튀었다가 흔들리며 잦아듦(0.3초) |
| 붉은 번쩍임 | 화면 전체에 붉은 색이 **확 들어왔다가 0.3초에 빠짐**(처음 35%) + 가장자리 점무늬는 그대로 |
| F4 | "맞을 때 흔들림·번쩍임" 켜기/끄기 |

- 공용: `jolt()`에 방향(`push`)을 받게 → 나중에 큰 타격·보스 공격에도 같은 흔들림.
