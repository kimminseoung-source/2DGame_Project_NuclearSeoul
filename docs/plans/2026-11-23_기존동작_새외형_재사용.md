# 기존 주인공 동작에 새 외형 연결

- 사용자: 기존 주인공 동작은 자연스러우니 그 동작 위에 새 외형을 넣을 수 있는지 확인해 달라.
- 확인: 기존 주인공은 MPFB 리깅 모델 + Mixamo 애니메이션을 렌더한 이미지다. Walking은 6프레임, 조준 이동은 같은 하체에 준비 상체를 혼합, 기본 samurai 공격은 baseball 준비와 greatsword 타격/회복을 조합한다.
- 새 AI 키 그림 방식은 프레임별 체형·관절 차이가 있어 기존 동작의 일관성을 그대로 보장하지 않는다. 기존 리깅/동작 재사용을 우선 비교한다.
- 이번 작은 시험: 기존 원본 모델 복사본을 붉은 재킷/맨팔/넓은 바지/배낭 없음 외형으로 조정하고 같은 Walking 원본과 같은 6개 시간 표본으로 걷기 한 방향을 렌더한다.
- 기존 3D 원본과 새 AI 그림/플레이 버전은 덮어쓰지 않는다. 모델 해석과 원화가 완벽히 같다고 보지 않고 외형 차이를 명시한다. 사용자의 현재 플레이 창은 임의 종료하지 않는다.
- 비교 출력: `assets/characters/previews/hero_redjacket_rig_v1/`. 모델: `assets/source3d/scenes/hero_redjacket_rig_v1/hero_redjacket_v1.blend`.
- 걷기 비교 후 외형이 맞으면 기존 조준/공격/회피/피격/사망 동작을 같은 뼈대에서 재사용한다. 이번 단계는 걷기 한 방향까지만이다.

## 결과

- 기존 뼈대/Walking 원본의 동일 6시간 표본을 새 모델 복사본에 적용하고 몸/검 포함 PNG 12장을 만들었다. 고정 카메라, 경계 접촉 없음.
- 기존/AI/3D 복사본 비교 GIF를 생성했다. 모델의 체격·머리·옷 형태는 승인된 그림과 달라 아직 외형 완성은 아니다.
- 방식 검증 결과와 나머지 과제는 결과 README에 기록했다. 기존 게임과 원본 모델을 교체하지 않았다.
