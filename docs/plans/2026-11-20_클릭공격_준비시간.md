# 계획서: 클릭 공격의 준비 시간 줄이기

- 작성 2026-11-20 · 상태: **완료**
- 요청: "조준하고 공격했을 때는 문제가 없습니다. 다만 클릭 공격을 했을 때 준비 동작의 시간을 줄여야 할 것 같습니다"

## 지금

| 공격 | 준비(맞기 전까지) | 근거 |
|---|---|---|
| 꾹 눌렀다 놓기(조준) | 준비 시간의 30%만 (`READY_SKIP` 0.7을 건너뜀) | 이미 들어 올려 있으니까 |
| 짧게 클릭 | 준비 시간 **전부**(쇠파이프 0.4초, 도끼 0.52초, 마체테 0.26초 × TEMPO 1.3) | 처음부터 들어 올림 |

클릭은 준비 그림을 오래 붙잡고 있어 굼뜨게 느껴진다.

## 바꿀 것

- 새 값 `weapons.QUICK_SKIP`(처음 0.5): 짧게 클릭하면 준비 시간의 이만큼을 건너뛴다. 모든 무기에 같은 규칙(공용). 쇠파이프 0.4초 → 0.2초.
- 조준 공격은 그대로(0.7 건너뜀이 클릭보다 여전히 빠름 → 조준할 이유는 유지: 부위 노리기·머리 3배).
- F4 슬라이더 "클릭 공격 준비 줄이기"(0~90%)로 직접 맞춰 볼 수 있게.
- 밟기(기는 피폭체)는 그대로.

## 하지 않는 것

- 무기 피해·범위·전체 시간 바꾸기
- 그림 바꾸기(준비 그림이 짧게 보일 뿐)
