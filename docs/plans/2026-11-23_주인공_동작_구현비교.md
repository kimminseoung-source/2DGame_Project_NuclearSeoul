# 주인공 동작 구현 비교

- 사용자 요청: 이전 주인공들의 구현 동작과 새 주인공의 동작을 비교하며 누락을 방지한다.
- 기본 3D, 이전 PixelLab, 공통 옛 시트, 실제 새 주인공 실행, 최신 미리보기를 구분한다.
- 그림 파일 존재와 로더의 실제 선택/대체, 게임 상태 진입과 기본 비활성 기능을 별도로 기록한다.
- 새 주인공은 실행 중인 6프레임 버전과 자세 안내 6/양손 8프레임 미리보기를 구분한다.
- 총 중심 사용자 방향은 반영하되 총 종류·탄창 수치·재장전 규칙을 임의 확정하지 않는다. 기존부터 없는 기능을 이식 누락으로 표시하지 않는다.
- 목록은 `docs/planning/HERO_MOTION_STATUS.md` 한 곳에 유지하고, 근거 JSON은 `HERO_MOTION_INVENTORY.json`, 재조사 도구는 `tools/checks/audit_hero_motions.py`로 둔다. 새 스프라이트 생성/게임 변경은 이번 범위가 아니다.

## 조사 결과

- 파일/메타데이터 검사 및 숨김 실제 로더 17요청×8방향×2종 경로 조사 완료. 기존 3D 키 참조168/PixelLab10에 파일 누락0. 전 동작의 육안/플레이 검수는 아님.
- 기존 3D의 살금/조준이동/피격/쓰러짐/줍기/구르기에 비해 새 실행은 여러 동작을 대기/일반 걷기로 임시 대체함을 확인했다.
- 최신 양손8은 미리보기, 실제 새 실행은 motion_v1을 로드함을 확인했다.
- 총 중심 신규 항목과 기존 발사 기능, 전용 그림/재장전 미구현을 구분했다. 이후 작업의 기준표/워크플로/인수인계/목차를 연결했다.
