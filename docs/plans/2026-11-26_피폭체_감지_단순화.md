# 2026-11-26 피폭체 감지 단순화

## 문제 (사용자 플레이 후 피드백)
"알아채는 범위가 너무 좁다", "소리·시야 둘 다라 복잡하다", "기준이 모호하다", "가까이 있는데도 모르는 건 문제".

## 근거 (현재 코드, `src/infected.py`)
- 시야 원뿔 260px·좌우 1.1rad인데, 실제 "!"는 140px(SPOT_DIST) 안에서만 → 보이는 것 같은데 모름.
- 사방 감지 NOTICE_NEAR 110px 이미 있음(벽에 가리면 안 됨).
- 소리: 발소리 70(살금 28)·구르기 140·베기 230·권총 400(`weapons.py`)·줍기.
- 발소리가 매 프레임 나서 감지 이유가 섞임.

## 수치안 (한 줄 규칙: "보이면·가까우면 들키고, 쏘면 몰려온다")
| 규칙 | 지금 | 바꿀 값 |
|---|---|---|
| 보이면 들킨다 (앞 원뿔, 벽 없을 때) | 원뿔 260, "!"는 140 | 원뿔·"!" 모두 **250** (하나로 합침) |
| 가까우면 들킨다 (방향 무관) | 110 | **90** |
| 쏘면 몰려온다 (총소리) | 400 | **400** 유지 |
| 베기 / 구르기 소리 | 230 / 140 | 유지 |
| 발소리 | 70 (살금 28) | **없앰** |

## 고칠 곳
- `src/infected.py`: SPOT_DIST 삭제 → SIGHT_RANGE 하나, NOTICE_NEAR 90, NOISE_STEP 제거(조용한 베기용 값만 남김).
- `src/play.py` 878줄 발소리 호출 제거.
- `src/dev_tools.py`: F5 원 → 가까운 피폭체 1~3마리만, 시야(노랑 부채)·근접(빨강 원) 구분. F4 슬라이더 이름 정리.
- `src/spitter.py`: `Zombie.sees/hear` 상속 확인.
- `tools/checks`: check_spot·check_behind 값 갱신 + 새 점검 `check_detect_rules.py`.

## 검수
숨긴 창 숫자: 정면 240px 감지 / 등 뒤 80px 감지 / 등 뒤 150px 미감지 / 걷기만 하면 등 뒤 120px 미감지 / 총 쏘면 380px 안 피폭체가 몰려옴. `run_all.py` 통과.

## 손맛
"!"는 지금처럼 즉시 뜸. 총소리 뒤 "?"가 여러 마리에 연달아 뜨며 몰려오는 긴장감. 밤 시야 320px 안에 감지 250px이 들어가 "보이는 놈이 나를 본다"가 맞음.
