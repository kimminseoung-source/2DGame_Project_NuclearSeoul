# 붉은 재킷 주인공 · 작은 외형 확인

## 후속 사용자 요청 · 직접 플레이

- 사용자가 새 주인공으로 바꿔 직접 플레이하고 싶다고 요청했다. 별도 실행 `tools/run_redjacket_trial.py`, `tools/새_주인공_플레이.cmd`를 추가한다.
- 기본 스테이지의 이동/공격/피격/회피 판정은 재사용하고 외형만 두 그림으로 연결한다. 걷기와 베기/쓰러짐의 중간 동작은 미완성이므로 정식 애니메이션 교체라고 보지 않는다.
- 검이 포함된 그림이므로 시험 중 다른 무기 줍기는 제외하고 기존 기본 무기의 수치를 유지한다. `--spitter`로 이전 원거리 시험장에서도 조작할 수 있다.

- 사용자 선택: 세 번째 시안, 검은 머리·붉은 짧은 재킷·넓은 바지와 낮은 검 준비 자세.
- 최신 범위: 작은 부분만 확인한 뒤 나머지를 이어간다. 이번에는 한 방향 대기/준비 두 장만 검토하며 전체 동작·8방향·게임 기본 교체는 진행하지 않는다.
- 기준: `assets/characters/concepts/hero_redesign_v1/hero_three_designs.png`의 오른쪽 인물, 특히 아래 작은 도트 시안.
- 먼저 내장 image_gen으로 외형 검토용 핵심 자세 두 장을 분리 생성한다. 실제 높이 36px 기준과 게임 배경 비교를 제공한다. 이 단계는 3D 모델/리깅 제작이나 동작 완성을 뜻하지 않는다.
- 검토 요소: 옷 색만 바뀐 기존 인물이 아니라 넓은 어깨·드러난 굵은 팔·낮은 무게중심·넓은 바지로 다른 실루엣을 만든다. 배낭/두루마리 없음. 마체테 대신 양손 검.
- 기존 모델·주인공 자산은 보존한다. 사용자의 외형 확인 전 나머지 동작으로 확장하지 않는다.
- 결과 위치: `assets/characters/previews/hero_redjacket_v1/`. 생성 문안·원본·축소 기준·비교·미완성 범위를 README에 기록한다.

## 결과

- 대기/준비 두 키 이미지, 공통 배율 36px 기준, 64×64 칸, 발 기준점 (32,58)로 정리했다. 검은 그림에 포함되어 있다.
- 기존/대기/준비를 각각 실제 게임 렌더로 비교하여 `comparison.png`에 모았다. 게임 기본 자산과 소스는 바꾸지 않았다.
- 넓은 하체가 기존과 구분되지만 실제 크기에서 얼굴과 팔 세부가 소실되고 어두운 보정에서 재킷이 탁해진다. 사용자 검토를 기다리며 다음 동작은 시작하지 않았다.
