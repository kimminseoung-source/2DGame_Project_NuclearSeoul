# 계획서: 연속 구르기 — 구르기 사이 텀 줄이기

- 작성 2026-11-21 · 상태: **완료**
- 요청: (구르기 2번 저장 뒤) "지금 연속 2번 구르기가 안 되지 않나? 그 사이의 텀이 있어서 그렇게 느껴짐"
- 원인: 구르기가 끝난 뒤 `ROLL_COOLDOWN` **0.35초** 동안 다시 못 구름(스태미나 시절 연타 막기). 구르는 동안 누른 Space는 버려짐.

## 바꿀 것

| | 지금 | 바꾼 뒤 |
|---|---|---|
| 구르기 끝 → 다음 구르기 | 0.35초 기다림 | **0.05초** (횟수가 이미 막아 줌) |
| 구르는 중 Space | 무시 | **미리 눌러 두기**: 구르기 끝나자마자 이어서 구름(그때 누른 방향) |
| F4 | | "구르기 사이 텀" 슬라이더 |

## 손맛(게임 쥬스)

- 이어 구를 때도 출발 먼지·소리가 나도록, 먼지·소리를 "구르기가 실제로 시작될 때"로 옮김(지금은 키를 누른 순간에만).

## 결과

- `ROLL_COOLDOWN` 0.35 → 0.05, 구르는 중 Space를 미리 눌러 두면 끝나자마자 이어 구름(그때 구르기가 없으면 빨간 점만, 늦게 저절로 구르지 않음). 먼지·소리는 구르기가 시작될 때(이어 구르기도).
- `tools/checks/check_roll_chain.py`: 첫 구르기 끝 → 둘째 시작 **0.066초**, 먼지 2번, 셋째(구르기 없음)는 안 나감. 관련 점검 8개 통과.
- 사용자 "아니면 구르기 차는 걸 늘리던가": F4 "구르기 횟수"(1~5)·"구르기 충전 시간"으로 바로 바꿔 볼 수 있음. 직접 해 본 뒤 기본값을 정함.
