문서의 과거 3D 본체 권장은 최신 사용자 선호(AI 최종 그림, 3D는 자세 안내)에 의해 대체한다. 파츠 분리/ControlNet/LoRA는 과거 36px 품질 실패가 기록되어 있으므로 설치하거나 다시 쓰면 해결된다고 단정하지 않는다. `ANIMATION_GUIDES.md`의 사용자 제공 도구 비교는 조사 메모이며 도구 기능/품질의 현재 검증을 뜻하지 않는다.

다음 수정의 우선순위는 **양손 준비 자세 유지 → 발 디딤/통과/반대 디딤과 루프 연결 확인 → 접지 좌표와 이동량 측정 → 그 결과에 따른 보폭/타이밍 조정**이다. 추가 장수/효과/다른 방향 확대보다 이 검수를 먼저 한다. 이번 문서 대조에서는 그림이나 게임을 다시 수정하지 않았다.

- 사용자 요청: 걷기를 더 자연스럽게, 첨부 빨간 선처럼 허리 앞에서 양손으로 검을 잡고 칼끝이 오른쪽 위를 향하도록 한다.
- AI 외형을 유지하고 3D는 자세 안내로만 사용한다. 기존 한손 버전과 게임은 보존한다.
- 기존 Walking의 실제 관절을 8시점으로 추출한다. 하체는 기존 걷기 흐름을 쓰고, 상체와 양손/검 위치는 사용자 지정 자세로 고정한 안내를 만든다. 상체 안내의 팔 좌표는 새 2D 자세 설계이며 원본 3D 관절 그대로라고 주장하지 않는다.
- 두 손은 허리/배 앞 같은 손잡이에 위아래로 붙인다. 칼날은 약 45도 오른쪽 위, 머리 위로 치켜들지 않는다. 팔 흔들기는 억제하고 다리의 통과/디딤 연결을 만든다.
- 장수만 늘리는 것이 아니라 머리/재킷/골반 중심과 검 길이를 일관되게 유지하는 것을 함께 검토한다. 8프레임은 한 주기 약 0.6초로 재생한다.
- 한 방향 그림 비교만 먼저 만든다. 게임 자동 교체/다른 방향/공격 확대 없음.
