# 붉은 재킷 · 걷기와 검 공격

- 사용자 피드백: 새 외형이 괜찮으니 걷기와 공격 모션을 추가한다.
- 기존 플레이 시험을 확장하되 원본 두 자세와 기존 주인공은 보존한다.
- 우선 한 방향+좌우 반전: 걷기 6자세, 검 공격 준비/치기/회복 3자세. 캐릭터를 코드로 늘이거나 회전해서 동작을 만들지 않는다. 이미지 생성 스킬의 내장 도구로 실제 자세를 만든다.
- 같은 배율과 발 기준으로 정리한다. 검이 커지는 프레임마다 몸이 확대/축소되거나 무기 bbox 때문에 몸 중심이 흔들리지 않도록 검수한다.
- 걷기는 실제 이동 거리로 프레임을 고른다. 서서 조준할 때는 준비 자세, 공격은 기존 hit_at 접촉 시점에 치기 자세를 맞추고 짧게 유지한 뒤 회복한다. 공격 3자세 기준을 유지한다.
- 실제 게임에서 이동/조준 이동/일반 클릭/충전/회피/피격/재시작을 확인하고 GIF를 남긴다. 임시 시험 실행만 갱신하고 기본 실행 자산은 바꾸지 않는다.
- 위아래 전용 방향, 실제 구르기/피격/쓰러짐 그림, 무기 레이어 분리는 이번 범위 밖이다. 두 방향으로 8방향 완성을 주장하지 않는다.
- 결과 위치 `assets/characters/previews/hero_redjacket_motion_v1/`, 제작/검수 도구 `tools/sprites/build_redjacket_motion.py`.

## 결과

- 9자세와 기존 대기/준비를 고정 기준점으로 정리하고 시험 실행에 연결했다.
- 게임 내 이동/정지/벽/일반·충전 공격 실제 피해와 타격 자세/회피/피격/재시작 검사를 통과했다. 실제 게임 300프레임 GIF를 남겼다.
- AI 자세별 머리·어깨/다리 차이와 위아래 조준의 시각 불일치는 남아 있다. 설명은 결과 README. 사용자 플레이로 감각을 검토하고 다음 수정 범위를 결정한다.
