# 계획서: 회피 — 구르기 그림 대신 "샤샥" 빠른 회피 연출

- 작성 2026-11-21 · 상태: **진행 중**
- 요청: "다음으로 회피 이동을 어떻게 하는 게 좋을지 이야기해 보죠" → 백스텝·구르기 비교, "나중에 보스나 다른 몬스터들도 넣을 거긴 해요" → **"구르기로 가죠"**
- 결정: 회피는 **하나**(Space, 무적, 붙잡혔을 때 빠져나감). 백스텝은 만들지 않음.
- **바뀜(2026-11-21):** Mixamo 구르기 3개를 비교한 뒤 사용자 "굳이 구르는 동작이 없어도 되지 않을까요? 그냥 살짝 샤샥하면서 하는 느낌은 어떤가요" → "한 방향만 작게 해서 봐 볼까요, 어떤 게 좋을지". **구르는 그림 없이** 걷기 그림 한 장으로 미끄러지며 잔상·먼지·속도선 연출. 받아 둔 구르기 원본은 남겨 둠([비교 그림](../planning/roll_cands_east.png)).

## 나중을 위해 (보스·다른 몬스터)

- 구르기 숫자(거리·무적·기력·소리)는 지금처럼 설정 한곳에 두어 보스 공격(넓은 내려찍기·돌진·잡기)에 맞춰 조정.
- 공격 예고는 지금 부채꼴만. 보스를 넣을 때 원·띠·고리를 `attack_tells`에 공용으로 늘림(이번엔 안 함).

## 하지 않는 것

- 구르기 거리·무적·쿨다운 숫자 바꾸기(그림이 생긴 뒤 직접 해 보고 정함)
- 백스텝, 보스, 새 예고 모양

## 결과

### 시험판 (2026-11-21)
- `dodge_fx.py` 연출 4가지: 잔상, 잔상 + 먼지(기본), 속도선 + 먼지, **구르기 그림(동쪽만)** + 먼지. 사용자 "게임 안에서 보고 싶음, 직접 구르는 동작도 1개만" → "한쪽 방향으로만 해서 비교, 직접 플레이해서 비교".
- 구르기 그림: Mixamo Stand To Roll, 4장(웅크림·몸 던짐·말림·일어섬), 동쪽만(`build_hero3d.py --only b_roll --dirs east`). 다른 방향은 미끄러짐.
- F4 "회피 연출 (Space)"로 바꿔 가며 직접 해 보기. 비교 그림 `docs/planning/dodge_styles_east.png`, `.gif`. check_dev·combat 그대로, 프레임 5ms.
- 남은 것: 사용자가 고르면 그것만 남기고(구르기면 8방향), 무기 그리기(구를 때 칼이 아래로 늘어짐) 정리.
