# 계획서: 화면 선명하게 (탁함 걷어내기)

- 작성 2026-11-25 · 상태: **완료**
- 요청: (2D 느낌 4가지 중) "색이 또렷하고 대비가 분명한 화면… 이쪽이 괜찮아 보임"
- 원인: 사실 모드 덮개가 회색(26,30,34)을 **반투명으로 덮어서**(알파 45~70) 어두운 곳은 밝아지고 밝은 곳은 어두워짐 = 대비가 줄어 뿌옇다.

## 바꿀 것
- 회색을 덮는 대신 **색 곱하기**(multiply)로 차갑게: 어두운 곳은 그대로 어둡고, 밝은 곳만 살짝 푸르게 → 색감은 차갑되 뿌옇지 않음.
- 낮/밤 세기는 지금처럼 빛에 따라. F4로 예전 덮개와 비교.

## 확인
- 숨긴 창: 화면 밝기 평균과 **대비(밝기 표준편차)** 전후, 밤은 너무 밝아지지 않게. 전후 그림.

## 손맛(게임 쥬스)
- 대비가 살아나면 피·불꽃·초록 빛 같은 효과가 더 튐.

## 결과

- 회색 반투명 덮개 → 색 곱하기(낮 (238,242,250), 밤 (205,214,232)). 숨긴 창: 낮 밝기 70.3 → 74.2, **대비 27.7 → 28.8**, 밤 밝기 43.1 → 41.6, 대비 30.0 → 31.0. 전후 `docs/planning/clear_look_compare.png`.
- 솔직한 평가: 좋아지긴 했지만 **작다**. 남은 탁함의 대부분은 배경 그림 자체(3D 렌더 바닥이 원래 대비가 낮음) → 배경 비교 시안(보류 항목)의 근거.
