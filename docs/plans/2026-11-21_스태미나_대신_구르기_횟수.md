# 계획서: 스태미나 빼고 구르기 횟수로

- 작성 2026-11-21 · 상태: **완료**
- 요청: 스태미나 빼기 / 구르기 횟수 / 그대로 비교 → "나로 가 볼까? 지금 모든 동작에 스태미나가 있으니까, 저는 속도감 있는 전투를 원하다 보니까 이게 금방 빠지더라구요"

## 바꿀 것

| | 지금 | 바꾼 뒤 |
|---|---|---|
| 베기·헛치기 | 기력 듦, 바닥나면 베기 느려짐 | **아무것도 안 듦** |
| 조준 유지 | 기력이 조금씩 닳음 | 안 닳음 |
| 구르기 | 기력 듦, 바닥나면 못 구름 | **구르기 2번 저장**, 1.2초마다 1개씩 다시 참(F4로 조절) |
| 발밑 표시 | 기력 막대 | **구르기 점 2개**(찬 점 / 빈 점) |

- 스태미나 코드는 지우지 않고 설정 하나로 끔(`settings.STAMINA_ON = False`), 다리·밀치기 끈 것과 같은 방식.
- 구르기 횟수는 공용 숫자(`ROLL_CHARGES`, `ROLL_RECHARGE`) — 나중에 변이·보스 조정용.

## 손맛(게임 쥬스)

- 점이 다시 찰 때 점이 잠깐 밝게 커졌다 줄어듦(차오름이 보이게).
- 빈 상태에서 Space: 빈 점이 빨갛게 깜빡 + 작은 헛숨 소리 대신 기존 "지침" 깜빡임 재사용.
- 구를 때 쓴 점이 바로 비어 보임.

## 결과

- `STAMINA_ON = False`(베기·헛치기·조준 비용 없음), `stamina.Charges`(2번, 1.2초), 발밑 점(쓴 점 어둡게, 차오르는 점 회색으로 채워짐, 돌아오면 밝게 커짐, 없을 때 Space 빨강), F4 "구르기 횟수"·"구르기 충전 시간".
- 숨긴 창 `tools/checks/check_roll_charges.py`: Space를 1초 동안 매 프레임 → 2번만 구름, 없을 때 Space → 안 구르고 빨강, 1.18초 뒤 1개 돌아옴, 베기 6번 연속 길이 같음(0.546초), 기력 100 그대로. 그림 `docs/planning/roll_dots.png`. 관련 점검 14개 통과.
- 직접 해 본 뒤: "나쁘지 않은 것 같네, 구르기 차는 거는 1.5초 정도가 좋을 듯" → 기본 충전 1.5초.
