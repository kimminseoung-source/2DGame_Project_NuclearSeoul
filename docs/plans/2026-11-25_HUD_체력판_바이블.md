# 계획서: 아트 바이블 첫 적용 — 체력판(HUD)

- 작성 2026-11-25 · 상태: **완료**
- 요청: "맵은 작은 부분만 우선. 화면에 보이는 게 우선이고, 많이 노출되는 게 우선. 아트 바이블 초안이 어떻게 나올지 잘 모르겠지만 일단 해 보는 게 좋아 보이긴 하네요"
- 바이블 0장 "많이 보이는 것부터": 1순위 HUD. 그중 늘 보이는 **왼쪽 아래 체력판**부터 작게.

## 바꾼 것
- 체력판: 짙은 회청색 금속판 + 녹슨 테두리 1px + 위쪽 밝은 줄 + 모서리 리벳, 체력은 **눈금 16칸 막대**(바이블 붉은색, 방금 잃은 칸은 옅게), 숫자는 종이색.
- 공용 `hud.metal_plate()`·`hud.tick_bar()` → 다음 UI(탄약·배낭·알림)도 같은 조각으로.
- F4 "HUD 아트 바이블 (체력판)"로 전후 비교.
