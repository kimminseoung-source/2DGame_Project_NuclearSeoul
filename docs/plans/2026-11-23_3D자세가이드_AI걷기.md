# 3D는 자세 안내, 최종 모습은 AI 그림 · 작은 시험

- 사용자 방향: 3D 외형은 마음에 들지 않음. 승인된 AI 그림을 유지하고 기존 동작의 자세/리깅만 참고해서 그려본다.
- 이번 범위는 걷기 한 방향 6프레임 비교만이다. 게임 자산/플레이 버전은 교체하지 않는다.
- 기존 MPFB/Mixamo Walking의 실제 관절 좌표를 카메라로 투영해 자세 가이드를 만든다. 생성기에 승인된 외형 그림과 자세 가이드를 함께 준다. 새 모델 외형을 그리거나 3D 렌더 자체를 최종 그림으로 쓰지 않는다.
- AI가 자세 가이드를 정확히 따르는지, 머리/옷 크기를 유지하는지, 발의 앞뒤가 실제로 바뀌는지 확인한다. 안내 이미지는 강제적인 관절 제어가 아니므로 결과를 자동으로 자연스럽다고 판단하지 않는다.
- 생성 원본·문안·가이드·스프라이트·GIF·판단을 `assets/characters/previews/hero_poseguided_ai_v1/`에 모은다.

## 결과

- 실제 기존 관절을 뽑은 JSON과 안내 이미지를 만들고 승인 외형과 함께 image_gen에 제공했다.
- 한 방향 6프레임을 정리하고 기존/앞선 AI/이번 방식 비교 GIF를 만들었다. 6장 경계 접촉 없음.
- 자세를 정확히 강제하는 방식이 아니며 머리/어깨/검과 가림 관계 차이가 남았다. 완성 동작으로 보지 않는다. 게임 미적용.
