# 계획서: 나머지 HUD도 아트 바이블(도트 UI)로

- 작성 2026-11-25 · 상태: **완료**
- 요청: (체력판 다음) "나머지 HUD"
- 기준: [ART_BIBLE](../planning/ART_BIBLE.md) 6장(금속판·눈금·종이색 글자·강조는 주황 하나) · 7장(탄약은 조준점 옆)

| 대상 | 지금 | 바꾼 뒤 |
|---|---|---|
| 무기 | 맨 글자 + 무기 그림 | 체력판 옆 작은 금속판 안에 |
| 탄약(총) | 무기 이름 옆 "N발" | **조준점 옆** 작은 눈금(한 칸 = 한 발, 최대 12칸) + 숫자, 덜 밝은 주황. 없으면 빨갛게 깜빡 |
| 빠른 칸 | 빈 칸 3개 늘 보임 | 물건이 있는 칸만, 금속판 칸 |
| 알림 | 가운데 맨 글자 | 작은 금속판 위 |

공용 조각 `metal_plate`·`tick_bar` 재사용. F4 "HUD 아트 바이블"로 전체 전후 비교.

## 확인
- 숨긴 창: 칼 들었을 때 / 권총 들었을 때(탄 6, 0) / 물건 있을 때 화면, 조준점 옆 탄약이 커서 위치에 붙는지(좌표 숫자). check_ui·bag·dev·pistol.

## 손맛(게임 쥬스)
- 쏠 때 탄 칸이 하나 꺼짐, 탄이 없으면 빨간 깜빡(빈 총 소리는 이미 있음).

## 결과

- 무기판(금속판), 빠른 칸은 물건 있을 때만 금속판 칸, 알림은 작은 금속판, **조준점 옆 탄약 눈금**(한 칸 한 발, 12칸까지 + 숫자, 0발이면 빨간 0 깜빡).
- `tools/checks/check_hud_bible.py`: 근접/권총 6발/0발/15발+물건+알림 4장 `docs/planning/hud_bible_states.png`, 커서 (760,300) → 탄 눈금 화면 (778,312)(커서 오른쪽 아래). 관련 점검 통과.
