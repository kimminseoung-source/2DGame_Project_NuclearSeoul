## 적용안 [제안 — 사용자 확인 대기]
1. 시험판 코드(`tools/pistol_flow_look.py`·`pistol_gait_look.py`·`run_pistol_comparison.py`의 D 부분: 그리기·발사·조준선·접지 소리)를 `src/pistol_hero.py`로 옮겨 기본 게임이 `tools/`에 기대지 않게 한다. tools 쪽 파일은 그대로(GPT 담당).
2. 그림 경로는 지금 `previews/hero_pistol_gait_v4/identity` + `hero_pistol_flow_v3`(쓰러짐·누움, 총구) 그대로 읽는다. FACE-R1 머리 공유 유지(같은 파일 로드).
3. 기본 게임 시작 무기 = 권총, 주인공 그림 = D. 3D 검 주인공은 스위치(`BUSAN_HERO=sword`)로 남긴다.
4. 바닥 무기 줍기: 권총 주인공 그림은 권총만 있으므로 근접 무기는 [사용자 결정].
5. 탄약: 기본 권총 규칙(시작 탄약) [사용자 결정].
