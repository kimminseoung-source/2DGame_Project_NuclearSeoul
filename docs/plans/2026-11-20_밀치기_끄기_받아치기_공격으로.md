# 계획서: 밀치기 끄기, 받아치기를 공격으로 옮기기, 기본 주인공을 3D로

- 작성 2026-11-20 · 상태: **진행 중**
- 요청: "main.py에서 하니까 적용이 안 되어 있길래" → (3D 주인공에 밀치기 그림이 없어 기본을 안 바꿨다고 설명) → "밀치기도 비활성화해도 될 것 같아요" → (받아치기가 밀치기에 묶여 있다고 설명) → "받아치기도 비활성화하세요. 그걸 공격으로 옮기죠"
- 방식: 다리 끄기처럼 **설정 하나로 끔**(`settings.SHOVE_ON = False`), 코드는 남김.

## 바뀌는 것

| 무엇 | 지금 | 바꾼 뒤 |
|---|---|---|
| 우클릭(게임 화면) | 밀치기: 앞의 피폭체를 밀어 휘청 | **아무것도 안 함**(배낭 화면의 우클릭 줍기·쓰기는 그대로) |
| 받아치기 | 할퀴기 준비 마지막 0.29초에 **밀치면** 멀리 밀려 오래 휘청 | 같은 순간에 **베기로 맞히면** 피해 + 멀리 밀려 오래 휘청 + 강한 타격 연출 |
| 공격 예고 | 받아치기 때 조금 밝게 | 그대로 — 이제 "지금 베면 받아치기" |
| 화면 안내 | 할퀴려는 놈 가까이 "[우클릭] 밀치기" | 없음 |
| 기본 주인공 | PixelLab(`hero_px40`) | **3D 주인공(`hero_3d`)**, `main.py`만 실행해도. 예전 것은 `BUSAN_HERO=hero_px40` |

3D 주인공에 남은 빈 곳: 구르기(걷기 그림이 미끄러짐), 식칼·권총 전용 자세 → 기본 주인공 교체 계획 나 단계에서(밀치기는 거기서 뺌).
