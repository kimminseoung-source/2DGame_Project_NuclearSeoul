## 0. 순서 — 많이 보이는 것부터 (2026-11-25 사용자)

> "맵은 작은 부분만 우선 구현하면 됩니다. 우선 화면에 보이는 게 우선이고, 많이 노출되는 게 우선입니다."

| 순위 | 대상 | 왜 |
|---|---|---|
| 1 | **HUD**(체력·무기·탄약·쪽지·구르기 점) | 게임 내내 화면에 있음 |
| 2 | **주인공** | 늘 화면 가운데 |
| 3 | **일반 피폭체** | 가장 자주 나오는 적 |
| 4 | **골목 한 칸**(바닥·소품) | 맵은 작은 부분만 먼저 |
| 5 | 배낭 화면, 원거리 피폭체, 역 등 | 덜 보이는 것 |

바이블은 초안이라 "해 보면서" 고친다: 1순위부터 바이블대로 바꿔 화면에서 보고, 맞지 않으면 바이블을 고친다.

### 사용자 결정 (2026-11-25, "2D 게임에 어울리는 느낌")

| 항목 | 결정 |
|---|---|
| 캐릭터 | **[확정]** 외곽선 분명·명암 단순한 도트 캐릭터(AI 붉은 재킷 쪽) — "전 이쪽이 마음에 들어요" |
| UI | **[확정]** 도트 UI를 더 밀고 감(테두리 장식·도트 아이콘·도트 글꼴) — "네" |
| 선명함 | **[확정]** 색 또렷·대비 분명, 어두운 곳은 확실히, 캐릭터는 바닥에서 떨어져 보이게 — "이쪽이 괜찮아 보임" |
| 배경 | **[보류]** 3D 렌더 → 도트 타일·소품: "얼마나 좋아질지 모르니 고민" → 골목 한 조각만 비교 시안을 만든 뒤 결정 |

## 1. 한 줄 콘셉트

> **재가 내리는 차가운 한국 도시, 그 속에서 초록으로 썩어 가는 위험과 붉은 재킷 한 사람.**

세 가지만 기억한다: **회청색 세상 · 초록은 위험 · 붉은색은 주인공(과 피)**.

## 2. 색

| 역할 | 색 | 쓰는 곳 | 쓰면 안 되는 곳 |
|---|---|---|---|
| 세상 바탕(어둠) | `#1B2026` `#262D35` | 그림자, 밤, 가장 어두운 곳 | |
| 세상 중간 | `#3A434D` `#525C66` `#6E7780` | 아스팔트, 콘크리트, 건물 | |
| 세상 밝음 | `#8C949B` `#B4B8B8` | 빛 받은 면, 페인트 선 | 넓은 면 전체 |
| 녹·흙(보조) | `#5A4A3C` `#7A6048` | 녹슨 차, 흙, 나무 | 바탕 전체(Scavland와 구분) |
| **위험 = 피폭 초록** | `#4E7A2A` → `#9BD13A` → `#D8F659`(빛) | 피폭체의 빛·탄, 방사능 표지, 오염 | **아이템·UI 장식에 쓰지 않음** |
| **주인공 = 붉은색** | `#8E2A22` `#B8392C` | 주인공 재킷, 체력, 피 | 배경 넓은 면 |
| 불빛·강조 | `#D9822B` `#F2B544` | 불, 가로등, **UI 강조 한 가지** | 위험 표시 |
| 글자 | `#E6E0D2`(밝은 종이색), `#22201E`(쪽지 위 잉크) | UI 글자 | 순수 흰색 `#FFFFFF` |

- 채도: 세상은 **낮게**(회청색), 진한 색은 초록·붉은·불빛 세 가지만.
- 시간대: 낮 = 바랜 회청색, 저녁 = 불빛 주황이 살짝, 밤 = 푸른 어둠 + 광원만 밝음.

## 3. 그래픽

| 항목 | 규칙 |
|---|---|
| 시점 | **비스듬한 탑뷰(3/4)**: 위에서 약 30° 기울임. 땅은 위에서, 차·건물·사람은 앞면이 조금 보임. 그림자는 오른쪽 아래로 짧게 |
| 크기 | 캐릭터 64×64 칸, **키 약 36px**(지금 기준). 소품도 같은 픽셀 크기(1 도트 = 화면 같은 배율), 크기 섞지 않음 |
| 외곽선 | 캐릭터: 짙은 회청색 1px(`#1B2026`), 순수 검정 금지. 배경 소품: 외곽선 없이 명암으로 |
| 명암 | 물체마다 **3단**(어둠·중간·밝음) + 필요하면 반사 1단. 그라데이션·흐림 금지 |
| 빛 방향 | 왼쪽 위에서. 모든 그림 같은 방향 |
| 소품 밀도 | 화면에 **"이야기를 하는 소품"**을 항상 몇 개: 버려진 차·버스, 넘어진 오토바이, 한글 간판, 피난 안내문, 방사능 표지, 쓰레기·종이. 빈 바닥이 화면 절반을 넘지 않게 |
| 장소 정체성 | 한국 도시: 아파트·상가 간판(한글), 편의점, 지하철 입구, 전선, 버스 정류장 |

## 4. 캐릭터

- 그림체 하나: **AI 그림 외형(붉은 재킷 주인공)을 기준**, 피폭체·사람도 같은 화풍·외곽선·명암으로 다시 맞춘다(지금 섞인 3D 도트·예전 도트는 교체 대상).
- 얼굴 일관성 최우선(AGENTS.md 2장 FACE-R1).
- 피폭체: 피부 회녹색, 상처·빛은 위험 초록. 사람(군인·시민)은 회청 계열 옷 + 작은 색 하나.
- 몸과 무기는 따로(손·총구 기준점).

## 5. 빛·효과

| 항목 | 규칙 |
|---|---|
| 광원 | 불·가로등·불탄 차 = 따뜻한 주황. 피폭체 빛 = 초록. 그 밖엔 빛 없음 |
| 그림자 | 캐릭터·소품 발밑에 짙은 회청색 타원(반투명 대신 디더링 점무늬) |
| 입자 | 재(낙진)가 늘 조금씩, 가끔 비. 먼지·피는 바닥색에 맞춰 |
| 화면 효과 | 가장자리 어둡게(약하게), 맞으면 붉은 번쩍임(있음). 색수차·필름 잡티는 쓰지 않음 |
| 손맛 색 | 타격 불꽃 = 밝은 종이색, 피 = 붉은색(사람: 방울 `#6E0C0E`, 바닥 `#460A0C`)·탁한 검녹색(피폭체: 방울 `#344422`, 바닥 `#202C18`) — 2026-11-26 사용자 "해 보기", [시험] |

## 6. UI — "주인공이 들고 다니는 물건"

| 요소 | 규칙 |
|---|---|
| 판 | 짙은 회청색 금속판 `#262D35` + **녹슨 청회색 테두리 1~2px** + 모서리 리벳/나사 장식. 둥근 모서리·반투명 유리 금지 |
| 쪽지·종이 | 목표·안내는 테이프 붙인 종이(`#E6E0D2`)에 잉크 글자 — 지금 쪽지 유지 |
| 강조색 | **불빛 주황 한 가지**(선택·중요 숫자). 초록은 위험에만 |
| 막대 | 칸 나눈 눈금 막대(체력·탄약·충전). 부드러운 그라데이션 막대 금지 |
| 글꼴 | 도트 한글 하나(Galmuri), 정해진 크기 2단계(본문·제목), 글자 테두리 1px |
| 아이콘 | 16×16 / 32×32 도트, 세상 그림과 같은 명암·빛 방향 |
| 배낭·물건 설명 | 같은 금속판 양식, 수치는 눈금 막대 + 숫자 |

## 7. UX — 정보는 어디에

| 정보 | 위치 |
|---|---|
| 탄약·재장전 | **조준점 옆** 작게(덜 밝은 색) + 재장전 눈금 |
| 체력 | 화면 왼쪽 아래(지금 자리) |
| 구르기 횟수 | 발밑 점(지금) |
| 목표 | 왼쪽 위 쪽지(접고 펴기) |
| 조작 안내 | 왼쪽 가장자리 작게, 처음 몇 번만. 머리 위에 겹치지 않음 |
| 위험 | 세상 안(바닥 빨간 범위, 초록 빛), 화면 밖 원거리 공격만 가장자리 초록 화살표 |
| 알림 | 오른쪽 위 작은 금속판, 잠깐 |

## 8. 금지 목록

- 둥근 카드·알약 칩·옆 색 띠·반투명 유리·부드러운 그림자(AI 티)
- 순수 흰색·순수 검정, 무지개처럼 많은 색
- 한 화면에 그림체 두 가지(3D 도트 + AI 그림 + 예전 도트 섞기)
- 크기가 다른 픽셀 섞기(확대·축소한 그림 그대로)
- 초록을 위험 말고 다른 데 쓰기

## 9. 점검표 (그림·UI를 보여 주기 전에)

- [ ] 색이 2장 팔레트 안인가(견본과 비교), 강조는 주황 하나, 초록은 위험뿐
- [ ] 시점 3/4, 빛은 왼쪽 위, 그림자 오른쪽 아래
- [ ] 캐릭터 키 36px 안팎, 외곽선 짙은 회청색 1px, 명암 3단
- [ ] 같은 화면의 다른 그림과 화풍·픽셀 크기가 같은가
- [ ] UI는 금속판·종이·눈금 막대 규칙, 금지 목록 없음
- [ ] 정보가 7장 자리에 있는가
- [ ] 게임 화면(낮·밤)에 넣어 나란히 비교했는가
