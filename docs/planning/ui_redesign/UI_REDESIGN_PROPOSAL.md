# UI 전면 개편 제안 (2026-11-16)

사용자: "UI가 너무 조잡해, 깔끔하게 다 바꿔야 해. 너가 잘 생각해 봐. 그리고 어떻게 바꾸면 좋을지 나한테 제안해. 여러 곳에서 조사했었잖아? 어떤 UI가 좋을지 최종 이미지를 나한테 보여 줘."

상태: **1차 제안, 사용자 "AI 느낌이 강하다" → 2차로 대체.** 2차: [UI_NOT_AI_RESEARCH.md](../../research/UI_NOT_AI_RESEARCH.md), [v2_play.png](v2_play.png), [v2_bag.png](v2_bag.png). 아래는 1차 기록.
그림: [지금 vs 제안: 게임 화면](compare_play.png), [지금 vs 제안: 배낭](compare_bag.png).
그림은 실제 게임 화면(HUD를 끈 것) 위에 제안 UI를 그린 것이다. 만든 도구: `tools/ui/ui_capture.py`, `tools/ui/ui_mockup.py`.

## 1. 지금이 조잡해 보이는 이유

1. **회색 테두리 상자가 화면의 1/4을 덮는다.** 목표·상태·빠른 칸이 모두 같은 굵기의 상자라 눈이 갈 곳이 없다.
2. **글꼴이 개발용 고정폭 글꼴이다**(Consolas+맑은 고딕 혼합). 숫자와 한글 굵기가 따로 놀고 게임 글씨처럼 안 보인다.
3. **필요 없는 정보가 많다.** "남은 피폭체 3 · 쓰러진 횟수 0", "체력" 이름표, 빈 빠른 칸, "Tab 배낭 무게 0.6/2.0" 글자가 늘 떠 있다.
4. **상태 칸이 납작한 색 블록이다.** 빨강·갈색 사각형이 경고처럼만 보이고 어떤 게 급한지 모른다.
5. **배낭이 빈 격자 15칸이다.** 물건은 2개인데 빈칸이 13개라 허전하고, 몸 그림은 회색 덩어리다.
6. **효과를 덧붙이기만 하고 전체를 정리한 적이 없다**(ART_FEEDBACK 3-16과 같은 실수).

## 2. 원칙 (조사에서 고른 것)

| 원칙 | 근거 |
|---|---|
| **상자를 없앤다.** 화면 위 UI는 글자와 얇은 막대만, 그림자로 읽히게 | 좀보이드 게임 화면은 작은 아이콘·막대만 띄우고 창은 필요할 때만 연다(Zombode/ui 메모). 커뮤니티 단점 "UI가 복잡하다"를 피함 |
| **필요할 때만 보인다.** 빈 칸, 이름표, 통계는 숨김. 줍기는 물건 옆에 `[E] 통조림` | 좀보이드 근처 물건 표시, 첫 안내를 줄이는 방향(커뮤니티 조사 6-1) |
| **상태는 느끼게.** 출혈이면 화면 가장자리가 붉어지고, 공황은 표시 없이 시야가 좁아짐 | 사용자 "긴장 공황 상태 표시하는 게 별로임"(v6.0) |
| **색은 세 가지만.** 글자 흰색, 위험 빨강, 물건·조작 호박색 | 한 화면의 강조색이 많으면 아무것도 강조되지 않음 |
| **배낭은 목록형.** 아이콘·이름·개수·무게 한 줄씩, 고른 줄만 밝게 | 좀보이드 인접 보관함 목록(Zombode/ui 메모). 물건이 적은 우리 게임에 격자보다 맞음 |
| **글꼴 하나.** 깔끔한 한글 글꼴 하나로 굵기만 바꿈 | 그림의 글꼴은 컴퓨터에 이미 있는 Noto Sans KR(무료, OFL) |

## 3. 바뀌는 것

### 게임 화면
| 자리 | 지금 | 제안 |
|---|---|---|
| 왼쪽 위 | 상자 안 목표 + 남은 피폭체·쓰러진 횟수 | 작은 "목표" + 목표 한 줄 + 챙긴 물자. 상자 없음, 통계는 구역 요약으로 |
| 왼쪽 아래 | 상자 안 "체력" 막대 + 색 블록 3개 | 큰 숫자 `58%` + 얇은 막대(맞은 만큼 흐린 꼬리). 그 아래 둥근 작은 칩(●출혈) |
| 가운데 아래 | 테두리 상자 3칸 + "Tab 배낭 무게" 글자 | 둥근 반투명 칸(빈 칸은 희미한 선만), 칸 아래 얇은 무게 선, 작은 "Tab 배낭" |
| 메시지 | 화면 가운데 노란 글자 | 빠른 칸 바로 위, 그림자 글자, 서서히 사라짐(그대로) |
| 줍기 | 화면 아래 안내 | 물건 옆에 `[E] 통조림` 칩 |
| 출혈·저체력 | 아이콘만 | 화면 가장자리가 붉게(체력이 낮을수록 진하게) |

### 배낭(Tab)
| 지금 | 제안 |
|---|---|
| 상자 3개가 따로 떠 있음 | 한 장의 판에 세 칸(몸 · 배낭 · 근처), 얇은 구분선 |
| 빈 격자 15칸 | 목록: 아이콘·이름·×개수·무게. 고른 줄은 호박색 띠 |
| 회색 덩어리 몸 | 얇은 선 사람 그림 + 다친 자리에 점, 옆에 "물림 · 오른팔 / 출혈" |
| 글자 안내 "방향키/WASD 선택 · Enter 사용 · X 버리기" | 키 모양 칩 `Enter` 사용 · `X` 버리기 · `W S` 고르기 |
| 붕대 설명 "체력 +1"(옛날 값) | "가장 심한 상처의 출혈을 멈추고 체력 +15%" |

## 4. 고를 것 (사용자)

1. **이 방향으로 갈지**: 상자 없는 미니멀 + 목록형 배낭.
2. **글꼴**: (가) 그림 그대로 Noto Sans KR(설치돼 있음, 깔끔) / (나) 도트 그림에 맞춘 도트 한글 글꼴(무료 Galmuri, 내려받기 허락 필요).
3. **출혈 시 붉은 가장자리**: 넣을지.

고르면 `hud.py`를 이 그림대로 다시 짜고, 실제 게임 화면을 다시 찍어 이 그림과 나란히 비교해 보여 준다.
