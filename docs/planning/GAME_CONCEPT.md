# 「부산까지」 콘셉트와 핵심 재미

2026-11-08 · 방향 확정본 v2 (턴제 파티)

## 한 문장 콘셉트

핵 재난으로 폐허가 된 서울의 방공호에서 동료를 모아, 피폭체와 생존자가 뒤섞인 길을 턴제 전술 전투로 돌파하며 **부산까지 함께 도착하는** 횡스크롤 턴제 파티 RPG.

## 확정한 방향

| 항목 | 결정 |
| --- | --- |
| 장르 | 실시간 탐색 + 턴제 파티 전투. 전투 규칙은 발더스 게이트 3의 행동 자원과 주사위 판정 구조를 참고해 단순화한다. |
| 파티 | 주인공 + 방공호에서 모집한 동료 최대 2명 |
| 스킬 | 약한 스킬은 재사용 대기 턴, 강한 스킬은 휴식으로 회복하는 사용 횟수. 사용에 따른 다른 대가는 없다. |
| 휴식 | 짧은 휴식(필드, 횟수 제한)과 긴 휴식(거점, 야영 물자 필요)으로 체력과 스킬을 회복한다. |
| 성장 | 전공서를 읽혀 파티원의 능력을 영구적으로 올린다 |
| 적 | 방사능으로 변이한 피폭체, 적대 생존자 |
| 캐릭터 표현 | 얼굴이 보이는 도트와 초상화. 방독면은 선택 장비로 바꾼다. |
| 제외 | 방독면 필터 자원, 실시간 액션 전투, 스킬·주사기의 피폭 대가와 중독 |

## 핵심 재미

**누구를 데려가고, 매 턴 어떤 자원을 어디에 쓰고, 강한 스킬을 언제 아낄지 판단한다.**

- **파티 구성** — 방공호의 생존자 가운데 누구와 떠날지 고른다. 데려가지 않은 사람의 이야기도 이어진다.
- **전술 전투** — 이동·행동·보조 행동을 나눠 쓰고, 명중 확률과 위치(엄폐, 측면, 밀치기)를 따져 고른다. 주사위가 긴장감을 만든다.
- **자원 운영** — 강한 스킬과 휴식에 쓸 야영 물자는 한정돼 있다. 지금 쓸지 보스까지 아낄지 고민한다.
- **육성 선택** — 전공서 한 권은 한 명만 읽을 수 있다. 누구에게 줄지가 파티의 색깔을 정한다.

## 게임 흐름

1. **방공호** — 동료를 모집하고 물자를 고른 뒤 출발한다.
2. **지상 탐색** — 실시간으로 걸어 다니며 물자와 전공서를 찾고 생존자를 만난다.
3. **조우** — 대화·거래로 풀거나, 들키거나 먼저 공격하면 그 자리에서 턴제 전투로 바뀐다.
4. **짧은 휴식** — 전투 사이에 필드에서 체력 일부와 일부 스킬을 회복한다.
5. **중간 거점** — 야영 물자로 긴 휴식을 하고, 전공서를 읽히고, 피폭을 치료한다.
6. **부산 도착** — 파티원의 생존 여부와 관계에 따라 엔딩이 갈린다.

## 방공호의 파티 모집

방공호에 동료 후보 3~4명이 있고, 그중 최대 2명을 데리고 떠난다. 혼자 떠날 수도 있다. 난이도가 높은 대신 물자를 혼자 쓴다.

| 후보 (예시) | 역할 | 데려가는 조건 |
| --- | --- | --- |
| 전직 간호사 | 치유. 붕대 효율이 높고 쓰러진 동료를 멀리서도 일으킨다. | 대화로 설득한다. |
| 공사장 인부 | 근접 탱커. 체력과 힘이 높고 밀치기에 강하다. | 통조림을 나눠 준다. |
| 고등학생 | 빠르고 회피가 높다. 이동 거리가 길고 기습에 유리하다. | 기본적으로 따라오려 한다. |
| 수상한 남자 | 방사능 능력자. 강한 스킬 사용 횟수가 많지만 체력이 낮다. | 해독약을 요구한다. |

데려가지 않은 후보는 이후 구간에서 우호 생존자로 다시 만나거나, 피폭체로 변해 있거나, 적대 세력이 되어 있을 수 있다. 이름과 세부 능력치는 시제품에서 정한다.

## 턴제 전투

### 참고한 발더스 게이트 3의 구조

| 발더스 게이트 3 | 이 게임의 적용 |
| --- | --- |
| 턴마다 이동·행동·보조 행동·반응 네 가지 자원 | 이동·행동·보조 행동 세 가지 + 자동 반응(기회 공격) 하나로 단순화 |
| 20면체 주사위 + 보정치를 방어도와 비교, 20 치명타 | 그대로 사용 |
| 유리함·불리함(주사위 두 개 중 높은/낮은 값) | 기습·측면·엄폐 등에 사용 |
| 고지대 +2 / 저지대 -2 | 횡스크롤이라 높이 대신 엄폐와 측면으로 대체 |
| 밀치기, 낙하·충돌 피해 | 밀치기를 보조 행동으로, 장애물 충돌 피해와 넘어짐 |
| 지형 표면(기름, 물, 불, 전기) | 방사능 웅덩이, 기름(불붙이기) 두 가지로 시작 |
| 주문 슬롯과 휴식 회복, 짧은 휴식 2회와 긴 휴식(야영 물자) | 강한 스킬 사용 횟수, 짧은 휴식 2회, 거점 긴 휴식(통조림·생수 소모) |
| 쓰러짐, 사망 내성 굴림 3회, 도움 행동으로 일으키기 | 그대로 사용 |

### 전투 전환과 기습

- 탐색은 실시간으로 이동한다. 피폭체에게 들키거나 플레이어가 먼저 공격하면 같은 화면에서 전투로 바뀐다.
- 들키기 전에 먼저 공격하면 **기습**이다. 기습당한 적은 첫 라운드에 행동하지 못한다.
- 전투가 끝나면 같은 자리에서 탐색으로 돌아간다.

### 전투판

- 현재 도로 화면의 바닥을 **가로 12칸 × 깊이 3칸** 격자로 나눈다.
- 폐차·상자 같은 장애물은 엄폐물이다. 공격 방향과 대상 사이에 엄폐물이 있으면 방어도가 오른다.
- **측면** — 아군 두 명이 적을 양쪽에서 끼면 공격에 유리함을 얻는다.
- **지형 표면** — 방사능 웅덩이는 들어간 캐릭터의 피폭 수치를 올린다. 기름 웅덩이에 불을 붙이면 위에 있는 대상이 불탄다.

### 턴 자원

| 자원 | 한 턴에 | 쓰는 곳 |
| --- | --- | --- |
| 이동 | 정해진 칸 수 | 칸 이동. 행동을 써서 질주하면 이동 칸이 두 배 |
| 행동 | 1회 | 공격, 강한 스킬, 아이템 던지기, 도움(쓰러진 동료 일으키기), 질주 |
| 보조 행동 | 1회 | 밀치기, 붕대 사용, 피폭 주사기, 약한 스킬, 숨기 |
| 반응 | 라운드당 1회, 자동 | 기회 공격: 인접한 적이 멀어지면 자동으로 한 번 공격 |

### 주사위 판정

- **선공** — 전투 시작 시 모두 20면체 주사위 + 민첩으로 행동 순서를 정한다.
- **명중** — 20면체 주사위 + 명중 보너스가 대상 방어도 이상이면 맞는다. 행동을 확정하기 전에 명중 확률(%)을 보여준다.
- **유리함과 불리함** — 주사위를 두 번 굴려 높은 값 또는 낮은 값을 쓴다.
- **피해** — 무기 주사위 + 힘. 예: 방망이 1d6 + 힘.
- **치명타와 실패** — 20이면 피해 주사위를 두 배로 굴리고, 1이면 반드시 빗나간다.
- **밀치기** — 힘 대결 굴림에서 이기면 대상을 1칸 밀어낸다. 장애물에 부딪히면 추가 피해를 주고 넘어뜨린다.

### 쓰러짐

- 체력이 0이 된 파티원은 쓰러진다. 쓰러진 파티원은 자기 턴마다 사망 내성 굴림을 한다. 성공 3번이면 안정, 실패 3번이면 사망한다.
- 옆 칸의 동료가 행동을 써서 도우면 체력 1로 일어난다. 붕대나 치유 스킬로도 일으킬 수 있다.
- 주인공이 사망하면 패배하고 구간을 다시 시작한다. 동료가 사망하면 그 여정에서 잃는다.

## 스킬과 휴식

| 구분 | 회복 방법 | 예시 |
| --- | --- | --- |
| 약한 스킬 | 재사용 대기 턴 | 응급 처치(간호사), 도발(인부) |
| 강한 스킬 | 사용 횟수. 짧은 휴식이나 긴 휴식으로 회복 | 강한 밀치기, 방사 폭발 |

### 주인공 스킬 후보

| 스킬 | 종류 | 효과 |
| --- | --- | --- |
| 강한 밀치기 | 강한 스킬 | 대상을 2칸 날린다. 장애물에 부딪히면 추가 피해와 기절 |
| 방사 폭발 | 강한 스킬 | 주변 모든 칸에 피해 |
| 감지 | 약한 스킬 | 적의 방어도와 남은 체력을 보여주고 아군 명중을 올린다 |

### 휴식

- **짧은 휴식** — 전투 밖 필드에서 긴 휴식 사이에 2번까지 한다. 파티 체력의 절반과 일부 강한 스킬을 회복한다.
- **긴 휴식** — 거점에서 야영 물자(통조림·생수)를 써서 한다. 체력과 모든 스킬 사용 횟수, 짧은 휴식 횟수를 회복한다. 물자가 부족하면 절반만 회복한다.

### 피폭 주사기

- 개수가 제한된 강화 소모품이다. 보조 행동으로 사용하면 그 파티원은 몇 턴 동안 명중과 피해가 오른다.
- 중독이나 피폭 같은 다른 대가는 없다. 귀하기 때문에 언제 쓸지가 판단이 된다.

## 피폭 수치

환경 위험으로만 다룬다. 스킬과 주사기는 피폭 수치를 올리지 않는다.

- 오염 구역, 방사능 웅덩이, 방사 피폭체의 공격으로 오른다.
- 해독약과 거점 치료로 내려간다. 방독면을 쓴 파티원은 오염 구역에서 덜 오른다.
- 단계별 불이익: 낮음(없음) / 중간(명중 감소) / 높음(턴마다 체력 감소)

## 전공서

책을 주우면 파티원 한 명이 읽고 영구적으로 능력이 오른다. 한 권은 한 명만 읽을 수 있다.

| 책 | 효과 | 어울리는 파티원 |
| --- | --- | --- |
| 의학 전공서 | 붕대 회복량 증가, 휴식 회복량 증가 | 간호사 |
| 체육학개론 | 힘 증가(근접 피해와 밀치기 증가) | 인부 |
| 심리학개론 | 대화 설득 성공률 증가 | 주인공 |
| 방사선학개론 | 피폭 상승량 감소, 강한 스킬 사용 횟수 +1 | 수상한 남자 |
| 기계공학개론 | 잠긴 문 열기, 장애물 충돌 피해 증가 | 아무나 |

## 적

| 종류 | 특징 |
| --- | --- |
| 일반 피폭체 | 가까운 대상에게 다가가 할퀸다 |
| 돌진 피폭체 | 직선으로 여러 칸 돌진한다. 경로를 비키거나 엄폐로 막는다 |
| 방사 피폭체 | 공격이 피폭 수치를 올리고, 죽으면 방사능 웅덩이를 남긴다 |
| 적대 생존자 보스 | 강한 스킬과 피폭 주사기를 쓰는 사람. 구간의 마지막 적 |

## 생존자 관계

발밑 원으로 관계를 표시한다. 미확인은 회색 원과 `?`, 우호는 초록, 적대는 빨강이다. 미확인·우호 생존자와는 대화와 거래를 할 수 있고, 적대 생존자와는 전투가 시작된다.

## 엔딩

| 엔딩 | 조건 (초안) |
| --- | --- |
| 함께 도착 | 모집한 동료가 모두 살아서 도착했다 |
| 홀로 도착 | 동료를 모두 잃었거나 혼자 출발했다 |

## 캐릭터 표현

- 파티 구분과 애착을 위해 모든 캐릭터의 얼굴이 보이게 한다. 현재 방독면 주인공 도트는 얼굴이 보이는 도트로 다시 만든다.
- 대화창, 턴 순서 표시, 파티 상태창에 초상화를 넣는다.
- 방독면은 장비 아이템으로 남긴다.
- 턴제 전투에 필요한 동작은 대기·걷기·공격·피격·쓰러짐이다. 동료 도트와 같은 기준으로 함께 만든다.

## 구현 순서

1. **전투판과 전환** — 격자, 탐색에서 전투로 전환하고 끝나면 복귀
2. **턴 순서와 이동** — 선공 굴림, 이동 범위 표시, 턴 자원 표시
3. **주사위 공격** — 명중 확률 UI, 피해, 치명타, 유리함·불리함
4. **피폭체 AI** — 가까운 대상에게 이동하고 공격, 기회 공격
5. **승패와 복귀, 쓰러짐과 도움**
6. **엄폐·측면·밀치기**
7. **스킬과 휴식**
8. **방공호 동료 모집과 파티 턴**
9. **전공서, 지형 표면, 보스, 나머지 적과 구간 연결**

## 방향 결정 기록

- **실시간 액션 시제품** — 걷기·조용히 걷기·대시·방망이 공격, 돌진 감염자와 일반 감염자(추격·할퀴기), 폐차 밀치기와 충돌 다운을 Pico2D에서 구현하고 확인했다. 이동·맵·방공호·배낭·생존자 관계 표시는 턴제에서도 그대로 쓴다.
- **2026-11-08 결정 과정** — 실시간 생존 탐색 → 방사능의 힘과 대가 → 실시간 액션 → 턴제 파티 RPG 순서로 검토했다. 파티 운영과 육성, 주사위 판정의 긴장감을 원해 턴제를 택했다. 전투 규칙은 발더스 게이트 3의 구조를 조사해 기반으로 삼았다. 범위는 적 3종과 보스 1명, 동료 2명, 전투 맵 3~4개로 제한한다.
- **제외한 요소** — 방독면 필터(피폭 수치와 역할이 겹치고 얼굴을 가림), 실시간 액션 전투, 스킬과 주사기의 피폭 대가·중독(규칙을 단순하게 하고 전술 판단에 집중), 생화학 테러 세계관, 정해진 선택 장면과 대본식 분기.
