# 「부산까지」 콘셉트와 핵심 재미

2026-11-08 · 방향 확정본

## 한 문장 콘셉트

핵 재난으로 폐허가 된 서울에서, 방사능이 준 힘으로 피폭체 무리를 쓸어내며 **부산까지 사람으로 도착해야 하는** 횡스크롤 액션 게임.

## 확정한 방향

| 항목 | 결정 |
| --- | --- |
| 장르 | 벨트스크롤 액션 + 가벼운 생존. 전투는 콤보·회피·스킬의 손맛을 중심에 두고, 구간 사이에는 필터·해독약·물자를 정비한다. 턴제 전투는 쓰지 않는다. |
| 핵심 장치 | 방사능의 힘(스킬)과 대가(피폭 수치) |
| 적 | 방사능으로 변이한 피폭체 |
| 생존자 | 각자 방사능 능력과 피폭 상태를 가진 사람. 미확인·우호·적대로 나뉜다. |
| 주제 | 부산까지, 사람으로 도착할 수 있는가 |
| 주인공 | 현재 방독면 생존자 도트를 그대로 사용한다. 피폭 정도는 색과 빛 효과로 덧입힌다. |

## 핵심 재미

**공격을 읽고 아슬아슬하게 피한 뒤 콤보를 꽂고, 방사능의 힘을 얼마나 빌릴지 판단한다.**

- **손맛 있는 근접 액션** — 방망이 콤보, 모아 치기, 회피 반격으로 피폭체 무리를 쓸어낸다.
- **힘을 빌릴수록 강해지고 위험해진다** — 방사능 스킬은 전투를 뒤집는다. 대신 쓸 때마다 피폭 수치가 오른다.
- **행동이 곧 선택** — 스킬을 쓸지 아낄지, 물자를 챙길지 서둘러 떠날지, 생존자와 거래할지 싸울지가 다음 구간과 엔딩을 바꾼다.

## 액션 전투

| 요소 | 내용 |
| --- | --- |
| 콤보 | 좌클릭 연타로 3타 콤보. 3타째는 적을 날려 넘어뜨린다. |
| 모아 치기 | 좌클릭을 길게 눌렀다 떼면 강공격. 막거나 버티는 적을 깨뜨린다. |
| 추가타 | 넘어진 적을 추가로 칠 수 있다. |
| 회피 | Space 대시에 짧은 무적 시간을 둔다. 공격 직전에 피하면 시간이 잠깐 느려지고 반격 기회가 생긴다. |
| 반격 | 회피 직후 공격하면 강한 반격이 나간다. |
| 환경 | 폐차 등 장애물로 날린 적은 더 오래 쓰러지고 추가 피해를 받는다. |
| 연출 | 타격 순간 짧은 히트스톱, 화면 흔들림, 타격음. 적은 움찔·넘어짐·날아감 세 가지로 반응한다. |
| 적 구성 | 피폭체가 무리로 몰려온다. 구간 끝에서 스킬을 쓰는 적대 생존자 보스를 만난다. |

평소 전투는 방망이와 회피만으로 이길 수 있어야 한다. 스킬은 무리에 둘러싸이거나 보스와 싸울 때 상황을 뒤집는 수단이며, 피폭 대가 때문에 매번 쓸지 고민하게 만든다.

## 방사능의 힘과 대가

강해지는 부분은 영구적으로 쌓이고, 대가는 관리할 수 있게 나눈다. 힘과 대가가 똑같이 늘면 강해지는 느낌이 사라지기 때문이다.

| | 강해지는 부분 | 대가 |
| --- | --- | --- |
| 대상 | 스킬 해금과 강화 | 피폭 수치 |
| 변화 | 한번 얻으면 사라지지 않는다. 구간을 지날수록 주인공이 확실히 세진다. | 스킬을 쓰거나 오염 구역에 머물면 오른다. 거점 치료와 해독약으로 내려간다. |
| 느낌 | 갈수록 강해진다 | 아껴 쓰면 버티고, 남용하면 망가진다 |

피폭 수치는 일정 선을 넘을 때만 불이익이 생긴다.

| 단계 | 상태 |
| --- | --- |
| 낮음 | 불이익 없음 |
| 중간 | 시야가 흐려지고 화면 가장자리가 어두워진다 |
| 높음 | 체력이 서서히 줄어든다 |

### 스킬 후보

| 스킬 | 효과 | 쓰는 상황 |
| --- | --- | --- |
| 강한 밀치기 | 앞쪽 피폭체를 멀리 날려 다운시킨다 | 길을 열거나 폐차로 날릴 때 |
| 돌진 타격 | 앞으로 빠르게 돌진하며 경로의 적을 친다 | 거리를 좁히거나 포위에서 빠져나올 때 |
| 방사 폭발 | 주변 적을 모두 밀어내고 넘어뜨린다 | 둘러싸였을 때 |

스킬마다 쿨타임이 있고 쓸 때마다 피폭 수치가 오른다. 피폭 수치가 높을수록 스킬 위력도 커지지만 불이익 단계에 가까워진다. 강한 밀치기 하나를 먼저 구현해 손맛과 피폭 대가를 확인한 뒤 나머지를 추가한다. 스킬 키, 쿨타임, 얻는 시점과 수치는 시제품에서 정한다.

### 필터와 피폭의 관계

방독면 필터는 일반 오염으로부터 몸을 지켜 피폭 수치가 저절로 오르지 않게 한다. 필터가 떨어지면 지상에 있는 동안 피폭 수치가 계속 오른다. 따라서 필터는 버티는 자원이고, 스킬은 그 버틴 몸을 대가로 쓰는 선택이다.

## 피폭체

방사능으로 변이한 사람들이다. 주인공과 같은 힘에 먹힌 결과라서, 주인공이 스킬을 남용하면 같은 길을 걷게 된다. 무리로 등장하며, 한 번에 공격하는 수를 제한해 둘러싸여도 예고를 읽을 수 있게 한다.

| 종류 | 행동 | 상태 |
| --- | --- | --- |
| 일반 피폭체 | 플레이어를 좌우·앞뒤로 걸어서 쫓고, 폐차를 우회하며, 가까이서 예고 후 제자리에서 할퀸다. 체력과 피격 반응 추가 예정 | 이동·공격 구현됨 |
| 돌진 피폭체 | 몸을 낮춰 돌진 경로를 예고한 뒤 직선으로 돌진한다 | 이전 시제품을 특수 개체로 재사용할 후보 |
| 방사 피폭체 | 주변의 피폭 수치를 올린다. 오래 근처에 있으면 위험하다 | 후보 |

방망이 밀치기와 폐차 충돌 다운은 모든 피폭체에 공통으로 적용한다.

## 생존자

다른 생존자들도 방사능의 힘을 가진 사람들이다. 그 힘을 어떻게 쓰느냐에 따라 우호와 적대가 갈린다. 관계 표시는 [PRD](../../PRD.md)의 발밑 원(회색 `?`, 초록, 빨강)을 그대로 쓴다.

| 관계 | 성격 | 플레이어와의 관계 |
| --- | --- | --- |
| 미확인 | 처음 만난 상태. 능력도 태도도 모른다. | 대화와 관찰로 알아낸다. |
| 우호 | 힘을 아끼며 버티는 사람 | 해독약·필터 교환, 스킬 강화 방법이나 안전한 길 정보 |
| 적대 | 힘에 취해 물자를 빼앗는 사람 | 스킬을 쓰는 강한 적. 구간의 보스 역할을 하고, 쓰러뜨리면 물자를 얻는다. |

- 피폭이 심한 생존자는 몸에 빛나는 상처가 보인다. 겉모습으로 위험을 짐작할 수 있지만 확정 정보는 아니다.
- 우호 생존자도 힘을 너무 쓰면 피폭체로 변할 수 있다. 해독약을 나눠 주지 않으면 다음 구간에서 변해 있을 수 있다.
- 생존자는 주인공에게 "나도 저렇게 될 수 있다"는 거울이다.

## 엔딩

부산 도착 시점의 피폭 수치로 엔딩을 나눈다.

| 엔딩 | 조건 |
| --- | --- |
| 사람으로 도착 | 피폭 수치를 낮게 관리하고 도착 |
| 변이 직전의 도착 | 피폭 수치가 높은 채로 도착 |

체력이 0이 되면 해당 구간을 다시 시작한다. 엔딩 수와 경계값은 구간이 완성된 뒤 조정한다.

## 첫 플레이 장면

방공호에서 지상으로 나오면 오른쪽 끝에 다음 대피소 문이 보인다. 도로를 따라가면 피폭체가 두세 마리씩 몰려오고, 길 중간에 폐차와 예비 필터가 있다.

| 순간 | 플레이어가 하는 일 | 판단 |
| --- | --- | --- |
| 첫 무리 | 콤보로 한 마리를 넘어뜨리고, 다른 피폭체의 할퀴기 예고를 보고 회피 반격한다 | 맞지 않고 이기는 법을 익힌다 |
| 폐차 앞 | 피폭체를 폐차 쪽으로 날려 오래 쓰러뜨린다 | 위치를 잡으면 싸움이 쉬워진다 |
| 포위 | 방사 폭발로 무리를 밀어낼지, 대시로 빠져나와 버틸지 고른다 | 스킬을 쓰면 편하지만 피폭 수치가 오른다 |
| 출구 앞 | 예비 필터를 챙기러 돌아갈지 바로 들어갈지 고른다 | 물자와 체력·필터의 교환 |

## 구현 순서

1. **전투 손맛** — 피폭체 체력과 피격 반응, 방망이 3타 콤보, 히트스톱과 화면 흔들림, 플레이어 피격과 대시 무적.
2. **피폭체 무리** — 두세 마리 동시 등장과 동시 공격 수 제한.
3. **필터와 피폭 수치, 강한 밀치기** — HUD 표시, 스킬 쿨타임과 피폭 대가 연결.
4. **회피 반격과 모아 치기**
5. **적대 생존자 보스 한 명과 생존자 거래**
6. **구간 연결과 엔딩** — 3구간과 피폭 수치에 따른 엔딩 두 가지.

관련 문서 [요구사항](../../PRD.md) · [개발 계획](../../PLAN.md)

## 시제품 기록

- **돌진 감염자 시제품** — 지상 구간에 돌진하는 적 한 마리와 폐차 한 대를 배치했다. 예고 후 직선 돌진, 회피 뒤 방망이 밀치기, 폐차 충돌 다운(1.65초)과 일반 밀치기 다운(0.38초)을 Pico2D에서 확인했다.
- **일반 감염자로 전환** — 걸어서 추격하고 폐차를 우회하며 제자리에서 할퀴는 적으로 바꿨다. 깊이 추격, 정지 공격과 회피, 공격당 한 번의 피해, 폐차 우회와 밀치기 다운을 확인했다. 이번 방향 확정으로 이 적을 일반 피폭체로 부른다. 게임 안 문구는 다음 구현 때 바꾼다.
- **검토 후 제외한 방향** — 턴제 전투(시스템과 필요한 콘텐츠가 커서 기존 실시간 전투를 다시 만들어야 함), 은신 중심의 생존 탐색(전투 손맛이 약하고 반복이 빨리 느껴짐), 생화학 테러와 감염자 세계관(방사능의 힘과 연결되지 않음), 정해진 선택 장면과 대본식 분기(행동 자체가 선택이 되는 구조로 대체).
