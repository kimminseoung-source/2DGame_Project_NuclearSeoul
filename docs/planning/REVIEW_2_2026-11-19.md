## 5. 결정 기록

### A. 전투의 중심 (2026-11-19 정함)

- 사용자: "제가 생각했을 때는 2가지입니다. 총 기반 전투를 하거나, 신체 변형으로 전투를 하거나."
- 비교: 총 중심은 이미 있지만 흔한 좀비 슈팅이 되고 "왜 핵 재난인가"에 답하기 어렵다. 몸(변이) 중심은 핵 → 피폭 → 수정 → 변이 → 싸우는 방식이 이어지고 1차 발표의 "실시간 근접"을 지킨다.
- 걱정 "앞서 한 작업들이 쓸모없어지지 않나?" → 아니다. 시야·소리·디렉터·디펜스·타격감·부위 판정·출혈·배낭·개발 도구는 그대로. 공격은 `weapons.py` 데이터라 칼날 팔은 데이터 한 줄 + 새 동작(돌진, 여러 명, 이어치기). 근접 무기 5종은 "사람일 때" 무기로 남고(줄일지 보류 중), 알약은 정리 대상.
- **결정: 근접 중심, 총은 비상용.** "칼은 조용하고 위험하고, 총은 확실하고 시끄럽다. 변이하면 칼이 괴물이 된다."

### D 일부. 변이 방식 (2026-11-19 정함)

- 질문 "항시 변이가 되어 있나요?" → 세 안(영구 / 켜고 끄기 / 영구 + 부위마다 잃는 것) 중 **영구 + 부위별**.
- 부위 후보: 팔(칼날 / 그 손으로 총 못 잡음), 다리(빠름·도약 / 발소리 큼), 눈(밤에도 멀리 / 사람들이 무서워함), 피부(단단함·출혈 없음 / 회복 아이템이 덜 들음). 첫 번째로 만들 것은 **칼날 팔**.
- 전투 흐름: 사람일 때는 느리고 무겁게(일부러 빠르게 하지 않음), 칼날 팔은 준비 0.08초쯤, 돌진 베기, 여러 명 맞히기, 2타, 크게 날려 보냄, 강한 히트스톱. 흐름 그림을 대화에서 보여 줌(사람 3초 넘게 1명 조금 밀어냄 / 칼날 0.6초에 3명 날림).
- 무기 바꾸기: 사용자 "q로 무기를 바꿀 수 있게" → 세 안(다른 손으로 총 / 칼날 접기 / 그냥 무기 칸) 중 사용자 "다른 손으로 잡는 게 좋을 듯". **Q로 칼날 ↔ 총, 총은 왼손으로 쏨, 두 팔 다 바꾸면 총을 잃음.** 처음엔 한 손이라 조준이 흔들리게 하자고 했으나 사용자 "한 손으로 쏴서 조준이 흔들리는 요소는 빼자, 게임적 허용"으로 뺌.
- 화면: 왼쪽 아래 몸 그림(변이 부위만 보라), 옆에 수정 개수(길게 E로 먹기), 칼날 팔은 1번 칸에 늘 있음, 권총 칸에 상태 표시. 이어치기는 칼날 위에 잠깐.
