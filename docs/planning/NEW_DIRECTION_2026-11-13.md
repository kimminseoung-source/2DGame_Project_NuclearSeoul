# 새 기획 방향 정리 (2026-11-13, 사이드 대화)

사용자와 사이드 대화에서 처음부터 다시 정한 기획 방향. 2026-11-13 메인 세션에서 사용자 확인 후 PRD v4.0으로 반영.

## 고민의 출발점
- "기획을 어떻게 하는 게 재미있을까 계속 고민."
- 총으로 갈까 → 지금 만든 것이 모두 칼 기준이라 보류.
- "근접 전투를 하려면 다이내믹해야 하는데, 나는 현실적인 느낌을 좋아해서 덜 재미있는 것 같다."
- "현실적인 부분은 콘텐츠가 좋지 않으면 재미가 반감. 게임은 일상에서 못 하는 경험을 해야 재미있다."
- "지금까지 한 것은 흔하게 볼 수 있는 일반적인 게임 같다." → **"흔한 건 싫어."** (최우선 기준)
- "가장 중요한 건 전투 방식."
- 부위 전투(B안)도 괜찮다고 했으나 확정 전 "다시 처음부터 정하자."
- 스팀·인디 게임 조사 → **Katana Zero 전투 방식이 마음에 듦.**
- **"순수 횡스크롤로 가자."**
- **"공격 모션이 (Katana Zero와) 굉장히 비슷하면 좋겠음."**

## 확정
| 항목 | 결정 |
|---|---|
| 최우선 기준 | 흔한 것은 싫다 |
| 화면 | **순수 횡스크롤** (깊이 이동 없음, 좌우 + 점프 + 층/발판/계단) |
| 전투 참고 | **Katana Zero** (규칙과 손맛만 참고, 그림·캐릭터·이야기·이름은 우리 것) |
| 공격 모션 | **Katana Zero의 공격과 굉장히 비슷하게**: 마우스 방향으로 즉시 한 번 베기, 짧게 앞으로 튀어 나가는 동작, 크고 선명한 반달형 베기 궤적, 빠른 회전률 |
| 배경 | 핵 재난 이후 한국, 서울 → 부산 (1차 발표 유지) |
| 적 | 피폭체 = 피폭 한계를 넘어 죽은 사람이 변이한 것 (PRD 12 적 콘셉트 유지) |
| 차별점 | 시간을 느리게 하는 힘(변이 가속)의 대가가 **피폭 수치**. 쓸수록 주인공이 괴물에 가까워지고(겉모습 변화), 끝까지 차면 피폭체가 됨 |

한 문장: **"한 방이면 끝나는 짧은 싸움을 반복하며 부산으로 가는 길, 살아남으려 괴물의 시간을 빌릴수록 나도 괴물이 되어 간다."**

## Katana Zero 전투 규칙 → 우리 버전
| Katana Zero | 「부산까지」 버전 | 지금 있는 것 |
|---|---|---|
| 서로 한 방 | 피폭체 한 번에 쓰러짐. 주인공은 한 방 또는 2~3번(정할 것) | 체력 숫자 조정 |
| 마우스 방향 베기 | 좌클릭 → 마우스 방향으로 짧게 파고들며 한 번 벰 (연타 대신) | 반격 돌진(lunge) 재사용 |
| 총알 튕겨내기 | 방사 피폭체의 방사능 덩어리·적대 생존자 총알을 베어 되돌림 | 새로 |
| 구르기 | Space 대시 + 완벽 회피 | 있음 |
| 시간 느리게(배터리) | 변이 가속, 배터리 대신 피폭 수치 | 있음(손볼 것) |
| 짧은 방 + 즉시 재시작 | 짧은 구역(골목, 지하철 칸 등), 죽으면 그 구역 처음부터 | 구조 변경 |
| 주변 활용 | 폐차 밀치기, 문, 물건 던지기 | 일부 있음 |

## 횡스크롤 전환 시 바뀌는 것
- 이동: 위아래 이동 → 점프·중력·발판·계단 (동작 팩 `Jump_Start/Loop/Land`)
- 맵: 넓은 도로 → 한 줄 바닥 + 건물 안 층. 배경 그림은 대부분 재사용, 발판은 새로(Tiled/LDtk 검토)
- 적: 좌우·높이·발판 따라 추격
- 그대로: 주인공·피폭체 그림, 타격감, 회피·반격, 변이 가속, 피폭 수치

## 아직 정할 것 (Claude 추천)
1. 주인공 체력: 한 방 / **2~3번으로 시작해 보고 줄이기**
2. 구역 구조: **짧은 구역 + 즉시 재시작**
3. 튕겨내기: **넣기** (방사 피폭체 필요)
4. 공격: **마우스 방향 한 번 베기** (지금 3연타는 정리)
5. 피폭 수치: 구역 넘어가도 **일부 남음**, 겉모습 변화, 끝까지 차면 피폭체
6. 은신: 횡스크롤식(어두운 곳·배경에 숨기)으로 남길지 뺄지

## 주의
- 교수님 지침("1차 발표에서 크게 벗어나지 말 것"): 실시간 근접 전투·공격 예고 보고 피하기는 유지, 화면(1차 발표는 탑뷰)과 시간 능력은 바뀜 → 설명 필요.
- 난이도: 한 방 게임은 어려움. 처음엔 넉넉하게.
- 공격 모션은 "느낌"을 비슷하게 하되 Katana Zero의 그림·프레임을 베끼지 않는다(우리 3D 동작 → 2D 도트 방식으로 제작).
