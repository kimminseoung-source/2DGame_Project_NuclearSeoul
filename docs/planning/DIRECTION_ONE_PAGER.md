# 「부산까지」 방향 한 장 정리

작성 2026-11-12 · 기획 고민 정리용(미확정). 교수님 상담 때 그대로 보여 드릴 수 있게 썼다.

## 왜 정리하나

실시간 전투로 돌아온 뒤 "전투가 현실적이라 다소 지루하다"는 고민에서 변이 능력·결정 재화·피폭 주사기·총·시야 제한·탑뷰까지 아이디어가 이어졌다. 기능을 고르기 전에 **이 게임의 재미를 한 문장으로** 먼저 정한다. 그러면 필요한 기능과 버릴 기능이 갈린다.

## 1차 발표(2026-11-03)의 핵심

- 한 문장: **"남은 공기로, 어디까지 갈 수 있을까?"**
- 화면: **탑뷰**(타일 맵). 인원: 플레이어 1명. 전투: 실시간 근접(마우스 방향), Space 회피, 공격 예고 보고 피하기.
- 적: 들개, 생존자 무리. 후순위 아이디어: **총기**, 사건·선택지. 성장 요소는 없음.

## 세 가지 방향

| | **A. 살아남는 긴장감** | **B. 변이된 몸의 손맛** | **C. 길 위의 선택** |
| --- | --- | --- | --- |
| 한 문장 | 남은 자원으로 들키지 않고 어디까지 갈 수 있을까 | 방사능으로 변이한 몸으로 몰아쳐 뚫고 나간다 | 누구를 믿고 무엇을 챙겨 어느 길로 갈까 |
| 전투 | 피하는 게 기본, 싸우면 비쌈. 귀한 총알, 총소리가 적을 부름 | 전투가 주인공. 연타·완벽 회피 반격·변이 스킬 | 사건의 하나. 짧고 단순하게 |
| 핵심 장치 | 공기(또는 피폭) 잔량, 은신, **보는 방향만 보이는 시야** | 결정 재화로 스킬 강화, 피폭 수치·억제 주사기 | 생존자 관계, 교섭·거래, 경로·파밍 |
| 화면 | 시야 제한·총이 살려면 **탑뷰가 유리** | 지금 옆 시점 그대로 가능 | 지금 옆 시점 그대로 가능 |
| 1차 발표와 거리 | **가장 가까움**(공기·탑뷰·총기 후순위가 모두 발표에 있음) | 가장 멂(성장·초능력은 발표에 없음) | 중간(교섭·생존자는 발표에 있음) |
| 만드는 양 | 큼(탑뷰라면 그림·맵 다시) / 옆 시점이면 중간 | 중간~큼(스킬마다 동작·이펙트·밸런스) | 중간(대화·이벤트 글이 많음) |
| 지루함 해결 | 긴장감으로 해결(전투가 짧고 무서움) | 손맛으로 해결(전투가 다양함) | 전투 밖의 재미로 해결 |

## 지금 이미 있는 것

옆 시점 거리 맵, 실시간 이동·은신·대시, 마체테 3연타와 검로, 피폭체(예고·할퀴기·쓰러짐), 기습, 공통 타격감, 3D 동작 → 2D 도트 캐릭터 제작 도구(Blender 카메라만 바꾸면 위에서 본 그림도 뽑을 수 있음).

## 제안

1. **중심은 A, B에서 한 가지만 빌린다.** A는 1차 발표의 제목 문구를 되살려 교수님 지침("처음 기획에서 벗어나지 말 것")에 가장 잘 맞는다. 지루함은 B의 "완벽 회피 → 반격" 하나로 손맛을 보강한다. 변이 스킬·결정 강화는 나중으로 미룬다. (2026-11-12 공기 잔량을 제외해서, A의 긴장감은 은신·어둠과 손전등 시야·귀한 총알·위험한 적에서 나온다.)
2. **화면은 시험판으로 정한다.** 탑뷰는 1차 발표 원래 화면이라 "되돌림"이지만 다시 만드는 양이 크다. 작은 탑뷰 시험판(주인공 8방향, 거리 하나, 권총, 시야 제한)을 따로 만들어 지금 옆 시점과 직접 비교한 뒤 정한다.
3. **교수님께 확인할 것:** ① 방향 A로 가도 되는지 ② 탑뷰로 되돌릴지 옆 시점을 유지할지 ③ 남은 일정에 맞는 범위.

## Claude 추천 (2026-11-12)

A 중심 + 옆 시점 유지. 탑뷰의 부채꼴 시야 대신 **어둠 + 손전등**(보는 방향 앞만 밝음)으로 옆 시점에서 시야 제한. 전투는 마체테 + 완벽 회피 반격, 총은 드물게 얻는 비상용. 변이 스킬·결정 재화는 일정이 남으면.

## 결정 기록

- 2026-11-12 사용자: **"공기 요소는 제외하죠, 총소리가 적을 부르는 요소도 제외하죠."** → 공기 잔량을 되살리지 않는다(2026-11-10 결정 유지). 총을 쏴도 소리로 적이 모여들지 않는다.
- 2026-11-12 사용자 "시작" → **완벽 회피 → 반격**을 먼저 만들었다(어느 방향이든 쓰이는 작업).

- 2026-11-13 사용자: **"전투 집중이 좋아 보임."** 은신을 살리는 대신(적 무리·시야 방향·은신 처치) 전투를 중심으로 간다. 중심 방향이 A(긴장감)에서 **B(변이된 몸의 손맛) 쪽**으로 옮겨졌다. 1차 발표의 실시간 근접 전투(공격 예고 보고 피하기)와는 맞는다.
