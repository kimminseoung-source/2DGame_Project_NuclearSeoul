# 처음 기획과 지금의 차이

작성 2026-11-10. 교수님께서 "처음 기획에서 최대한 벗어나면 안 된다"고 하셔서, [1차 발표 자료](../presentation/부산까지_기획2_1차발표.pdf)(2026-11-03)와 지금의 [PRD](../../PRD.md)·코드를 비교했다.

## 그대로인 것

| 항목 | 1차 발표 | 지금 |
| --- | --- | --- |
| 주제 | 핵 재난 이후 가상 한국, 서울 → 부산 대피 거점 | 같음 |
| 진행 | 거점 준비 → 지상 탐색 → 위험 대응(관찰·교섭·전투) → 거점 도착 | 같음 |
| 구간 | 서울 → 중간 거점 → 부산, 3구간 | 같음(지금은 1구간 시제품) |
| 생존자 | 정체를 모르는 무리, 관찰·대화·교환·위협·우회 | 같음(관계 원 표시 기획, 아직 미구현) |
| 물자·배낭 | 물·식량·수리 부품, 배낭 공간 한계 | 배낭은 있음, 물자는 아직 없음 |
| 승패 | 체력 0이면 종료, 마지막 거점 도착 시 클리어 | 같음 |
| 화풍·환경 | 다크풍 도트, Python + pico2d, 싱글 | 같음 |
| 실제 원칙 | 실제 대응 원칙과 가상 규칙 구분(CDC 참고) | 같음 |

## 크게 바뀐 것

| 항목 | 1차 발표 | 지금 | 바뀐 정도 |
| --- | --- | --- | --- |
| **핵심 자원** | "남은 공기로, 어디까지 갈 수 있을까?" 공기 잔량·방호복 상태가 탐색의 한계. 검증 질문도 "공기가 선택을 바꾸는가" | 필터·공기·방호복 모두 제외, 오염·피폭은 추후 개발 | **매우 큼** — 발표의 제목 문구이자 핵심 재미가 빠짐 |
| **전투 방식** | 실시간 근접 공격(마우스 방향), Space 회피, 공격 예고를 보고 피하기 | 발더스 게이트 3식 턴제, d20 명중 돌림판, 미터 단위 이동 | **매우 큼** |
| **화면** | 탑뷰(내려다보는 화면), 타일 기반 맵 | 횡스크롤 + 바닥 깊이, 그림 배경 | 큼 |
| **인원** | 플레이어 1명 | 최대 3명 파티, 동료 모집 | 큼 |
| **적** | 들개(공격 예고), 생존자 무리 | 피폭체(좀비 형태), 적대 생존자 | 중간 — 생존자는 유지, 들개가 피폭체로 바뀜 |
| **성장·추가 요소** | 없음(후순위: 총기, 사건·선택지) | 스킬, 휴식, 피폭 주사기, 전공서 성장(PRD v2.0) | 중간 — 기획에 없던 요소 추가 |
| 무기 | 쇠파이프 | 야구 방망이 | 작음 |

## 정리

- 여정 구조(준비 → 탐색 → 조우 → 도착, 3구간)와 생존자 조우, 세계관은 지켜졌다.
- 그러나 1차 발표의 **핵심 재미였던 "공기 잔량"이 빠졌고**, **전투 방식(실시간 → 턴제)·화면(탑뷰 → 횡스크롤)·인원(1명 → 파티)** 이 바뀌었다. 겉으로 보기에 다른 게임에 가깝다고 느낄 수 있는 수준이다.

## 기획으로 되돌리거나 맞추는 방안 (제안)

1. **공기 잔량 복원(가장 중요)** — 발표 제목이 걸린 요소다. 얼굴을 가리는 문제는 지금 주인공이 이미 노란 방호복·후드 차림(발표 콘셉트와 같음)이므로 그림을 바꿀 필요가 없고, 공기는 HUD 게이지로만 보여 주면 된다. 지상 탐색 중 시간이 지나면 줄고, 거점에서 공기통을 교체한다. 파티 전원 파밍 부담은 "파티 공용 공기통 1개"처럼 단순화한다.
2. **방호복 상태** — 공격을 받으면 손상, 거점에서 수리. 공기와 함께 HUD에 표시.
3. **들개 추가** — 발표의 첫 적이었다. 피폭체와 함께 등장시켜 기획의 적 구성을 지킨다.
4. **전투 방식·화면·파티** — 이미 많이 구현돼 되돌리면 비용이 크다. 교수님께 "턴제·횡스크롤·파티로 바꾼 이유"를 설명하고 허용 여부를 확인하는 것을 권한다. 허용되지 않으면 실시간 근접 전투(공격 예고·회피)로 돌아가야 한다.
5. 앞으로의 변경은 이 문서와 1차 발표를 기준으로 먼저 비교하고 기록한다.

## 주인공 겉모습 변경 (2026-11-11)

- 1차 발표: 노란 방호복·후드 차림의 생존자.
- 변경: 사용자 결정으로 **생존자 느낌**(낡고 겹쳐 입은 탁한 색 옷, 작은 포인트 색 하나, 임시변통 장비, 얼굴이 보임)으로 바꾼다.
- 이유: 사용자가 밝은 노란 방호복보다 폐허에서 버텨 온 생존자 느낌을 원함. 방독면은 얼굴과 캐릭터 UI를 가려 이미 추후 개발로 미뤘다(2026-11-10).
- 지켜지는 것: "핵 재난 속 민간인 생존자"라는 주인공 설정, 근접 무기(방망이·파이프), 배낭을 멘 탐색자 모습. 맵에서 잘 보이도록 포인트 색 하나는 밝게 둔다.

## 전투 방식 되돌림 (2026-11-12)

- 결정: 턴제(BG3식) → **1차 발표대로 실시간 근접 전투**. 이유는 [PRD](../../PRD.md) v3.0. "크게 바뀐 것" 표의 전투 방식 항목이 1차 발표 쪽으로 돌아온다.
- 함께 정할 것: 파티(혼자 싸우는 주인공으로 시작, 동료는 지원), 주무기(방망이 대신 다른 무기 검토, 1차 발표는 쇠파이프), 적(일반·돌진 피폭체, 1차 발표의 들개).

## 방향 고민 정리 (2026-11-12)

변이 능력·결정 재화·총·시야 제한·탑뷰 논의를 세 방향(A 살아남는 긴장감 / B 변이된 몸의 손맛 / C 길 위의 선택)으로 묶어 1차 발표와 비교했다: [방향 한 장 정리](DIRECTION_ONE_PAGER.md). 탑뷰와 총기는 1차 발표에 있던 요소라 넣는다면 "되돌림"에 가깝다.
