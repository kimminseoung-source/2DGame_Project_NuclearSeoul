# 2D 그래픽 방향 조사 (2026-11-14)

순수 횡스크롤 확정 후 "2D도 그래픽이 다양한데 어떻게 할지" 조사. **미확정.** 규칙 6(그림보다 재미 먼저)에 따라 전투가 재밌다고 확인된 뒤 고른다.

## 스타일 6가지

| 스타일 | 대표 게임 | 느낌 | 우리에게 |
|---|---|---|---|
| 도트(픽셀) + 네온 | Katana Zero, Hotline Miami | 선명, 빠름, 색이 강함 | 전투 참고작과 같은 결. 만드는 양 중간 |
| 3D → 도트 | Dead Cells | 부드러운 동작, 도트 느낌 | **지금 우리 도구(Blender → 도트)와 같은 방식** |
| 어두운 고딕 도트 | Blasphemous | 무겁고 처참함, 세밀함 | 분위기는 맞지만 손으로 그릴 양이 매우 큼 |
| 실루엣 | Limbo, Inside, Deadlight | 검은 형체, 안개, 공포 | 핵 재난 분위기에 잘 맞음. 색 포인트(피폭 빛)가 돋보임 |
| 손그림(잉크·수채) | Hollow Knight, Gris, The Rusted | 감성, 부드러움 | 그림 실력과 시간이 많이 필요 |
| 도트 캐릭터 + 3D 배경 | Post War | 깊이감 | 순수 횡스크롤과 덜 맞음 |

## Claude 추천

**3D → 도트 캐릭터(Dead Cells 방식) + 실루엣 겹 배경 + 피폭 빛 하나만 밝게.**
- 캐릭터: 지금 Blender 도구 그대로. 새로 배울 것 없음.
- 배경: 앞쪽은 검은 실루엣, 뒤로 갈수록 안개 낀 회색 도시 겹(패럴랙스). 그리기 쉽고 분위기가 큼.
- 색: 전체는 회색·남색으로 누르고, **피폭 상처·방사능·주인공 포인트 색만 밝게** → 기둥 2(괴물이 되어 감)가 화면에서 보임. "흔한 건 싫어": 네온(Katana Zero)도 고딕(Blasphemous)도 아닌 "핵 재난 회색 + 피폭 빛".
- 주의: After Us 리뷰처럼 회색만 쓰면 단조로움 → 구역마다 다른 빛 색(서울 골목 주황 가로등, 지하철 초록 비상등, 부산 붉은 노을).
