# 그림 요청서 양식 (Claude → GPT)

복사해서 `docs/collab/requests/<날짜>_<이름>.md`로 만들고, 작업판 "그림 요청"에 한 줄 적는다. GPT는 끝나면 아래 "결과" 칸을 채우고 작업판을 "끝남"으로 옮긴다.

```markdown
# 요청: <무엇> (<날짜>)

- 왜: <게임에서 어디에 쓰나, 사용자 말 인용>
- 기준 그림: <따라야 할 원화·얼굴 머리 레이어 경로 — 얼굴 일관성>
- 참고 문서: ART_FEEDBACK, MOTION_RULES, CHARACTER_WORKFLOW 중 관련 줄

## 규격
| 항목 | 값 |
|---|---|
| 캔버스 | 64×64 (인물 키 약 36px, 발은 아래에서 12px 위) |
| 방향 | 예: 남동·남서·북동·북서 (8방향 이름: south, south-east, east, …) |
| 동작·장수 | 예: 조준 걷기 8장, 순서 = 접지 → 체중 받기 → 통과 → 들기 … |
| 몸/무기 | 몸만(빈손) / 무기 따로 PNG(손잡이 위치 표시) |
| 기준점 | 발 피벗, 오른손(손잡이), 보조손, 총구 — 장마다 json |
| 배경 | 투명 PNG, 효과(불꽃·먼지)는 그리지 않음(게임이 그림) |
| 파일 | `assets/characters/previews/<폴더>/<동작>/<방향>/<번호>.png` + README |

## 손맛(게임 쥬스)
- 예: 발사 순간 반동 장, 디딤 장(먼지가 나올 자리), 강조할 타격 장

## 검수 (Claude가 게임에서 확인할 것)
- 얼굴 머리 픽셀이 기준과 같은지, 몸이 칸 안인지, 발 미끄러짐(px), 손·총구 좌표가 그림과 맞는지

## 결과 (GPT가 채움)
- 만든 파일:
- 지킨 것 / 못 지킨 것:
- 남은 것:
```
