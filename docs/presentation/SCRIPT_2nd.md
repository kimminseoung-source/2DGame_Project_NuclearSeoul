## 게임 시연 연습 (0:10–0:50)

1. `python src/main.py`로 실행합니다(기본 구역이 골목). 창 크기는 그대로 1280×720입니다.
2. 시작하면 왼쪽 보도입니다. 오른쪽으로 걸으면 길 가운데 보도의 피폭체가 보고 달려옵니다.
3. 클릭을 길게 누르고 커서를 머리에 올렸다가 놓아 베기 → 할퀴기 예고(붉은 !)가 끝날 즈음 우클릭 → 휘청일 때 베기.
4. 길 건너 북쪽 가운데 집의 철문(빨간 벽돌, 방범창)으로 들어가 바닥의 붕대·통조림을 **E**로 줍습니다.
5. 나와서 남쪽 골목으로 내려가 빈터 끝 지하철 입구에서 **E**.
6. 피폭체는 매번 조금씩 다르게 움직이니 2~3번 연습하고, 잘 된 판을 씁니다. 실수하면 **R**로 처음부터 다시 할 수 있습니다.

## 녹화 방법 (무료, 설치 없이)

- **화면 + 목소리를 한 번에:** Windows 캡처 도구(`Win + Shift + R`)로 화면 녹화를 시작하고 마이크를 켭니다. PowerPoint 슬라이드 쇼(F5)와 게임 창을 `Alt + Tab`으로 오가며 대본을 읽습니다.
- **나눠서 찍기(실수가 적음):** 게임만 게임 바(`Win + Alt + R`)로 40초 찍고, 슬라이드는 PowerPoint [녹화] 기능으로 목소리와 함께 찍은 뒤, Clipchamp(Windows 기본 무료 편집기)에서 순서대로 이어 붙입니다.
- 마지막에 직접 재생해서 **길이 1분 30초, 글자가 보이는지, 목소리가 또렷한지** 확인합니다.
