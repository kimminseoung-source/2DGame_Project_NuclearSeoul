# 2차 발표 준비 (2026-11-15)

교수님 가이드(`2026_2DGP_2차발표가이드.pdf`, 저장소에는 올리지 않음) 요약과 우리 준비 계획.

## 1. 가이드 요약
- **1분 30초 발표 동영상**: 프로젝트 진행 상황 발표 + 게임 데모 실행. 글자가 뚜렷하고 음성이 또렷해야 함(직접 재생해서 확인).
- **제출**: 유튜브 업로드 후 링크를 e-class에, GitHub 저장소 링크를 e-class에, 발표 자료는 저장소에.
- **기한**: 발표 당일 0시 1분(엄수). 발표 날짜: _사용자 확인 필요_.
- **PPT 구성**: 게임 설명 1쪽, 개발 계획 대비 현재 진행 상황 1쪽(1차 일정 대비 상세히), **기획 변경이 있으면 변경 내용 제시**.

## 2. 1차 계획 대비 진행 상황 (발표 슬라이드 2쪽의 바탕)

| 1차 발표 단계 (비율) | 계획 | 현재 |
|---|---|---|
| 01 탐색 기반 (20%) | 타일맵·이동·충돌·수집, 물자를 찾고 출구로 | **완료**(2026-11-15): 이동·충돌, 물자 7개 줍기와 사용, 지하철 입구로 나가기와 구역 요약. 타일맵 그림은 4단계에서 |
| 02 전투 시제품 (25%) | 적 AI·공격·회피·피격, 공격을 보고 피할 수 있는가 | **완료 이상**: 마우스 방향 한 방 베기, 구르기, 예고(!), 보고 듣고 찾는 피폭체, 시야 밖 공격, 붙잡힘, 사방에서 몰려오기 |
| 03 생존과 여정 (30%) | 공기·장비·생존자·구간 | 피폭 수치(시간 느리게의 대가)만 있음. 구역 3개·이월·결말은 다음 |
| 04 완성·검수 (25%) | 픽셀 그래픽·소리·UI·출처 | 효과음 일부, 출처 문서. 그래픽·소리는 다시 만들 예정 |

## 3. 기획 변경 (슬라이드에 꼭 넣을 것, ORIGINAL_VS_CURRENT.md·DESIGN_LOCK.md 근거)

| 1차 발표 | 지금 | 이유 |
|---|---|---|
| 탑뷰, 마우스 방향 근접 공격, Space 회피 | **유지** (중간에 횡스크롤·턴제를 시험한 뒤 탑뷰로 돌아옴) | 세 방식을 직접 해 보고 "사방에서 오는 긴장감" |
| 공기 잔량·방호복 | **피폭 수치**: 시간을 느리게 하는 힘의 대가, 끝까지 차면 괴물이 됨 | 자원 관리보다 전투 선택에 압박을 걸기 위해 |
| 들개·생존자 무리 | **피폭체**(피폭 한계를 넘어 변이한 사람), 좀보이드식 감각 | 핵 재난 세계관과 이야기(결말)에 연결 |
| 쇠파이프 | 마체테, 한 방 베기 | 짧고 긴장감 있는 전투 |
| 결말 없음 | 힘을 많이 쓰면 괴물이 되어 쉘터를 공격하는 결말, 아끼면 생존자로 도착 | 기둥 2(괴물이 되어 가는 대가) |

## 4. 준비 순서
1. 데모가 한 흐름으로 보이게: 탐색(물자) → 전투 → 출구 (01 단계 채우기)
2. 발표 자료(PPTX 3쪽: 게임 설명 / 진행 상황 / 기획 변경)를 `docs/presentation/`에
3. 동영상 대본(1분 30초)과 촬영 순서. 녹화와 목소리는 사용자(Windows: Win+Alt+R 게임 바 녹화)
4. 제출 전 점검: 새 폴더에서 실행 확인, 저장소 링크, 영상 소리·글자 확인
